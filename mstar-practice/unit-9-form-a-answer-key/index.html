Select all that apply

Select ALL statements that name the independent variable correctly for their own situation.

A, C, E. A gardener chooses how many minutes to run the sprinkler, so the minutes the sprinkler runs is the independent variable. · Claire decides how long to jog, so the minutes she jogs is the independent variable. · A tray receives a set number of hours of sunlight each day, so the hours of sunlight is the independent variable and the plant height depends on it.

26.AT.119-2 · Analyze Graphs of Relationships Between Two Variables

Written response — 2 points

Ramona is graphing sales at the stadium pretzel stand. Pretzels cost $6 each, and her table shows 1 pretzel with $6, 2 pretzels with $12, and 3 pretzels with $18. She labels the horizontal axis 'number of pretzels' and the vertical axis 'total cost'. For 3 pretzels she plots the point (18, 3).

Explain Ramona's misconception and give the correct ordered pair for 3 pretzels.

Score 2: Student explains that the independent variable, the number of pretzels, is written first in an ordered pair and belongs on the horizontal axis, and gives the point (3, 18).

Score 1: Student gives the point (3, 18) but does not explain that the independent variable is written first.

Score 0: Student agrees with Ramona or gives an unrelated response.

Model: Ramona reversed the coordinates. Her horizontal axis is the number of pretzels and her vertical axis is the total cost, so the first coordinate has to be pretzels and the second has to be dollars. Three pretzels cost 3 × 6 = 18 dollars, so the point is (3, 18). The point she plotted, (18, 3), reads as 18 pretzels costing 3 dollars, which does not match any row of her table.

36.AT.119-3 · Write Equations to Represent Relationships Between Two Variables

Part A

A spin studio charges $7.50 for each class. Let n be the number of classes a member takes and let c be the total cost in dollars. Which equation represents the relationship?

D. c = 7.5n

The studio charges $7.50 for every class, so the total cost is the rate times the number of classes: c = 7.5n. The dependent variable, the cost, stands alone on the left, and the independent variable, the classes, is multiplied by the rate.

Part B

Which reasoning justifies the equation chosen in Part A?

D. The $7.50 is charged for every single class, so the total is 7.5 times the classes; 4 classes cost 7.5 × 4 = $30.

A rate applies to every class, so the operation is multiplication and the total for 4 classes is 7.5 × 4 = $30. Adding gives $11.50, which charges the fee only once. The cost depends on the classes, not the other way around, so the cost is the variable that stands alone.

46.AT.119-4 · Apply Two-Variable Relationships to Solve Problems

Part A

A bottling machine fills 45 bottles each minute. The relationship is b = 45m, where m is the number of minutes the machine runs and b is the number of bottles filled. The crew needs 1,800 bottles. How many minutes must the machine run?

A. 40 minutes

Substitute 1,800 for b to get 45m = 1,800, then divide both sides by 45: m = 1,800 ÷ 45 = 40 minutes. Checking the answer, 45 × 40 = 1,800 bottles.

Part B

Which reasoning justifies the number of minutes chosen in Part A?

C. Substitute 1,800 for b to get 45m = 1,800, then divide both sides by 45, since 45 is multiplied by m.

In b = 45m the 45 is multiplied by m, so dividing both sides by 45 undoes the multiplication and gives m = 40. Multiplying 1,800 by 45 gives 81,000, far more minutes than the whole order needs, and subtracting treats the rate as a one-time amount instead of a rate for every minute.
