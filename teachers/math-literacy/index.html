What is in every unit

1. Word wall

Five key words with a student-friendly meaning, an example, the Spanish word and a place for the student's own sentence.

2. Read it. Say it. Solve it.

Three word problems with a Three Reads routine. Each unit teaches one reading move, such as finding the question or crossing out extra information.

3. Math talk and write

A prompt with a sentence frame, so every student can explain their thinking out loud and on paper.

4. Fact fluency

Eight facts, untimed. Accuracy first. A new set any time.

5. Skill fluency

Eight grade-level skill items (regrouping, fractions, decimals, equations) with a new set any time.

6. Quick check and goal

A vocabulary item, a skill item and a word problem, then a 1 to 4 self-rating.

Why teachers use it

  • Zero prep. Print the packet or open the page. No materials to gather: everything uses paper and pencil.
  • Every answer is checked by computer. The program's numbers are computed and re-verified, so answer keys are right.
  • Untimed on purpose. Fluency is built on accuracy and strategy, not racing a clock.
  • Built for multilingual learners. Spanish word help, sentence frames and one routine you can reuse all year.
  • Interactive and printable. The same content as a web page, a Word packet you can edit and a PDF.
