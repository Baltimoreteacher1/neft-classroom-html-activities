# BCPSS Teacher Studio — build contract

Route: `/bcpss-teachers/studio/` (teacher app, hash routes) and `/bcpss-teachers/studio/play/` (student-safe activity player).
Scope: **K–8 ONLY** (Joel, 2026-11-23: no Pre-K, no grades 9–12), 11 subject areas. Static: vanilla ES modules, no backend, no new dependencies. Tokens come from
`/access-practice-lab/ds.css` (navy `--brand`, teal `--teal`, ochre `--accent`, terracotta `--coral`, sage, paper `--bg`,
domain colours `--listening --speaking --reading --writing`). Never hardcode a second palette; studio-only classes are prefixed `st-`.

## Hard rules (every worker)

1. **No fabricated curriculum.** `curriculum.status` is `"standards-aligned"` unless the lesson maps to a unit that exists in the
   BCPSS seed (`data/bcpss-curriculum-seed.mjs`, K–8 ELA/Math/Science/Social Studies only) — then `"district-referenced"` plus
   `unitId` (must exist; the validator checks). Never invent unit titles, publisher lesson numbers or textbook text.
2. **Standards codes must exist in the registry** (`data/standards/*.js`). Add the code there first with a paraphrased `text`
   (never copy publisher/assessment text). Use only codes you are certain are real (CCSS `6.RP.A.3`, NGSS-based `3-LS1-1`,
   C3 `D2.His.1.6-8`, WIDA `ELD-MA.6-8.Explain...` etc.). Unsure → leave it out.
3. **No official-WIDA claims.** Everything is "WIDA-aligned original practice". Never score, never predict ACCESS results, never
   reproduce secure/official items. Practice is untimed.
4. **Rigor stays.** Scaffold tiers change language access (frames, word banks, visuals, oral rehearsal), never the math/science/
   reading task. The same `answer`/target applies in every tier.
5. **Answers are checked by code.** Every math item carries `answer` data the validator recomputes where possible.
6. **No emoji, no lorem ipsum, no placeholder text, no "TODO", no stock imagery.** Visuals are SVG built from the visual kit
   (`core/visuals.js`) or existing repo art (`access-practice-lab/pictures`, `access-practice-lab/src/art`).
7. **Privacy.** No student names/ids anywhere. Evidence is class-level, anonymous, device-local, moved by pasted "evidence code".
8. **a11y.** Keyboard + touch for every interaction, visible focus, 44px targets, `aria-live` feedback, reduced-motion respected,
   every visual has `alt` text (and `longDesc` when it carries data), colour never the only signal, audio always has a transcript.
9. **Subject authenticity.** Subjects differ in activities, visuals, discourse and vocabulary. See `SUBJECT_PROFILE` in
   `data/taxonomy.js`; do not reuse a math template with new nouns.
10. **File size.** ≤500 LOC per file (hard cap 750, data files excluded). Split rather than grow.
11. Review status is honest: every resource ships `review.status = "authored"` (automated checks run by
    `tools/validate-studio.mjs`; human stages stay `"pending"`). The UI shows "Teacher review recommended" until a human flips it.

Data modules are plain ES modules (`export default {...}`) importable by both browser and Node (no DOM, no JSON import attributes —

## Visual spec (rendered by `core/visuals.js` → `renderVisual(spec) → SVG string`, `visualToPng(spec,w) → Promise<Blob>`)

Every spec has `kind`, `alt` (required), optional `longDesc`, `w`,`h` (default 480×320), `palette` (token names). Kinds:

| kind         | fields                                                                                                                                             |
| ------------ | -------------------------------------------------------------------------------------------------------------------------------------------------- |
| `shapes`     | `items:[{t:"rect"/"circle"/"ellipse"/"line"/"poly"/"path"/"text"/"icon", ...attrs, fill/stroke as palette names or hex}]` general primitive canvas |
| `icon`       | `name` from `core/icons.js` (≥100 flat icons: animals, plants, weather, school, food, body, community, tools, shapes, science kit, arrows)         |
| `scene`      | `bg:"sky"/"room"/"field"/"water"/"plain"`, `items:[{icon,x,y,s,label?}]`                                                                           |
| `tape`       | `parts:[{label,units,color?}]`, `total?` (tape/bar model, ratio double tape via `rows:[{label,parts}]`)                                            |
| `numberline` | `min,max,step,marks:[{at,label?,style?}]`, `arcs?:[{from,to,label}]`, `openEnds?`                                                                  |
| `coord`      | `xmax,ymax,xLabel,yLabel,points:[{x,y,label?}]`, `lines:[{m,b,label?,dashed?}]`, `grid?`                                                           |
| `table`      | `head:[...]`, `rows:[[...]]`, `highlight?:[[r,c]]` (SVG table, for ratio tables / data)                                                            |
| `cycle`      | `stages:[{label,icon?}]` arrows between, circular                                                                                                  |
| `flow`       | `steps:[{label,icon?}]` linear with arrows, `vertical?`                                                                                            |
| `labeled`    | `base:<visual spec>`, `labels:[{text,x,y,tx,ty}]` leader-line callouts (labels may be `hidden:true` for label-the-diagram engines)                 |
| `timeline`   | `events:[{at,label,detail?}]`, `span:[start,end]`                                                                                                  |
| `map`        | `regions:[{id,label,d                                                                                                                              | rect}]`, `routes?`, `compass?` (schematic maps, never geographic claims unless data is exact) |
| `venn`       | `sets:[{label,items:[...]}]`, `overlap:[...]`                                                                                                      |
| `bars`       | `data:[{label,value}]`, `xLabel,yLabel,unit` (bar/pictograph)                                                                                      |

Palette names: `navy teal sage ochre coral rose sky ink paper line`. Output must be deterministic, `viewBox`-scaled, `role="img"` with `<title>`/`<desc>`.

## Vocabulary collection (`data/vocab/<id>.js`)

```js
export default {
  id:"g6-math-ratios", title, grade:"6", band:"6-8", subject:"math",
  curriculum:{status:"standards-aligned", note}, standards:["6.RP.A.1"], unitId?: "g6-math-u?",
  entries:[{
    id:"ratio", word:"ratio", pos:"noun", pron:"RAY-shee-oh", ipa?:"ˈreɪʃioʊ",
    def:"A comparison of two quantities.",                // student-friendly
    visual:{kind:"tape", alt:"...", ...},                  // required unless noVisualReason
    noVisualReason?:"abstract connector word",
    context:"The ratio of cats to dogs is 3 to 2.",
    nonExample?:"3 + 2 is not a ratio; it adds the quantities.",
    academicSentence:"A ratio compares ...",
    everyday?:"Like 2 scoops of mix for every 1 cup of water.",
    es?:{word:"razón",def:"...",verified:true|false}, // include only if sure; verified:false shows "needs review" badge
    homeLanguages?:{ar?:{...}}                            // other languages only if verified, else omit
    morphology?:{parts:[{part:"bi-",meaning:"two"}]}, misconception?:"...", related:["rate","unit rate"],
    practice:{visualPrompt:"Which picture shows 2 to 3?", speakWrite:"Say a ratio about our class, then write it.", retrieval:"Yesterday we learned ... Which word means ...?"},
    tier?:2|3, domains?:["Speaking","Writing"], klu?:"Explain"
  }],
  review:{status:"authored", checks:{}}
}
```

`audio`: pronunciation always via `speechSynthesis` (`core/speech.js` in kit) — no mp3 files; transcript is the word/sentence itself.

export default {

  title, subtitle?, grade:"6", band:"6-8", subject:"math", duration:50,
  curriculum:{status:"standards-aligned"|"district-referenced", unitId?, program?:"Reveal Math", note:"..."},
  standards:["6.EE.C.9"], wida:{eld:["ELD-MA"], klus:["Explain"], domains:["Speaking","Writing"], cluster:"6-8"},
  contentObjective:"I can ...", languageObjective:"I can explain ... using 'as ... increases, ...'.",
  languageDemands:{ functions:["describe a pattern","compare representations"], structures:["as __ increases, __ ..."],
      discourse:"two-turn partner explanation", barriers:["'for every' vs 'per'"], oralRehearse:["..."], writeScaffold:"..." },
  vocab:{ collection:"g6-math-ratios", ids:["ratio"] },       // must resolve; or inline `entries:[...]`
  launch:{ title:"Notice / Wonder", visual:<visual spec>, prompts:["What do you notice?","What do you wonder?"], teacherNote },
  teach:{ model:"teacher explanation, 3–6 short paragraphs or steps", moves:[...] },
  guided:[{prompt, answer, hint, supports:{ee:{frames:[],wordBank:[],visual?},dev:{...},exp:{...},br:{...}}}],
  collaborate:{ title, task, roles?, discussionCards:[{prompt,frame}] },
  threeWays:{ see:{title,visualOrModel,teacherNote}, discuss:{title,structure,frames}, apply:{title,task,successCriteria:[...]} },
  activities:[{engine:"concept-builder", id:"g6-ratio-table-lab"}],   // ids in data/activities/
  independent:{items:[{id,prompt,type:"numeric"|"choice"|"short",answer,tolerance?,choices?,explain}]},
  formative:{...same item shape...}, exitTicket:{prompt, items:[...], successCriteria:[...]},
  answerKey:{ notes:"...", items:{<itemId>:"worked answer"} },
  extension:{title,task}, homeLanguage?:{es:{objective,vocab:[{en,es,verified}],familyPrompt}},
  printables:["organizer","task-cards","exit-ticket","vocab-mat"],   // template ids from print/templates.js
  teacherNotes:{ pacing, misconceptions:[...], differentiation, ...},

Supports shape everywhere: `{ee:S,dev:S,exp:S,br:S}` with `S={frames?:[],wordBank?:[],visual?:<spec>,directions?:"",hint?:"",oral?:""}`. `br` may be `{}`.

## Activity data per engine (`data/activities/<id>.js`, `export default {id, engine, title, grade, band, subject, lessonId?, standards, vocabIds?, minutes, intro, items|rounds|..., reflection:{prompt, frames:{ee,dev,exp,br}}}`)

Shared per-item fields: `id`, `prompt`, `supports` (tier object), `misconceptions:[{pick|match, tag, hint, model?}]` (feedback tied to the wrong choice), `hints:[h1,h2,h3]` (graduated; never the answer), `transfer?:{...same item shape}` shown after repeated misses.

- `visual-match` — `pairs:[{id, term, visual?, definition?, example?, es?}]`, `modes:["term-visual","term-definition","term-example"]`, `distractors:[{term|visual|definition, tag, hint}]`.
- `language-detective` — `scene:{kind:"image"|"passage"|"conversation"|"diagram", visual?, text?, lines?:[{speaker,text}]}`, `questions:[{id,prompt,type:"evidence"|"inference"|"detail", options?, evidence:[{id,text|region}], answer}]`, `explainFrames`, `claimPrompt`.
- `concept-builder` — `kind:"ratio-table"|"number-line"|"graph-line"|"label-diagram"|"process-model"|"timeline-sort"|"scale-sort"|"area-model"|"fraction-bar"`, kind-specific `model:{...}`, `tasks:[{id,prompt,target,check:{type,...},explain:{prompt,frames}}]`, every task ends with "what changed and why" explanation.
- `conversation-studio` — `topic`, `roles:[...]`, `moves:[{id,label,frames:{ee,dev,exp,br},example}]`, `rehearsal:{turns:[{speaker,prompt,suggest}]}`, `sequenceTask:{moves in order}`, `reflect`.
- `escape-challenge` — `story:{title,setting,beats:[{id,text}]}`, `rooms:[{id,title,narrative,puzzle:{type:"numeric"|"choice"|"order"|"match", ... answer},gate:{needs:"concept"},reveal}]` — puzzles test the concept; a code is _derived from correct answers_, never guessable arbitrary digits.
- `vocab-quest` — `collection`, `stages:[{id,kind:"see"|"use-in-context"|"retrieve"|"apply"|"revisit", entryIds, items}]`, progression across ≥4 stages, spaced revisit queue.
- `argument-builder` — `question`, `sources:[{id,title,text|visual}]`, `claims:[{id,text,strong:bool}]`, `evidence:[{id,sourceId,text,supports:claimId|null,quality:"strong"|"weak"|"irrelevant"}]`, `reasoningFrames`, `revision:{checks:[{id,label}]}`.
- `wida-studio` — see `data/wida/<id>.js` below.
- `early-sort` (K–2) — `mode:"picture-sort"|"sound-match"|"syllable-clap"|"sequence-story"|"oral-describe"`, `items:[{id,visual,word,sound?,category?}]`, `categories:[{id,label,visual}]`, `oral:{prompt, frames}`; child-sized targets, audio (speechSynthesis) on every item, no reading required, no timers.

## WIDA practice collection (`data/wida/<id>.js`)

`{id, domain, grade, band, cluster, subject, klus:[...], standards:[...], title, tasks:[{id, type, ...}], successCriteria:[...], supports, teacherGuide, scoring:{ objective:"auto"|"none", note:"Instructional indicators only; not a WIDA score." }}`
Task types: Listening `listen-select|listen-sequence|listen-label|listen-notes` (`audio:{transcript,voiceHint}` + visual; captions toggle), Speaking `speak-describe|speak-explain|speak-compare|speak-argue` (optional local recording via MediaRecorder after explicit click; never uploaded; teacher feedback rubric), Reading `read-select|read-evidence|read-sort|read-multitext` (original passages), Writing `write-expand|write-explain|write-paragraph|write-revise` (expandable response, language targets, revision checklist).

## Project (`data/projects/<id>.js`)

`{id, title, drivingQuestion, grade/band, subject(s), standards, wida, contentTargets, languageTargets, duration, materials, intro, facilitation:[...], studentDirections:[...], checkpoints:[{id,title,days,evidence,tool?}], visuals:[...], organizers:[template ids], vocab:{collection,ids}, supports:{ee,dev,exp,br}, rubric:{criteria:[{id,label,levels:[{score,descriptor}]}]}, selfAssessment:[...], peerFeedback:{structure,frames}, revision, finalProduct, tools:[{engine,id}], review}`

## Evidence (engine-core.js → `core/evidence.js`)

Attempt record `{v:1,aid,eng,lesson?,t:ISO,tier,support:{…},items:[{id,tries,hints,ok,tags:[misconception tags],ms?}],reflection?:text}`
stored under `lp.studio.v1.ev.<aid>`. Share code = `LPE1.` + base64url(JSON with no names). Teacher pastes codes into Class Evidence.
Dashboard statements only render when `n ≥ 3` attempts back them and always show the count behind them.

## localStorage keys (all prefixed `lp.studio.v1.`)

`prefs` (grade, subject, band, role, lang, projector, scale) · `classes` · `favorites` · `recents` · `bundles` · `ev.<aid>` · `tour` · `progress.<aid>` (save/resume of an in-progress activity). Existing hub/pathways keys are never touched.

## Verification contract

`node tools/validate-studio.mjs` must pass (schema, resolved ids, standards registry, answer recomputation, no placeholder strings,
no emoji, every visual renders, every vocab entry has visual|noVisualReason, scaffold tiers present on all guided items).
Per-engine unit tests: `node --test tools/studio-<name>.test.mjs`. Browser smoke: Playwright script per owner with screenshots to the scratchpad.

## Routes and view contract (teacher app, hash routing)

`studio.js` (shell) lazy-loads `views/<name>.js`. Each view: `export async function render({ root, params, shell }) → void | cleanup fn`.
`shell = { nav(hash), prefs, catalog, classes, library, announce, setTitle(t), openActivity(activityId, {tier, mode}) , projector }`.
`catalog` (core/catalog.js, owned by shell): `manifest()`, `lesson(id)`, `vocab(id)`, `activity(id)`, `wida(id)`, `project(id)`, `standards()`,
`seedUnits(grade, subject)`, `seedUnit(unitId)` (fetch `/api/bcpss/units?grade&subject`, `/api/bcpss/units/<id>`; cached; graceful failure).
