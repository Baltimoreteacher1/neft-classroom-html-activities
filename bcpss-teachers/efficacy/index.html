1. BCPSS K–8 Unit Coverage (162 Units)

The bridge organizes 162 K–8 instructional units spanning Grades K through 8 across four core content areas: English Language Arts, Mathematics, Science, and Social Studies. Each unit includes standards alignment, Tier 2/Tier 3 academic vocabulary, classroom language routines, reading passages at three language-support tiers, and printable studio packets.

2. Bilingual EN/ES Framework

Every unit carries parallel English and Spanish family communication cards, bilingual conversation starters, and key vocabulary supports so multilingual families can engage with unit concepts in the home language. Scaffolds are inspired by the WIDA ELD Standards Framework (2020) and are explicitly labeled as teacher-built supports, not official WIDA materials.

3. Automated Verification Gates

Every release is checked by automated verification gates with paired negative controls to confirm the checks can fail when invariants break:

  • Content & API integrity: verifies list/detail parity, bilingual EN/ES completeness, reading/routine answer bounds, and provenance draft labels across all 162 units.
  • Performance budgets (G-97): enforces payload size limits (≤ 250 KB full unit response), ETag / 304 conditional caching, ?fields= payload reduction (≥ 70%), and static asset size ceilings.
  • Privacy & trust checks (G-99): verifies draft review notices, D8 on-device lock disclosures, zero external CDN dependencies, zero student PII in demo pages, and D14 minimum cell size 10 suppression in aggregate summaries.
  • Visual palette & accessibility checks (G-09): enforces high-contrast editorial typography and zero prohibited purple hues across teacher surfaces.
