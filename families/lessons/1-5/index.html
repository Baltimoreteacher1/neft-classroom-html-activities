Math is Finding Patterns

Las matemáticas son encontrar patrones

I can find patterns and pattern rules, use them to make generalizations, and check my solutions with a table of values.

Speaking and writing goal: I can describe a pattern using the words pattern rule, generalization, and 'each number is ___ more than the one before it.'

What Your Child Is Learning / Qué está aprendiendo su estudiante

English

Tonight we look for a pattern, write the pattern rule in words, and use a table of values to check that our answers are reasonable.

A pattern rule tells you what to do to any number in the pattern, so you can answer questions you have not worked out yet.

Español

Esta noche buscamos un patrón, escribimos la regla del patrón con palabras y usamos una tabla de valores para comprobar que nuestras respuestas son razonables.

La regla de un patrón dice qué hacer con cualquier número del patrón, para poder responder preguntas que todavía no has resuelto.

Why This Matters / Por qué es importante

This skill supports everyday problem solving with money, measurements, games, planning, and checking whether an answer is reasonable.
Esta habilidad ayuda con dinero, medidas, juegos, planificación y con revisar si una respuesta es razonable.

Example from this lesson / Ejemplo de esta lección

Real example: coins. One penny is $0.01, one nickel is $0.05, one dime is $0.10, one quarter is $0.25.

Ejemplo real: monedas. Un penny vale $0.01, un nickel $0.05, un dime $0.10 y un quarter $0.25.

Make a table: 100 pennies = $1.00, 100 nickels = $5.00, 100 dimes = $10.00, 100 quarters = $25.00.

Hagan una tabla: 100 pennies = $1.00, 100 nickels = $5.00, 100 dimes = $10.00, 100 quarters = $25.00.

The pattern rule in words: multiply the number of coins by the value of one coin.

La regla del patrón en palabras: multiplica la cantidad de monedas por el valor de una moneda.

How You Can Help At Home / Cómo puede ayudar en casa

Ask your student

  • What changes from one row to the next?
  • Can you say the rule as a sentence?

Watch for: Listen for "pattern rule" (regla del patrón) — the sentence that says what to do every time.

Pregunte a su estudiante

  • ¿Qué cambia de una fila a la siguiente?
  • ¿Puedes decir la regla como una oración?

Preste atención: Escucha "regla del patrón": la frase que dice qué hacer cada vez.

Key Vocabulary / Vocabulario clave

pattern patrón

Something that repeats or changes in a predictable way.

Algo que se repite o cambia de una manera predecible.

pattern rule regla del patrón

The instruction that tells how to get from one number in a pattern to the next.

La instrucción que dice cómo pasar de un número del patrón al siguiente.

generalization generalización

A statement that is true for a whole pattern, made by noticing repeated calculations.

Una afirmación verdadera para todo un patrón, hecha al notar cálculos repetidos.

table of values tabla de valores

A table that lists each step of a pattern so you can check that a solution is reasonable.

Una tabla que muestra cada paso de un patrón para comprobar que una solución es razonable.

reasonableness sensatez del resultado

Whether an answer makes sense — checked as you work, with adjustments made when needed.

Si una respuesta tiene sentido — se comprueba mientras trabajas y se ajusta cuando es necesario.

Try It Together / Inténtenlo juntos

A bag of chips costs $2.50. Make a table for 1, 2, 3, and 4 bags.

Una bolsa de papitas cuesta $2.50. Hagan una tabla para 1, 2, 3 y 4 bolsas.

Let your child explain first, then open a hint. / Deje que su estudiante explique primero y después abra una pista.

  1. Fill in the table: 1 bag $2.50, 2 bags $5.00, 3 bags $7.50, 4 bags ?
    Llenen la tabla: 1 bolsa $2.50, 2 bolsas $5.00, 3 bolsas $7.50, 4 bolsas ?
    Show hint / Mostrar pista
    Each row adds $2.50.
    Cada fila suma $2.50.
  2. Write the pattern rule in words.
    Escriban la regla del patrón con palabras.
    Show hint / Mostrar pista
    "Multiply the number of bags by $2.50."
    "Multiplica la cantidad de bolsas por $2.50".
  3. Use the rule for 10 bags without extending the table.
    Usen la regla para 10 bolsas sin extender la tabla.
    Show hint / Mostrar pista
    10 × 2.50 = $25.00
    10 × 2.50 = $25.00
