Write and Evaluate Algebraic Expressions

Escribir y evaluar expresiones algebraicas

I can write an algebraic expression for a real situation and evaluate it for a given value of the variable.

Speaking and writing goal: I can explain my expression using the words variable, term, coefficient, constant, substitute, and evaluate.

What Your Child Is Learning / Qué está aprendiendo su estudiante

English

Tonight we turn words into an algebraic expression, then evaluate it for a given number of students.

Name what the variable represents, then describe how the quantities relate. A cost per ticket times the number of tickets gives total cost. Do not choose an operation from a keyword alone.

Español

Esta noche convertimos palabras en una expresión algebraica y luego la evaluamos para un número dado de estudiantes.

Nombra lo que representa la variable y describe cómo se relacionan las cantidades. El costo por boleto multiplicado por la cantidad de boletos da el costo total. No elijas una operación por una palabra aislada.

Why This Matters / Por qué es importante

Expressions and equations help students describe patterns and missing numbers. This matters for planning, budgeting, games, coding, and solving everyday questions step by step.
Las expresiones y ecuaciones ayudan a describir patrones y números desconocidos. Son útiles para planear, presupuestar y resolver problemas paso a paso.

Example from this lesson / Ejemplo de esta lección

Real example: a concert charges $12 for each ticket, plus a flat $50 venue fee. Let t be the number of tickets. We want an expression for the total revenue.

Ejemplo real: un concierto cobra $12 por cada boleto, más una tarifa fija de $50 por el lugar. Sea t el número de boletos. Queremos una expresión para los ingresos totales.

"$12 for each ticket" means 12 times t. We write that as 12t (a number next to a letter means multiply).

"$12 por cada boleto" significa 12 por t. Lo escribimos como 12t (un número junto a una letra significa multiplicar).

The $50 fee is added one time, no matter how many tickets sell. So we add 50.

La tarifa de $50 se suma una sola vez, sin importar cuántos boletos se vendan. Entonces sumamos 50.

How You Can Help At Home / Cómo puede ayudar en casa

Ask your student

  • What key word do you see? Does it tell us to add, subtract, or multiply?
  • Which number stays the same no matter what, and which one changes?

Watch for: Listen for "variable" — it means a letter that stands for an unknown number.

Pregunte a su estudiante

  • ¿Qué palabra clave ves? ¿Nos dice sumar, restar o multiplicar?
  • ¿Qué número se queda igual pase lo que pase, y cuál cambia?

Preste atención: Escucha la palabra "variable" — significa una letra que representa un número desconocido.

Key Vocabulary / Vocabulario clave

Write Algebraic Expressions Escribir expresiones algebraicas

Translate words or a situation into numbers, variables, and operation symbols.

Traducir palabras o una situación a números, variables y símbolos de operaciones.

Variable Variable

A letter that stands for a number that is unknown or can change.

Una letra que representa un número desconocido o que puede cambiar.

Algebraic Expression Expresión algebraica

A math phrase that has at least one letter.

Una frase matemática que tiene al menos una letra.

Coefficient Coeficiente

The number in front of a letter, like the 3 in 3x.

El número frente a una letra, como el 3 en 3x.

Constant Constante

A fixed number in an expression or equation that does not change.

Un número fijo en una expresión o ecuación que no cambia.

Like terms Términos semejantes

Terms with the same letter raised to the same power, like 2x and 5x.

Términos con la misma letra elevada a la misma potencia, como 2x y 5x.

Try It Together / Inténtenlo juntos

Stay at the concert, but make it simpler: a snack stand sells drinks for $5 each. Let d be the number of drinks.

Sigan en el concierto, pero háganlo más sencillo: un puesto vende bebidas a $5 cada una. Sea d el número de bebidas.

Let your child explain first, then open a hint. / Deje que su estudiante explique primero y después abra una pista.

  1. Write an expression for the cost of d drinks. What does "$5 each" tell you to do?
    Escriban una expresión para el costo de d bebidas. ¿Qué les dice "$5 cada una" que hagan?
    Show hint / Mostrar pista
    "Each" means multiply, so multiply 5 by d.
    "Cada" significa multiplicar, así que multipliquen 5 por d.
  2. Now suppose they also pay a flat $3 for a cup. Add that fee to your expression.
    Ahora supongan que también pagan $3 fijos por un vaso. Sumen esa tarifa a su expresión.
    Show hint / Mostrar pista
    The $3 is added once, so write 5d + 3.
    Los $3 se suman una sola vez, así que escriban 5d + 3.
  3. Check together: in 5d + 3, which part changes with the number of drinks, and which part stays the same?
    Revisen juntos: en 5d + 3, ¿qué parte cambia con el número de bebidas y qué parte se queda igual?
    Show hint / Mostrar pista
    The 5d grows with more drinks; the 3 stays fixed.
    El 5d crece con más bebidas; el 3 se queda fijo.
