Add and Subtract Decimals

Sumar y restar decimales

I can add and subtract decimals by lining up the place values and the decimal points.

Speaking and writing goal: I can explain my steps using the words decimal, place value, tenths, hundredths, and add zeros.

What Your Child Is Learning / Qué está aprendiendo su estudiante

English

Tonight we add and subtract decimals. The key is to line up the decimal points so the same place values match.

When you line up the decimal points, tenths add to tenths and hundredths add to hundredths. If a number is shorter, add a zero at the end so every place matches.

Español

Esta noche sumamos y restamos decimales. Lo importante es alinear los puntos decimales para que los mismos valores posicionales coincidan.

Cuando alineas los puntos decimales, las décimas se suman con décimas y las centésimas con centésimas. Si un número es más corto, agrega un cero al final para que cada lugar coincida.

Why This Matters / Por qué es importante

This skill supports everyday problem solving with money, measurements, games, planning, and checking whether an answer is reasonable.
Esta habilidad ayuda con dinero, medidas, juegos, planificación y con revisar si una respuesta es razonable.

Example from this lesson / Ejemplo de esta lección

Real example: the fuel tank has 128.75 liters and a shuttle adds 46.8 liters. Line up the points and add a zero: 46.80.

Ejemplo real: el tanque tiene 128.75 litros y un transbordador agrega 46.8 litros. Alinea los puntos y agrega un cero: 46.80.

Add: 128.75 + 46.80 = 175.55 liters.

Suma: 128.75 + 46.80 = 175.55 litros.

The thrusters used 19.35 liters, so subtract: 175.55 − 19.35 = 156.20 liters.

Los propulsores usaron 19.35 litros, así que resta: 175.55 − 19.35 = 156.20 litros.

How You Can Help At Home / Cómo puede ayudar en casa

Ask your student

  • Are the decimal points lined up in a straight line?
  • Does one number need a zero added so both have the same places?

Watch for: Listen for "valor posicional" — it means what a digit is worth based on its place, like tenths or hundredths.

Pregunte a su estudiante

  • ¿Están los puntos decimales alineados en línea recta?
  • ¿Necesita un número un cero agregado para que los dos tengan los mismos lugares?

Preste atención: Escucha "valor posicional" — significa lo que vale un dígito según su lugar, como décimas o centésimas.

Key Vocabulary / Vocabulario clave

Add and Subtract Decimals Sumar y restar decimales

Combine or find the difference between decimals by lining up equal place values.

Combinar o hallar la diferencia entre decimales alineando valores posicionales iguales.

Decimal Decimal

A number with a dot, like 0.5, that shows a part less than one.

Un número con un punto, como 0.5, que muestra una parte menor que uno.

Place value Valor posicional

What a digit is worth based on where it sits in a number.

Lo que vale un dígito según el lugar que ocupa en el número.

Tenths Décimas

The first spot after the decimal point. It shows parts out of 10.

El primer lugar después del punto decimal. Muestra partes de 10.

Hundredths Centésimas

The second spot after the decimal point. It shows parts out of 100.

El segundo lugar después del punto decimal. Muestra partes de 100.

Annex zeros Agregar ceros

Adding zeros at the end of a decimal so numbers line up evenly.

Agregar ceros al final de un decimal para que los números se alineen.

Try It Together / Inténtenlo juntos

Like adding fuel amounts on the station, add two simpler decimals: 12.45 + 7.8.

Como sumar cantidades de combustible en la estación, sumen dos decimales más simples: 12.45 + 7.8.

Let your child explain first, then open a hint. / Deje que su estudiante explique primero y después abra una pista.

  1. Write 7.8 with two decimal places by adding a zero: 7.80. Now both have two places.
    Escriban 7.8 con dos cifras decimales agregando un cero: 7.80. Ahora los dos tienen dos lugares.
    Show hint / Mostrar pista
    Adding a zero at the end does not change the value.
    Agregar un cero al final no cambia el valor.
  2. Line up the decimal points and add. What is the sum?
    Alineen los puntos decimales y sumen. ¿Cuál es la suma?
    Show hint / Mostrar pista
    12.45 + 7.80 = 20.25. Add the hundredths first, then tenths, then ones.
    12.45 + 7.80 = 20.25. Sumen primero las centésimas, luego las décimas, luego las unidades.
  3. Where does the decimal point go in the answer? Check that it lines up with the others.
    ¿Dónde va el punto decimal en la respuesta? Comprueben que quede alineado con los demás.
    Show hint / Mostrar pista
    Right below the other points: 20.25.
    Justo debajo de los otros puntos: 20.25.
