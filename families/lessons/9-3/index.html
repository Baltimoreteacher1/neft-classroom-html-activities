Unit 9: Two-Variable Relationships Lesson 9-3 6.AT.11

Write Equations to Represent Relationships Between Two Variables

Escribir ecuaciones que representen relaciones entre dos variables

I can write an equation from a table or a graph to model the relationship between the dependent and independent variables.

Speaking and writing goal: I can define the variables in my equation and explain what each part represents using the words equation, variable, and rate.

What Your Child Is Learning / Qué está aprendiendo su estudiante

English

Tonight we write an equation from a table or a graph, so two letters can describe the whole relationship.

When the total is a steady rate times an amount, write it as: dependent variable = rate × independent variable.

Español

Esta noche escribimos una ecuación a partir de una tabla o una gráfica, para que dos letras describan toda la relación.

Cuando el total es una tasa constante por una cantidad, escríbelo así: variable dependiente = tasa × variable independiente.

Why This Matters / Por qué es importante

Expressions and equations help students describe patterns and missing numbers. This matters for planning, budgeting, games, coding, and solving everyday questions step by step.
Las expresiones y ecuaciones ayudan a describir patrones y números desconocidos. Son útiles para planear, presupuestar y resolver problemas paso a paso.

Example from this lesson / Ejemplo de esta lección

Real example: a gym membership costs $24.95 each month. 1 month is $24.95, 2 months are $49.90, 3 months are $74.85.

Ejemplo real: una membresía del gimnasio cuesta $24.95 al mes. 1 mes son $24.95, 2 meses $49.90, 3 meses $74.85.

Each row adds the same amount, $24.95. That steady amount is the rate.

Cada fila suma la misma cantidad, $24.95. Esa cantidad constante es la tasa.

Define the variables: let m = number of months and c = total cost.

Definan las variables: sea m = cantidad de meses y c = costo total.

How You Can Help At Home / Cómo puede ayudar en casa

Ask your student

  • How much does the total change from one row to the next?
  • What should each letter stand for?

Watch for: Listen for "define the variables" (definir las variables) — saying what each letter stands for is required work.

Pregunte a su estudiante

  • ¿Cuánto cambia el total de una fila a la siguiente?
  • ¿Qué debe representar cada letra?

Preste atención: Escucha "definir las variables": decir qué representa cada letra es parte obligatoria del trabajo.

Key Vocabulary / Vocabulario clave

equation ecuación

A mathematical sentence with an equals sign that shows two amounts are the same.

Una oración matemática con un signo igual que muestra que dos cantidades son iguales.

variable variable

A letter that represents a quantity that can change, or vary.

Una letra que representa una cantidad que puede cambiar o variar.

rate tasa

A fixed amount of one quantity for every one unit of the other quantity.

Una cantidad fija de una cantidad por cada unidad de la otra cantidad.

represent representar

To show a relationship using a tool such as a table, a graph, or an equation.

Mostrar una relación usando una herramienta como una tabla, una gráfica o una ecuación.

define the variables definir las variables

To state exactly what quantity each letter in an equation stands for.

Decir exactamente qué cantidad representa cada letra de una ecuación.

Constant Constante

A number in an equation that never changes.

Un número en una ecuación que nunca cambia.

Try It Together / Inténtenlo juntos

A pizza costs $9. The table shows 1 pizza $9, 2 pizzas $18, 3 pizzas $27.

Una pizza cuesta $9. La tabla muestra 1 pizza $9, 2 pizzas $18, 3 pizzas $27.

Let your child explain first, then open a hint. / Deje que su estudiante explique primero y después abra una pista.

  1. What does each row add?
    ¿Qué suma cada fila?
    Show hint / Mostrar pista
    $9 — that is the rate.
    $9: esa es la tasa.
  2. Define the two variables.
    Definan las dos variables.
    Show hint / Mostrar pista
    Let p = number of pizzas, t = total cost.
    Sea p = cantidad de pizzas, t = costo total.
  3. Write and test the equation.
    Escriban y prueben la ecuación.
    Show hint / Mostrar pista
    t = 9p; check 9 × 3 = 27 ✓
    t = 9p; comprueben 9 × 3 = 27 ✓
