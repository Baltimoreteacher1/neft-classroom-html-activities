Student path

How MCAP practice works

Step 1

Choose a domain to practice

Pick the domain practice set that matches what you want to work on.

Step 2

Practice the questions

Work through each question and answer your best.

Step 3

Review the explanations

Read the explanation for every question so you understand the answer.

Step 4

Try a full-length practice test

When you feel ready, take a full-length test to check how you do.

Teacher guidance

For teachers

Have students complete the domain practice sets first, then the explanations for any questions they miss. Use the domain practice sets for targeted review of a single standard, and the full-length practice tests as readiness checks before the real MCAP. After each auto-graded test, review the domain breakdown together to see which standards need more support.
