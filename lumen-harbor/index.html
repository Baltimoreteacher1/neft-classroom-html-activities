EduWonderLab · Units 2–9

Lumen Harbor

A connected set of interactive graphic novels for Grade 6. The same crew follows a harbor that keeps trying to survive on a single careless number. Each chapter opens with a choice. Both paths rejoin before the math, so the decision changes the scene and still leaves every problem in front of you. Start any chapter. No account is required.
