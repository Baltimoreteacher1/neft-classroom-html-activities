# robots.txt — a mirror of isTeacherSurface() in functions/_lib/teacher-surface.js.
#
# The site is student-open. A small set of paths is teacher-only and answers an
# anonymous request with 401, so a crawler that requests one spends a crawl
# request to be refused and Search Console records the refusal. The rules below
# keep crawlers off exactly those paths.
#
# THIS FILE IS A MIRROR, SO IT MIRRORS THE PREDICATE'S SHAPE, NOT A GUESS AT IT.
# The predicate asks `p.includes("teacher")` — not "ends with notes-teacher.html"
# — and it is checked against any request path, HTML or not. An earlier version
# of this file listed .html suffixes (/*notes-teacher.html$ and friends), which
# left 814 teacher-gated PDFs, .docx and .csv files crawlable-but-refused: for
# example /lessons/1-1/downloads/1-1-notes-teacher.pdf, which 401s and which
# robots allowed. Match the substring, like the predicate does.
#
# ORDER AND LENGTH MATTER. Google resolves an Allow/Disallow conflict by the
# LONGEST matching pattern, not by file order, so the Allow rules that protect
# shared code have to be longer than the Disallow they override. "/assets/" (8
# characters) does NOT out-rank "/*teacher" (9), which is why the explicit
# /assets/*teacher and /data/*teacher rules below exist: the PUBLIC curriculum
# hub fetches /assets/curriculum-teacher-workflow.js and Googlebot renders the
# page with it. Blocking it degrades how the hub is indexed, for no benefit —
# the predicate itself exempts /assets/ and /data/ for this exact reason.
#
# npm run validate:seo checks both directions of this: every path the gate
# refuses must be disallowed here, and no publicly served file may be blocked.

User-agent: *

# Shared code and curriculum data: student-loaded, even when the filename names
# a teacher feature. These must out-rank the substring rules below.
Allow: /assets/
Allow: /data/
Allow: /assets/*teacher
Allow: /data/*teacher

# The three substrings the gate matches, anywhere in the path.
Disallow: /*teacher
Disallow: /*dashboard
Disallow: /*answer-key

# The three prefixes the gate matches. Prefixes, never substrings — "planning"
# as a substring would block lesson pages that merely mention it in a path.
Disallow: /curriculum/plan-notes
Disallow: /curriculum/planning
Disallow: /admin

Sitemap: https://eduwonderlab.com/sitemap.xml
