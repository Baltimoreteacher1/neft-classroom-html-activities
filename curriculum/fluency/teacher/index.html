How to use this guide

Check → Practice → Revisit
1

The day before · 1 minute

Open tomorrow's lesson and read the four skills it assumes. Note whether they come from elementary grades or from a lesson you already taught this year — that tells you where to pull a review from.

2

First two minutes of class

Project the quick check. Students answer on whiteboards. Three versions are provided so you can use a different one with each class, or re-check the same skill two days later.

3

Right after · decide

Open the answer notes. If most of the room missed it, run the short reteach before starting the lesson. If a few missed it, note them for small group. Open Worksheets & practice. Use Build foundations for support, Connect & apply for practice, or Extend & explain for a challenge. Revisit with another check next class.

Why this matters: when a student is still working out 7 × 8 or which side is the height, there is no attention left for the new idea. The check is not a quiz and it is not timed for speed — it tells you what to shore up before the lesson, while it is still cheap to fix.
