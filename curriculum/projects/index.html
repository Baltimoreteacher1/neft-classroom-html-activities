What do Flagship, Version, Stretch and Companion mean?
Flagship
Lead project of a current unit.
Version
Alternate version for the same current unit.
Stretch
Extension expedition a teacher assigns; the unit hub labels it stretch/extension.
Companion
Standalone project page outside the unit folders.
