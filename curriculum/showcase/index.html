Student work becomes the textbook

Student Work Gallery

Real Grade 6 mathematics work, shared with permission and read by a teacher before anyone else sees it, standing in as the real-world example for the standard it illustrates. Next year's class learns ratios from work this year's class made.

How work gets here — and how it leaves

  1. A teacher approves everything. A submission starts as pending and is invisible to everyone except a signed-in teacher. Nothing on this page was published automatically.
  2. Names are optional and limited. The default is anonymous (“A Grade 6 mathematician”). The most that can ever appear is a first name and a last initial, and only when a student explicitly chose that. Anything unclear is treated as anonymous.
  3. No photos, no files, no uploads. The gallery accepts a caption, a short written explanation, an optional link to a page already published on this site, and optional numbers — which this page draws as its own chart.
  4. A teacher can unpublish instantly. One click returns a piece of work to the pending queue or removes it, and it disappears from this page and from every lesson that shows it.
