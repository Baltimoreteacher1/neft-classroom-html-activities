🛡️ Honor Code Boundaries

🟢 Smart Tutor Use
  • "Explain how to divide fractions using a diagram."
  • "Give me a practice problem similar to x + 4 = 10."
  • "Explain what I did wrong in my homework step."
🔴 Avoid Short-Circuits
  • "Do my homework math for me."
  • "Give me the final answer to question 4."
  • Copy-pasting an entire test into the chat.
