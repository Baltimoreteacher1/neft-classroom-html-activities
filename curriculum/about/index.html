What a lesson looks like

Every core lesson moves through the same taught order: Vocabulary → Launch → Learn It → Explore → Practice → Connect. Each lesson pairs its math standard with a language objective, and supported (small-group) and catch-up versions of the lesson follow the same path.

Platform & learning supports

Classroom integrations

  • SCORM 1.2: lesson and homework packages that report scores to Canvas.
  • Common Cartridge: IMS Common Cartridge export for Canvas.
  • LTI 1.3: a tool for Deep Linking and grade passback is built but not yet registered with a district, so it is not in use.
  • Canvas package tools 🔒 Teacher sign-in

Universal Design for Learning

  • Engagement: review games, choice of practice, and cooperative class tasks.
  • Representation: interactive models such as NetFold 3D nets, and English and Spanish text.
  • Action & expression: the Math Workbench and written or spoken explanations.

Language development

  • Language objectives: one with every lesson.
  • English and Spanish: Spanish alongside lesson, homework, and family materials where available.
  • Vocabulary: each lesson's terms with definitions and examples.

Data & access

  • Local-first: progress stays on the device, with optional save-code recovery.
  • Data privacy guide — what each feature stores and shares.
  • Accessibility: keyboard navigation, readable type, and lesson supports.
