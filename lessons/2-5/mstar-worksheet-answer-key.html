MSTAR Practice Worksheet

Lesson 2-5: Describe Data by Range and Interquartile Range

Grade 6 Mathematics · Standard 6.DS.3

These are MSTAR-style questions written for this curriculum to rehearse the format. They are not official Maryland assessment items. MSTAR — Maryland's new state test, first given in spring 2027 — uses the same kinds of questions you see here: selected response, select-all, two-part evidence questions, and written responses.

Part A — Skills Check

One point each.

Question 1Selected response — correct: B

A data set runs from a least value of 12 to a greatest value of 30. What is the range?

  • A12
  • B18
  • C21
  • D30

Range = greatest − least = 30 − 12 = 18.

Question 2Selected response — correct: A

On a box plot, Q1 = 20 and Q3 = 36. What is the interquartile range?

  • A16
  • B28
  • C36
  • D56

IQR = Q3 − Q1 = 36 − 20 = 16.

Question 3Selected response — correct: A

Which measure of spread uses ONLY the middle half of the data?

  • AThe interquartile range
  • BThe range
  • CThe median
  • DThe mode

The IQR runs from Q1 to Q3, which is exactly the middle half of the values. The range uses every value, including the extremes.

Question 4Selected response — correct: C

Two classes both have a median score of 81. Class A's IQR is 13 and Class B's IQR is 8. Which statement is true?

  • AClass B has a higher median
  • BClass A has more students
  • CThe middle half of Class B's scores is less spread out
  • DClass B's highest score is greater

A smaller IQR means the middle half of the data is packed into a shorter stretch, so Class B's middle half varies less. The medians are equal, so nothing there separates them.

Question 5Selected response — correct: C

A box plot shows: least 68, Q1 75.5, median 83.5, Q3 88, greatest 94. What are the range and the IQR?

  • ARange 12.5, IQR 26
  • BRange 20, IQR 12.5
  • CRange 26, IQR 12.5
  • DRange 26, IQR 83.5

Range = 94 − 68 = 26. IQR = 88 − 75.5 = 12.5. The range covers the whole span; the IQR covers only the box.

Question 6Selected response — correct: B

Team A's salaries have a range of $14M and an IQR of $7M. Team B's have a range of $7M and an IQR of $2.5M. Both teams have the same median salary. What does this tell a player?

  • ATeam B pays more overall
  • BTeam B's salaries cluster much more tightly around the median
  • CTeam A has more players
  • DTeam B's highest salary is greater

Both measures of variation are smaller for Team B, so its salaries vary less: a typical player is more likely to earn close to the median. Team A spreads much wider in both directions.

Part B — Test-Format Questions

Scoring notes and distractor rationales below each item.

Question 7Two-part question

Part A — correct answer: B

Two classes have the same median score of 81. Class A scores range from 78 to 84; Class B scores range from 60 to 99. What does this tell you?

  • AClass B has a higher median.
  • BClass B has greater variability, even though the centers are the same.
  • CClass A has more students.
  • DThe two classes performed identically.

Class A's range is 84 − 78 = 6; Class B's is 99 − 60 = 39. Equal centers can hide very different spreads, which is what measures of variability reveal.

  • A: Both medians are 81, as the question states. What differs between the classes is how spread out the scores are.
  • C: Neither range tells you how many students there are. A range describes spread, not count.
  • D: The centers match, but Class A spans 6 points and Class B spans 39.

Part B — correct answer: D

Why is the IQR often preferred over the range as a measure of spread?

  • AThe IQR is always larger than the range.
  • BThe range cannot be calculated for large data sets.
  • CThe IQR uses every value in the data set.
  • DThe range depends on only two values and is strongly affected by an outlier.

The range uses only the minimum and the maximum, so one unusual value changes it completely. The IQR describes the middle 50% and is not moved by an extreme value.

Question 8Written response · 2 points

Type II Reasoning: Same Center, Different Spread

Lena compared two data sets. Both had a median of 50. She concluded: 'The two sets are the same because their medians match.'

Explain why Lena's conclusion may be wrong, and name a measure that would tell the sets apart.

Model answer: The median describes the center only. One set could be 48, 49, 50, 51, 52 and another 10, 30, 50, 70, 90 — same median, very different spread. Range, IQR, or MAD would distinguish them.

2 pointsStudent explains that the median describes CENTER only, that two sets with the same center can have very different spreads, and names range, IQR, or MAD as a measure of variability.
1 pointStudent says the sets may differ but does not name a measure of spread.
0 pointsStudent agrees with Lena or gives an unrelated response.

Part C — Show Your Thinking

Model answer and scoring guidance.

Question 9Written response · 2 points

Two students both scored 80 on a make-up test — one joins Class A (range 28, IQR 13) and one joins Class B (range 20, IQR 8). Both classes have a median of 81. Predict how each class's IQR changes, and explain your reasoning.

Model answer: Each new score of 80 lands just below the median of 81, which is inside the box for both classes. Adding a value inside the middle of the data pulls the quartiles slightly toward the center, so each IQR either stays the same or shrinks a little; neither can grow much, because nothing was added out at the extremes. The ranges do not change at all, since 80 is neither a new least nor a new greatest value for either class. The comparison holds: Class B's scores stay the more tightly clustered of the two.

Award 2 points for a complete explanation with correct mathematics, 1 point for a correct answer with thin reasoning, 0 for an unrelated response.
