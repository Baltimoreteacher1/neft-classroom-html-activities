  1. 1 MULTIPLE CHOICE

    Which inequality represents: 'The temperature is less than 40 degrees'?

    1. At < 40
    2. Bt > 40
    3. Ct ≤ 40
    4. Dt = 40

    💡 Solution Rationale: 'Less than' means <, so the inequality is t < 40.

    ⚠️ Watch for (Misconception): A common mistake in Write Inequalities is using a strict symbol (> or <) for a phrase that actually includes the boundary value. For 'the suspect is at least 18 years old,' students often write a > 18 instead of the correct a ≥ 18 — this wrongly excludes 18 itself, even though 'at least 18' means 18 counts as a match. The same error happens in reverse with 'at most': for 'the getaway bag holds at most 12 items,' students write n < 12 instead of n ≤ 12. Always ask: does the key phrase include the number ('at least,' 'at most,' 'no more than,' 'no fewer than' → use ≥ or ≤) or exclude it ('more than,' 'fewer than' → use > or <)?

SECTION 3 MATHEMATICAL WRITING & ERROR ANALYSIS [Reasoning & Critique]
  1. 6 ERROR ANALYSIS

    Spot the Detective's Mistake

    1. 1Clue:The witness says the suspect is at least 16 years old.
    2. 2Choose a variable:Let a stand for the suspect's age.
    3. 3Write the inequality:a > 16

    Which step contains the error? Explain the mathematical misconception and write the correct calculation below.

    Key Analysis: Mistake is in Step 3. Correct Work: 'At least 16' means 16 itself counts as meeting the clue, plus any age older than 16. The symbol > would leave out exactly 16, so the correct inequality is a ≥ 16, not a > 16.. Misconception: The inequality step used >, which shuts out a suspect who is exactly 16. "At least 16" means 16 counts as well as every older age, so the clue is a ≥ 16 — the bar under the symbol is what lets the boundary age in.

SECTION 3 MATHEMATICAL WRITING & ERROR ANALYSIS [Reasoning & Critique]
  1. 5 ERROR ANALYSIS

    Crack the Inequality Error

    1. 1Clue:The report says no fewer than 9 witnesses saw the suspect.
    2. 2Choose a variable:Let w stand for the number of witnesses.
    3. 3Write the inequality:w < 9

    Which step contains the error? Explain the mathematical misconception and write the correct calculation below.

    Key Analysis: Mistake is in Step 3. Correct Work: 'No fewer than 9' means the count cannot drop below 9 — 9 or more witnesses is required. That is w ≥ 9, not w < 9, which would only allow numbers below 9, the opposite of what the clue says.. Misconception: The inequality step pointed the symbol the wrong way. "No fewer than 9" means the count can never drop below 9, so 9 and every larger number works: w ≥ 9. The w < 9 that was written allows only counts under 9, which is the opposite of the clue.

SECTION 2 MATHEMATICAL WRITING & ERROR ANALYSIS [Reasoning & Critique]
  1. 2 ERROR ANALYSIS

    Find the Inequality Error

    1. 1Situation:No more than 25 students can join the field trip
    2. 2Identify key phrase:'No more than' means greater than
    3. 3Write inequality:s > 25

    Which step contains the error? Explain the mathematical misconception and write the correct calculation below.

    Key Analysis: Mistake is in Step 2. Correct Work: 'No more than' means less than or equal to (≤), not greater than. The correct inequality is s ≤ 25.. Misconception: The key-phrase step read "no more than" as greater than, but that phrase puts a cap on the group — the number of students can never go above 25. It means "at most," so the model is s ≤ 25, which allows 25 and every smaller count.
  2. 3 OPEN RESPONSE

    Write two different real-world situations: one that uses > and one that uses ≥. Explain why the situations need different symbols even though both mean 'bigger.'

    💡 Exemplar Response: Key Terms to Look For: greater than, at least, equal to, included, not included, boundary Explanation: The only difference between > and ≥ is whether the boundary number itself is allowed. A rule like "score more than 10 points to win" leaves 10 out, so it needs >, while "you must be at least 13 to watch" lets exactly 13 count, so it needs ≥. Testing the boundary number in your own situation is the quickest way to check which symbol fits.
