WordWhat it meansExample
Properties of Operations
Propiedades de las operaciones		Rules that let you reorder or regroup numbers without changing an expression's value.
Reglas que permiten reordenar o reagrupar números sin cambiar el valor de una expresión.		2 + 3 = 3 + 2 — Order changed, value kept.
Commutative Property
Propiedad conmutativa		You can change the order and get the same answer.
Puedes cambiar el orden y obtener la misma respuesta.		4 + 7 = 7 + 4 — Changing the order keeps the same sum.
Associative Property
Propiedad asociativa		You can change the grouping and get the same answer.
Puedes cambiar la agrupación y obtener la misma respuesta.		(2 × 3) × 4 = 2 × (3 × 4) — The grouping moved.
Identity Property
Propiedad de identidad		Adding 0 or multiplying by 1 keeps the same value.
Sumar 0 o multiplicar por 1 mantiene el mismo valor.		7 + 0 = 7 — Adding zero keeps the value.
Property
Propiedad		A rule that is always true in math.
Una regla que siempre es verdadera en matemáticas.		a(b + c) = ab + ac — True for every number.
Distributive Property
Propiedad distributiva		Multiplying a number by everything inside the parentheses: a(b + c) = ab + ac.
Multiplicar un número por todo lo que está dentro del paréntesis: a(b + c) = ab + ac.		3(2 + 6) = 3 × 2 + 3 × 6 — The 3 is multiplied by each number inside the parentheses.
Equivalent expressions
Expresiones equivalentes		Expressions that have the same value for every value of the variable.
Expresiones que tienen el mismo valor para todo valor de la variable.		3(4x + 1) + 2x and 14x + 3 — They give the same value for any x.
Expand
Desarrollar		Multiply out an expression to remove the parentheses.
Multiplicar una expresión para eliminar los paréntesis.		Rewriting 2(6x + 69) as 12x + 138 — The factor was multiplied through and the parentheses removed.
Factor an expression
Factorizar una expresión		Pull a shared factor outside parentheses.
Sacar un factor común fuera de los paréntesis.		Rewriting 16x + 160 as 16(x + 10) — The shared factor 16 was moved outside.

🚀 Launch

You're a band director arranging musicians on stage. You have 3 guitarists, 5 drummers, and 2 keyboard players. Whether you seat the guitarists first or the drummers first, you still have 3 + 5 + 2 = 10 musicians. The order you arrange them doesn't change the total!

What are the properties of operations?

Properties are math rules that are always true. The Commutative Property lets you change the order. The Associative Property lets you change the grouping (the parentheses).

Key idea: Properties of Operations. Formula: Commutative: a + b = b + a | Associative: (a + b) + c = a + (b + c). 1. Commutative Property: Order does not change sum or product. 2. Associative Property: Grouping does not change sum or product. 3. Identity Property: a + 0 = a; a · 1 = a

  • The Associative Property says grouping does not matter: (3 + 5) + 2 = 3 + (5 + 2), both equal 10.
