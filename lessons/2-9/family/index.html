The mean absolute deviation (MAD) tells how spread out the data is. Find the mean, find how far each number is from the mean, then find the average of those distances. A small MAD means the numbers are close together; a large MAD means they are spread out.

How we did it in class today

  1. My data set: 6, 8, 10, 12. First I find the mean: 6 + 8 + 10 + 12 = 36, then 36 ÷ 4 = 9. The mean is 9.
  2. Next I find each deviation (value − mean): 6−9 = −3, 8−9 = −1, 10−9 = 1, 12−9 = 3.
  3. Then I take the absolute value of each (the distance, never negative (zero is allowed)): 3, 1, 1, 3.
  4. Finally I average those distances: 3 + 1 + 1 + 3 = 8, then 8 ÷ 4 = 2. So the MAD = 2 points.

If they get stuck...

Watch out for this: A common mistake in Mean Absolute Deviation is adding the signed deviations (value − mean) instead of their absolute values, so the positives and negatives cancel out to 0. For 6, 8, 10, 12 (mean = 9), the deviations are −3, −1, 1, 3 — they sum to 0, but that is NOT the MAD. Before averaging, take the absolute value of every deviation so each becomes a nonnegative distance, including zero: |−3| = 3, |−1| = 1, |1| = 1, |3| = 3. Sum = 8, so MAD = 8 ÷ 4 = 2. A MAD of exactly 0 is a warning sign — it only happens if every value in the data set equals the mean.

Try asking: "Can you show me how you got that? Did we miss a step?"
