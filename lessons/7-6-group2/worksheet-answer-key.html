Lesson 7.67.6 Small Group · Group 2

Group 2 · Answer KeyChallenge practice

Learning target I can find the distance between two points on the coordinate plane using absolute value, explain why the method works, and use it on a problem I have not seen before.

  1. 1Complete each step, then write the final answer.

    Find the distance between (−7, −2) and (−1, −2).

    1. 1Which coordinate is the same? Which way does the line go?y = −2, so the line goes across.
    2. 2Are −7 and −1 on the same side of 0?Yes. Both are negative.
    3. 3Find the distance.6
    Final answer:The distance is 6 units. |−7| − |−1| = 7 − 1 = 6.
  2. 2Complete each step, then write the final answer.

    Find the distance between (1.5, −2.5) and (1.5, 4).

    1. 1Which coordinate is the same? Which way does the line go?x = 1.5, so the line goes up and down.
    2. 2Find the distance.6.5
    3. 3Why do we add 2.5 and 4 here, and not subtract?The points are on opposite sides of the x-axis. The path crosses 0, so both parts count.
    Final answer:The distance is 6.5 units. Opposite sides of 0 means add.
  3. 3Complete each step, then write the final answer.

    Find the distance between (−3.5, 1) and (2.25, 1).

    Final answer:5.75

    Why: Find the coordinate that is the same: y = 1 Find each distance from 0: |−3.5| = 3.5 → |2.25| = 2.25 Add the two distances: 3.5 + 2.25 = 5.75

  4. 4Complete each step, then write the final answer.

    Point P is at (−2, 5). Point Q has the same x-coordinate and is 8 units from P. Q is in Quadrant III. What is the y-coordinate of Q?

    Final answer:−3

    Why: Decide the direction from the quadrant: Quadrant III → y < 0 → down Move down 8 from y = 5: 5 − 8 = −3

  5. 5Complete each step, then write the final answer.

    A hiking map uses miles. The camp is at (−4.5, −2) and the lake is at (3, −2). How far is the camp from the lake?

    Final answer:7.5 miles

    Why: Find each distance from 0: |−4.5| = 4.5 → |3| = 3 Add, because 0 is between them: 4.5 + 3 = 7.5

  6. 6Complete each step, then write the final answer.

    Kim says the distance from (5, −4) to (5, 9) is 9 − 4 = 5. She always subtracts the distances from 0. What is the correct distance?

    Final answer:13

    Why: Check the signs of the y-values: −4 and 9 → opposite sides Add the distances from 0: 4 + 9 = 13
