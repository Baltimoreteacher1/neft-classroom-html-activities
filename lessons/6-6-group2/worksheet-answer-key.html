    Spot the Combining Mistake

    1. 1Expression7x + 3 + 2x
    2. 2CombineCombine every number you see: 7x + 2x + 3 = 9x + 3, then add the 9 and 3 too
    3. 3Result7x + 3 + 2x = 12x

    Which step has the mistake? Explain it and write the correct work.

    The mistake is in Step 2. Correct work: Only LIKE terms combine. 7x and 2x are like terms (7x + 2x = 9x), but the 3 is a constant and cannot be added to the 9x. The simplified form is 9x + 3. Check x = 2: 7(2) + 3 + 2(2) = 21 and 9(2) + 3 = 21, but 12(2) = 24 — so 12x is wrong. 7x and 2x are like terms, so 7x + 2x = 9x is fine — but the step keeps going and adds the 9 to the 3. A constant like 3 has no variable, so it cannot join 9x in one term. The simplified form is 9x + 3. Check with x = 2: 7(2) + 3 + 2(2) = 21 and 9(2) + 3 = 21, but 12(2) = 24.

  2. 2

    Find the Simplification Error

    1. 1Expression3x + 5 + 2x + 1
    2. 2Combine3x + 2x + 5 + 1
    3. 3Simplify5x² + 6

    Which step has the mistake? Explain it and write the correct work.

    The mistake is in Step 3. Correct work: 3x + 2x = 5x (NOT 5x²). When you combine like terms, you add the coefficients, not multiply them. The correct answer is 5x + 6. Rearranging to 3x + 2x + 5 + 1 is correct. The error is in the last step: combining like terms adds the COEFFICIENTS, so 3x + 2x = 5x, not 5x². The exponent never changes when you add like terms, so the answer is 5x + 6.

  4. 4

    Producer A wrote 2(x + 3) for a beat's cost. Which expression is equivalent?

    1. A2x + 6
    2. B2x + 3
    3. Cx + 6
    4. D2x + 5

    Distribute the 2 to each term inside: 2 · x + 2 · 3 = 2x + 6. Check x = 5: 2(5 + 3) = 16 and 2(5) + 6 = 16.

    Watch for: A common mistake in Equivalent Expressions is adding the exponents instead of the coefficients when combining like terms — writing 3x + 2x as 5x² instead of 5x. Remember: 3x means 3 groups of x and 2x means 2 more groups of x, so you add the coefficients (3 + 2 = 5) and keep the variable's power the same (x¹, not x²).

    Level 2 Extension — The False Remix

    1. 1Expression2x + 6
    2. 2Claim2x and 6 are like terms, so combine them
    3. 3Result2x + 6 = 8x

    Which step has the mistake? Explain it and write the correct work.

    The mistake is in Step 2. Correct work: 2x and 6 are NOT like terms — 2x has a variable and 6 is just a number, so they cannot be combined into one term. 2x + 6 is already simplified. You could rewrite it by factoring: 2x + 6 = 2(x + 3). Check x = 5: 2(5) + 6 = 16, but 8(5) = 40 — not equal, so 8x is wrong. 2x and 6 are NOT like terms — 2x carries a variable and 6 is just a number — so they cannot be merged into one term. 2x + 6 is already in simplest form; the only rewrite available is factoring: 2x + 6 = 2(x + 3). Testing x = 5 confirms it: 2(5) + 6 = 16, but 8(5) = 40.
