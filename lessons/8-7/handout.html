Equations and Inequalities Problem Solving

6.AT.8 · Unit 8 · Lesson 7

Name   Period

Objectives / Objetivos

Content Objective: I can model and solve real-world problems using equations and inequalities.

Language Objective: I can explain my reasoning using the words model, equation, inequality, and reasonableness.

Key Idea / Idea clave

Modeling Real-World Scenarios with Equations & Inequalities. 1. Define the variable and units in the scenario. 2. Look for keywords: 'equals/is' (=) vs 'at least/limit' (≥, ≤, >, <). 3. Write the algebraic model, solve with inverse operations, and check in context

I Notice / Observo

  • Which clue leads to an equation and which leads to an inequality?
  • What operation does 'divided equally among 4' suggest?

I Wonder / Me pregunto

  • How do you decide when to use an equation versus an inequality?
