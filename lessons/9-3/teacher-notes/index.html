Unit 9, Lesson 3: Write Equations to Represent Relationships Between Two Variables6.AT.11

Everything you need to teach this tomorrow. ~45 min.

Objectives

Content: I can write an equation from a table or a graph to model the relationship between the dependent and independent variables.

Language: I can define the variables in my equation and explain what each part represents using the words equation, variable, and rate.

Before class

  • Print / open: guided notes, homework, slides.
  • Have the family page link ready for absent students.
  • Preview the key vocabulary below before the lesson.

Warm-up

A canoe rents for $15 per hour. Which quantity is independent — hours or total cost?

Teaching notes

Key idea: Writing Two-Variable Equations. Formula: y = kx | Dependent = (Unit Rate) × Independent. 1. Identify the independent variable (x) and dependent variable (y). 2. Find the constant unit rate (k = y ÷ x). 3. Write the equation relating the two variables: y = kx (or y = x + c)

I do:

  1. The quantities are the number of months of membership and the total cost. The total cost depends on the number of months.
  2. In the table, each month adds $24.95: 1 month is $24.95, 2 months are $49.90, 3 months are $74.85.
  3. The pattern in words: the total cost is $24.95 times the number of months.
  4. Define the variables — let m = number of months and c = total cost in dollars — and write the equation: c = 24.95m.
  5. Now ANY number of months works: for 10 months, c = 24.95 × 10 = 249.50.

You do: For each situation below, say the pattern in words first: total = rate × amount. Then define your variables and write the equation.

Common misconception

Writing the equation with addition — c = 24.95 + m — instead of multiplication. The fee is charged EVERY month, so the total is the rate times the number of months; always test the equation against a row of the table.

Language & learning supports

  • Pre-teach: equation, variable, rate, represent, define the variables (Spanish + visuals are in the lesson vocabulary).
  • Offer the sentence frames: “I know ___ because ___.” “First, I ___. Then, I ___.” “The answer is ___, so ___.”
  • Chunk the I-do steps; let students restate each step to a partner before moving on.
  • Provide the worked example as a reference while they practice.

Exit ticket

Recreation World charges $24.95 per month. Let m = number of months and c = total cost. Which equation represents the relationship?

  • c = 24.95m ✓ correct
  • c = 24.95 + m
  • m = 24.95c
  • c = m ÷ 24.95

Each month costs $24.95, so the total cost is $24.95 multiplied by the number of months: c = 24.95m. Check: 2 months gives 24.95 × 2 = 49.90, which matches the table.

Reteach

Re-run the I-do example with smaller numbers and have students narrate each step using the key idea.

Extension

Diamond is considering using an online music service. She can either purchase songs one at a time or pay to stream songs. Each choice has its own relationship between the number of songs and the total cost.
