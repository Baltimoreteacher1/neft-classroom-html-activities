Example

  1. The quantities are the number of months of membership and the total cost. The total cost depends on the number of months.
  2. In the table, each month adds $24.95: 1 month is $24.95, 2 months are $49.90, 3 months are $74.85.
  3. The pattern in words: the total cost is $24.95 times the number of months.
  4. Define the variables — let m = number of months and c = total cost in dollars — and write the equation: c = 24.95m.
  5. Now ANY number of months works: for 10 months, c = 24.95 × 10 = 249.50.

Common mistake

Writing the equation with addition — c = 24.95 + m — instead of multiplication. The fee is charged EVERY month, so the total is the rate times the number of months; always test the equation against a row of the table.
