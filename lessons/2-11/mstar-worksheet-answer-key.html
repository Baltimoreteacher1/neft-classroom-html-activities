Question 1Two-part question

Part A — correct answer: C

Find 12.4 + 3.75.

  • A4.99
  • B15.15
  • C16.15
  • D16.79

Line up the decimal points and use a placeholder zero: 12.40 + 3.75 = 16.15.

  • A: That is 124 + 375 with the decimal points ignored. Line the points up first, then add.
  • B: The carry was dropped: 0.40 + 0.75 = 1.15, so a whole 1 carries into the ones place.
  • D: Write 12.40 so every column has a digit, then add the hundredths first: 0 + 5 = 5.

Part B — correct answer: C

Why is a placeholder zero written as 12.40 rather than leaving 12.4?

  • AIt changes the value of 12.4 to make the addition work.
  • BZeros must always be written at the end of a decimal.
  • CIt makes both numbers have the same number of decimal places so each column holds the same place value.
  • DIt rounds the answer to the nearest hundredth.

12.4 and 12.40 are equal in value. The zero simply fills the hundredths column so digits with the same place value line up in the same column.

Question 2Written response · 2 points

Type II Reasoning: Lining Up the Wrong Edge

Malik computed 9.6 + 0.45 by lining up the RIGHT-hand edges of the digits, as if adding whole numbers. He got 1.41.

Explain Malik's misconception and give the correct sum.

Model answer: 9.60 + 0.45 = 10.05. Decimals are lined up by the decimal point, not by the right edge, so that each column holds one place value. Estimation confirms it: 9.6 is nearly 10, so the sum must be just over 10.

2 pointsStudent explains that decimals are aligned by DECIMAL POINT so that tenths add to tenths and hundredths to hundredths, and computes 9.60 + 0.45 = 10.05.
1 pointStudent gives 10.05 without explaining place-value alignment.
0 pointsStudent agrees with Malik or gives an unrelated response.
