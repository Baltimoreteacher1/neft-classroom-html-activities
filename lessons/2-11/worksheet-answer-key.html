Lesson 2.11Add and Subtract Decimals

Version A · Answer KeySupported practice

Learning target I can add and subtract decimals by lining up the place values and the decimal points.

Start here pageNow you try — model solution

  1. Line up the points and add the hundredths, then tenths, then ones. What do we get? (12.45 + 7.80 = 20.25.)
  2. So the sum is 20.25. The points stay lined up in the answer.
Part 1Understand the ideamodels and meaning
  1. 1Mark and label each value on the number line.

    Show 6.5 − 2.8 and 3.25 + 1.5 on the number line

    Hint Each label shows an operation — work out the value first, then find that exact spot between the whole numbers.

    Answer: 6.5 − 2.8 at 3.7; 3.25 + 1.5 at 4.75

    Why: 6.5 − 2.8 = 3.7, so that mark sits between the 3.5 and 4 ticks. 3.25 + 1.5 = 4.75, which lands between the 4.5 and 5 ticks. Writing each pair with the decimal points lined up (6.50 − 2.80 and 3.25 + 1.50) keeps tenths under tenths and hundredths under hundredths, so every place is combined with its own place.

    What is 14.6 + 3.85?

    1. A17.45
    2. B18.35
    3. C18.45
    4. D18.55

    Hint Notice the mismatch: 14.6 has one decimal place but 3.85 has two. Lining up the POINTS is the whole trick here.

    Answer: C — 18.45

    Why: Line up decimals: 14.60 + 3.85. Hundredths: 0 + 5 = 5. Tenths: 6 + 8 = 14, write 4 carry 1. Ones: 4 + 3 + 1 = 8. Tens: 1. Answer: 18.45.

    Watch for: A common mistake in Add and Subtract Decimals is lining up the last digits (the right edges) of each number instead of lining up the decimal points — for example, adding 8.3 and 2.45 as if the 3 and the 5 belong in the same column. Before you add or subtract, add zeros so every number has the same number of decimal places (write 8.3 as 8.30), then check that the decimal points sit directly above one another.

    Spot the Mistake — Missing Annex Zero

    1. 1ProblemAdd 8.3 + 2.45
    2. 2Set upLined up the right edges so the 3 sits under the 5
    3. 3Add8.3 + 2.45 = 8.75
    4. 4Final answer8.75

    Hint Check the Set up step. Are the decimal points lined up, or just the last digits on the right?

    Mistake: Step 2. The Set up step is where it breaks. Lining up the right edges puts the 3 of 8.3 (a tenth) under the 5 of 2.45 (a hundredth), so the places no longer match. Annex a zero to get 8.30, line up the decimal points, and add: 0 + 5 = 5 hundredths, 3 + 4 = 7 tenths, 8 + 2 = 10 ones, giving 10.75 — not 8.75.

    Correct work: The student lined up the right edges instead of the decimal points. Annex a zero so 8.3 becomes 8.30, then line up the decimal points: 8.30 + 2.45. Hundredths: 0 + 5 = 5. Tenths: 3 + 4 = 7. Ones: 8 + 2 = 10, write 0 carry 1. Tens: 1. The correct sum is 10.75.

    Spot the Mistake — Subtracting Without a Placeholder

    1. 1ProblemSubtract 12.5 − 3.45
    2. 2Set upLeft 12.5 as one decimal place instead of annexing a zero
    3. 3Subtract12.5 − 3.45 = 9.5
    4. 4Final answer9.5

    Which step has the mistake? Explain what went wrong, then show the correct work.

    Mistake: Step 2. The Set up step is the problem: 12.5 was left with one decimal place while 3.45 has two, so the hundredths column had nothing to subtract from. Write 12.5 as 12.50 and subtract with the points aligned — 0 − 5 needs a borrow, giving 5 hundredths, then 4 − 4 = 0 tenths and 12 − 3 = 9 ones. The correct difference is 9.05, not 9.5.

    Correct work: The student did not annex a zero, so the hundredths place had nothing to subtract from. Write 12.5 as 12.50, then line up the decimal points: 12.50 − 3.45. Hundredths: 0 − 5 → borrow → 10 − 5 = 5. Tenths: 4 − 4 = 0 (after borrowing). Ones: 2 − 3 → borrow → 12 − 3 = 9. Tens: 0 (after borrowing). The correct difference is 9.05.
