🚀 Launch

The space station's main fuel tank reads 128.75 liters. A resupply shuttle delivers 46.8 liters of fuel, but the thrusters used 19.35 liters during docking. What is the fuel level after both events?

How do you add and subtract decimals?

A decimal is a number with a point that shows parts smaller than one whole. To add or subtract decimals, you line up the decimal points so the same place values match.

Key idea: Adding & Subtracting Decimals. 1. Line up the decimal points vertically by place value. 2. Insert placeholder zeros so each number has the same number of decimal digits. 3. Add or subtract right-to-left, regrouping as needed, and drop decimal straight down

Watch me

  • The tank has 128.75 liters. A shuttle adds 46.8 liters. I line up the decimal points and annex a zero: 46.80.
  • I add: 128.75 + 46.80 = 175.55 liters.
  • Now the thrusters use 19.35 liters, so I subtract: 175.55 − 19.35 = 156.20.
  • The final fuel level is 156.20 liters. I check with estimation: about 130 + 47 − 19 = 158, which is close, so my answer is reasonable.

Let's try together

  • Let's add 12.45 and 7.8. First, how do we write 7.8 with two decimal places? (7.80.)
  • Line up the points and add the hundredths, then tenths, then ones. What do we get? (12.45 + 7.80 = 20.25.)
  • So the sum is 20.25. The points stay lined up in the answer.

Now it's your turn

  • Next, you will use a number line to add and subtract decimals on your own.
  • Remember: line up the decimal points and add zeros so every place matches.
