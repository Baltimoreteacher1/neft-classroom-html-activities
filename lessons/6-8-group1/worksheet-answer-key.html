    Which property is shown? 5 + 13 = 13 + 5

    1. ACommutative Property
    2. BAssociative Property
    3. CIdentity Property
    4. DDistributive Property

    The order of the addends changed, so this is the Commutative Property of Addition.

    Watch for: A common mistake in Properties of Operations is applying the commutative property where it does not belong, or confusing it with the associative property. Students often assume 15 − 8 = 8 − 15 (it does not: 7 ≠ −7 — commutative only works for addition and multiplication), or they see parentheses move and call it "associative" even when the numbers inside just swapped places, like (2 + 3) + 4 = (3 + 2) + 4 (that is commutative — the order inside the parentheses changed, not the grouping). Before you label a property, ask: did only the order change (commutative), did only the grouping change (associative), or was a 0 or 1 involved (identity)?

    Spot the Common Mistake

    1. 1Statement4 + 0 = 4
    2. 2Student's labelThis shows the Commutative Property.
    3. 3ReasoningThe numbers 4 and 0 switched places, so it must be commutative.

    Which step has the mistake? Explain it and write the correct work.

    The mistake is in Step 2. Correct work: This is the Identity Property, not the Commutative Property. Adding 0 keeps the same value (4 + 0 = 4). The Commutative Property is about changing the ORDER of two different addends, like 4 + 7 = 7 + 4. Here nothing was reordered — a 0 was simply added, which does not change the number. The student's label is wrong: 4 + 0 = 4 shows the Identity Property, because adding 0 leaves the value unchanged. Nothing was reordered here — commutative would look like 4 + 7 = 7 + 4, with two different addends trading places.

  5. 5

    Level 2 Extension — Catch the Mislabeled Track

    1. 1Track3(a + b) = 3a + 3b
    2. 2Student's labelThis shows the Associative Property.
    3. 3ReasoningThere are parentheses, so the grouping must have changed.

    Which step has the mistake? Explain it and write the correct work.

    The mistake is in Step 2. Correct work: This track actually shows the Distributive Property, not the Associative Property. The 3 is multiplied across both terms inside the parentheses: 3 × a and 3 × b. Check with numbers a = 2, b = 6: 3(2 + 6) = 3 × 8 = 24, and 3 × 2 + 3 × 6 = 6 + 18 = 24. The Associative Property only changes grouping inside one operation, like (a + b) + c = a + (b + c). Distributive spreads a multiplier over a sum. Parentheses alone do not mean associative. In 3(a + b) = 3a + 3b the 3 gets multiplied by each term inside, which is the Distributive Property; testing a = 2 and b = 6 gives 3 × 8 = 24 and 6 + 18 = 24. Associative would only regroup one operation, like (a + b) + c = a + (b + c).

  6. 6

    Find the Property Error

    1. 1Statement15 − 8 = 8 − 15
    2. 2Student's claimThis shows the Commutative Property of Subtraction.
    3. 3ReasoningI switched the order, so it must be commutative.

    Which step has the mistake? Explain it and write the correct work.

    The mistake is in Step 2. Correct work: 15 − 8 = 7, but 8 − 15 = −7. These are NOT equal. The commutative property does NOT apply to subtraction. It only works for addition and multiplication. The claim fails as soon as you compute: 15 − 8 = 7 but 8 − 15 = −7, so the two sides are not equal and no property is being shown. The commutative property applies only to addition and multiplication, never to subtraction or division.
