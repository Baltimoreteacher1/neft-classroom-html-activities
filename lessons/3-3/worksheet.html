6.RP.3a Version A — Answer Key

Graph Ratio Tables

Answer Key

Name: Date:
  1. 1

    A ratio table shows (2, 6), (4, 12), and (6, 18). Which ordered pair comes next if the pattern continues?

    1. A(8, 24)
    2. B(7, 20)
    3. C(8, 22)
    4. D(10, 24)

    The pattern adds 2 to x and 6 to y each time. After (6, 18): x = 6+2 = 8, y = 18+6 = 24. The next point is (8, 24).

  2. 2

    When you graph equivalent ratios, the points will always form what shape?

    1. AA straight line through the origin
    2. BA curved line
    3. CA zigzag
    4. DA circle

    Equivalent ratios are proportional, so their graph is always a straight line that passes through the origin (0, 0).

  3. 3

    A ratio table shows (2, 8), (3, 12), and (5, 20). What is the y-value when x = 7?

    1. A28
    2. B24
    3. C21
    4. D35

    The ratio is y/x = 8/2 = 4. For every x, y = 4x. When x = 7: y = 4 × 7 = 28.

  4. 4

    Which point would NOT be on the graph of the ratio 1:5?

    1. A(3, 10)
    2. B(2, 10)
    3. C(4, 20)
    4. D(5, 25)

    For the ratio 1:5, every y-value should be 5 times the x-value. (3, 10): 5 × 3 = 15, not 10. So (3, 10) does not belong.

    Points from a ratio table are plotted at (1, 4), (2, 8), and (3, 12). What is the ratio of y to x for each point?

    1. A4:1
    2. B1:4
    3. C2:8
    4. D3:4

    For each point: 4÷1 = 4, 8÷2 = 4, 12÷3 = 4. The ratio of y to x is always 4:1.

    Two students graph ratio tables. Student A plots (1,2), (2,4), (3,6). Student B plots (1,3), (2,6), (3,9). Whose line is steeper?

    1. AStudent B
    2. BStudent A
    3. CSame steepness
    4. DCannot tell

    Student A's ratio is 1:2 (y goes up 2 for each 1 in x). Student B's ratio is 1:3 (y goes up 3 for each 1 in x). A higher rate of change means a steeper line, so Student B's is steeper.
