A statistical question is answered with data and anticipates variation. Read the question, identify what data you would collect, and make your choice before seeing an example.Una pregunta estadística se responde con datos y espera variación. Lee la pregunta, identifica qué datos recopilarías y elige antes de ver un ejemplo.

How many books are on this shelf right now?¿Cuántos libros hay en este estante ahora?

One shelf, at one moment. Count its books once.Un estante, en un momento. Cuenta sus libros una vez.

Example data: This shelf: 4 booksDatos de ejemplo: Este estante: 4 libros

This asks for one fixed count. We do not expect a set of varying answers to answer this question.Se pide una sola cantidad fija. No se espera un conjunto de respuestas variadas para responder esta pregunta.

How many books are on each shelf in this room?¿Cuántos libros hay en cada estante de este cuarto?

Several shelves. Collect one book count from each shelf.Varios estantes. Recopila una cantidad de libros de cada estante.

Example data: Shelf A: 4 · Shelf B: 7 · Shelf C: 10 booksDatos de ejemplo: Estante A: 4 · Estante B: 7 · Estante C: 10 libros

The book counts can vary from shelf to shelf. We collect a set of data to answer the question.Las cantidades de libros pueden variar de un estante a otro. Recopilamos un conjunto de datos para responder la pregunta.

How long does my bus trip take on different school days?¿Cuánto dura mi viaje en autobús en distintos días de clase?

The same trip, observed on several days. Collect one travel time per day.El mismo viaje, observado durante varios días. Recopila un tiempo de viaje por día.

Example data: Monday: 18 · Tuesday: 25 · Wednesday: 21 minutesDatos de ejemplo: Lunes: 18 · Martes: 25 · Miércoles: 21 minutos

Travel time can vary across days. A question about one person or one bus can be statistical when it asks about repeated observations.El tiempo de viaje puede variar entre días. Una pregunta sobre una persona o un autobús puede ser estadística si pide observaciones repetidas.

What is each student's favorite sport?¿Cuál es el deporte favorito de cada estudiante?

Several students. Collect one sport preference from each student.Varios estudiantes. Recopila el deporte preferido de cada estudiante.

Example data: Student A: soccer · Student B: basketball · Student C: swimmingDatos de ejemplo: Estudiante A: fútbol · Estudiante B: baloncesto · Estudiante C: natación

Preferences can vary. Statistical data can be categories, such as sports; the answers do not have to be numbers.Las preferencias pueden variar. Los datos estadísticos pueden ser categorías, como deportes; las respuestas no tienen que ser números.

How many days are in each calendar week?¿Cuántos días tiene cada semana del calendario?

Calendar weeks all have a fixed length of seven days.Todas las semanas del calendario tienen una duración fija de siete días.

Example data: Week A: 7 · Week B: 7 · Week C: 7 daysDatos de ejemplo: Semana A: 7 · Semana B: 7 · Semana C: 7 días

The word 'each' is not enough. A calendar week always has seven days, so this question does not anticipate variation.La palabra «cada» no basta. Una semana del calendario siempre tiene siete días, así que esta pregunta no espera variación.

How many pets does each student in our class have?¿Cuántas mascotas tiene cada estudiante de nuestra clase?

Survey the class. Pet counts can vary, even if the first few answers match.Encuesta a la clase. Las cantidades de mascotas pueden variar, aunque las primeras respuestas coincidan.

Example data: First three students: 0, 0, 0 petsDatos de ejemplo: Primeros tres estudiantes: 0, 0, 0 mascotas

We anticipate variation before collecting the data. Matching answers in a small sample do not make the question non-statistical.Esperamos variación antes de recopilar los datos. Respuestas iguales en una muestra pequeña no hacen que la pregunta deje de ser estadística.

Watch for these (3)Ten en cuenta (3)
  • 👀

    A statistical question asks for data that are expected to vary. Observations can come from different people or from the same person on different days.

    Una pregunta estadística pide datos que se espera que varíen. Las observaciones pueden venir de distintas personas o de la misma persona en distintos días.

  • 💬

    The answers can be categories, such as favorite sports. They do not have to be numbers.

    Las respuestas pueden ser categorías, como deportes favoritos. No tienen que ser números.

  • ✋

    The word “each” alone does not make a question statistical. Matching observed answers do not rule out a statistical question if variation was expected.

    La palabra «cada» por sí sola no hace estadística una pregunta. Respuestas observadas iguales no descartan una pregunta estadística si se esperaba variación.
