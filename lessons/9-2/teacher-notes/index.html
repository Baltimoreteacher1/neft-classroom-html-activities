Warm-up

The tram travels 1,200 feet every minute. Which quantity is independent — time or distance?

Teaching notes

Key idea: Each row of the table becomes one ordered pair — (independent variable, dependent variable) — plotted as one point on the graph.

I do:

  1. Each ticket costs $45, so the total cost is 45 times the number of tickets: 1 ticket is $45, 2 tickets are $90, 3 tickets are $135.
  2. The number of tickets is the independent variable, so it goes first in each ordered pair: (1, 45), (2, 90), (3, 135).
  3. I label one axis 'Number of tickets' and the other 'Total cost ($)', then plot each pair as a point.
  4. The points rise to the right: as the number of tickets increases, the total cost increases.

You do: For each situation below, decide what one point on the graph represents. Say it as a sentence: 'The point (___, ___) means ___ .'

Common misconception

Reversing the coordinates of a point — writing (cost, tickets) instead of (tickets, cost). The independent variable always comes first in the ordered pair.

ESOL / SPED supports

  • Pre-teach: graph, table of values, ordered pair, axis, coordinates (Spanish + visuals are in the lesson vocabulary).
  • Offer the sentence frames: “I know ___ because ___.” “First, I ___. Then, I ___.” “The answer is ___, so ___.”
  • Chunk the I-do steps; let students restate each step to a partner before moving on.
  • Provide the worked example as a reference while they practice.

Exit ticket

On the football ticket graph, what does the point (3, 135) represent?

  • 3 tickets cost a total of $135 ✓ correct
  • 135 tickets cost a total of $3
  • 3 tickets cost $135 each
  • The game lasts 135 minutes

The independent variable — number of tickets — comes first in the ordered pair, and 3 × $45 = $135, so the point pairs 3 tickets with a total cost of $135.

Reteach

Re-run the I-do example with smaller numbers and have students narrate each step using the key idea.

Extension

Nakai opened a savings account with an initial deposit, or principal, of $750. The account earns 3.5% simple interest each year — interest is the amount earned for the use of the principal. A graph shows the interest Nakai has earned over a period of years, with points rising steadily.
