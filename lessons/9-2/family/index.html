Unit 9, Lesson 2: Analyze Graphs of Relationships Between Two Variables6.AT.11

A quick guide for families and for any student who missed class.

What students are learning

A table shows a relationship with numbers. A graph shows the same relationship with points. Reading either one tells you how the dependent variable responds to the independent variable.

Key idea: Representing Two-Variable Relationships with Tables & Graphs. Formula: Table (x, y) → Graph Point (x, y). 1. Construct table: Put independent variable in column 1 (x) and dependent in column 2 (y). 2. Identify the rate of change or rule connecting x to y. 3. Plot the ordered pairs on the coordinate plane with x on horizontal axis and y on vertical

Key words

  • graph — A picture on a coordinate plane that shows how two quantities are related.
    Español: gráfica — Un dibujo en un plano de coordenadas que muestra cómo se relacionan dos cantidades.
  • table of values — A list of matched pairs of values that shows a relationship using numbers.
    Español: tabla de valores — Una lista de pares de valores que muestra una relación usando números.
  • ordered pair — Two numbers written as (x, y) that name one point on a graph. The independent variable comes first.
    Español: par ordenado — Dos números escritos como (x, y) que nombran un punto en la gráfica. La variable independiente va primero.
  • axis — One of the two number lines that frame a graph. Each axis is labeled with a quantity from the problem.
    Español: eje — Una de las dos rectas numéricas que enmarcan una gráfica. Cada eje se rotula con una cantidad del problema.
  • coordinates — The numbers in an ordered pair that tell how far to move along each axis to reach a point.
    Español: coordenadas — Los números de un par ordenado que indican cuánto avanzar por cada eje para llegar a un punto.

Example

  1. Each ticket costs $45, so the total cost is 45 times the number of tickets: 1 ticket is $45, 2 tickets are $90, 3 tickets are $135.
  2. The number of tickets is the independent variable, so it goes first in each ordered pair: (1, 45), (2, 90), (3, 135).
  3. I label one axis 'Number of tickets' and the other 'Total cost ($)', then plot each pair as a point.
  4. The points rise to the right: as the number of tickets increases, the total cost increases.

Answer check

  1. On the football ticket graph, what does the point (3, 135) represent? → 3 tickets cost a total of $135

Common mistake

Reversing the coordinates of a point — writing (cost, tickets) instead of (tickets, cost). The independent variable always comes first in the ordered pair.

How families can help at home

  • Have them say why each step works, not just the answer.
