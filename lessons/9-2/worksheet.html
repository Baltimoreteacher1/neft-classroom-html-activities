6.NS.7 Version A — Answer Key

Integers and Absolute Value

Answer Key

Name: Date:
  1. 1

    What is the absolute value of -9?

    1. A9
    2. B-9
    3. C0
    4. D1

    Absolute value is the distance from zero. -9 is 9 units from zero, so |-9| = 9.

  2. 2

    Which integer has the GREATEST absolute value: -3, 7, -5, 2?

    1. A7
    2. B-5
    3. C-3
    4. D2

    |-3| = 3, |7| = 7, |-5| = 5, |2| = 2. The greatest absolute value is 7.

  3. 3

    What is |0|?

    1. A0
    2. B1
    3. C-1
    4. DThere is no answer

    Zero is 0 units from itself on the number line, so |0| = 0.
