  1. 1

    A gym charges $24.95 per month. Which pair correctly names the variables?

    1. AIndependent: months; Dependent: total cost
    2. BIndependent: total cost; Dependent: months
    3. CIndependent: $24.95; Dependent: months
    4. DIndependent: months; Dependent: $24.95

    You choose how many months to stay a member. The total cost responds to that.

    Watch for: Naming the variables backward — calling the responding quantity 'independent' because it is the one the question asks about.

  2. 2

    Which of these pairs is NOT a dependent relationship?

    1. ANumber of pizzas sold and number of employees the shop has
    2. BNumber of pizzas sold and weekly cost of cheese
    3. CHours jogged and Calories burned
    4. DTickets bought and total cost

    The shop has 6 employees whether it sells 5 pizzas or 500. That count does not respond to pizza sales.

    Watch for: Naming the variables backward — calling the responding quantity 'independent' because it is the one the question asks about.

  3. 3

    Which question would you ask to find the DEPENDENT variable?

    1. AWhich quantity responds when the other one changes?
    2. BWhich quantity is larger?
    3. CWhich quantity has units?
    4. DWhich quantity comes first alphabetically?

    The dependent variable is defined by its response to the independent variable — not by size, units, or name.

    Watch for: Naming the variables backward — calling the responding quantity 'independent' because it is the one the question asks about.

  4. 4

    Claire decides to walk instead of jog for the same 30 minutes. What happens to the two variables?

    1. ATime stays the independent variable; Calories burned still depends on it
    2. BCalories burned becomes the independent variable
    3. CNeither is a variable any more
    4. DTime becomes the dependent variable

    Changing the activity changes how many Calories each minute burns, but time is still the quantity she chooses.

    Watch for: Naming the variables backward — calling the responding quantity 'independent' because it is the one the question asks about.

  1. 1

    If Claire runs exactly 3 miles and records how long it takes, which is the independent variable now?

    1. ADistance (3 miles)
    2. BTime it takes
    3. CHer speed
    4. DCalories burned

    This time she fixes the distance by choice and the time is whatever results, so distance is independent and time is dependent.

    Watch for: Naming the variables backward — calling the responding quantity 'independent' because it is the one the question asks about.

  2. 2

    Two quantities are related. Which statement is ALWAYS true?

    1. AThe independent variable is subject to choice
    2. BThe independent variable is always the larger number
    3. CThe dependent variable is always measured in dollars
    4. DThe independent variable is always listed first in a table

    Being subject to choice is the definition. Size, units, and table position are not part of it.

    Watch for: Naming the variables backward — calling the responding quantity 'independent' because it is the one the question asks about.

  3. 3

    Which relationship is NOT a case of one quantity depending on the other?

    1. AA student's height and their house number
    2. BHours studied and quiz score
    3. CMinutes jogged and Calories burned
    4. DPizzas made and cheese used

    A house number is assigned by an address, not by how tall someone is — the two are unrelated.

    Watch for: Naming the variables backward — calling the responding quantity 'independent' because it is the one the question asks about.

    Write the relationship as a sentence: a printer prints 12 pages per minute.

    1. APages printed depends on minutes running
    2. BMinutes running depends on pages printed
    3. C12 depends on the number of pages
    4. DThe printer depends on the pages

    You choose how long to let it run; the number of pages is the result of that choice.

    Watch for: Naming the variables backward — calling the responding quantity 'independent' because it is the one the question asks about.

  6. 6

    Claim: “The dependent variable always has the larger values.” Is this claim always, sometimes, or never true?

    1. ASometimes — the size of the numbers has nothing to do with which variable is which
    2. BAlways — the dependent variable is the result, so it is bigger
    3. CNever — the independent variable is always the larger one
    4. DOnly when both quantities are measured in the same unit

    Sometimes. Jog for 90 minutes and you might run 9 miles — the dependent value (9) is smaller. Give a plant 3 hours of sunlight and it might reach 12 cm — the dependent value (12) is larger. The role is decided by which quantity is subject to choice, not by which numbers are bigger.

    Watch for: Naming the variables backward — calling the responding quantity 'independent' because it is the one the question asks about.
