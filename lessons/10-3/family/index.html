Vocabulary you might hear

  • puzzle — A problem designed to be played with — it has rules, a goal, and room to imagine solutions.
    Español: rompecabezas — Un problema diseñado para jugarse: tiene reglas, una meta y espacio para imaginar soluciones.
  • pattern — Something that repeats or changes in a predictable way.
    Español: patrón — Algo que se repite o cambia de una manera predecible.
  • pattern rule — A rule that tells you how to get the next value in a pattern from the one before it.
    Español: regla del patrón — Una regla que te dice cómo obtener el siguiente valor de un patrón a partir del anterior.
  • predict — To say what will happen before it happens, using a pattern or reasoning.
    Español: predecir — Decir lo que va a pasar antes de que pase, usando un patrón o el razonamiento.
  • organize — To arrange information — often in a table — so patterns become easier to see.
    Español: organizar — Ordenar la información, muchas veces en una tabla, para que los patrones sean más fáciles de ver.

How we did it in class today

  1. Before moving anything, I describe what the solved puzzle will look like: the discs in the same order — smallest on top to largest on bottom — but on a different rod.
  2. Then I play the small cases: a one-disc tower takes 1 move, and a two-disc tower takes 3 moves.
  3. A three-disc tower takes at least 7 moves. Small cases are how mathematicians play.

If they get stuck...

Watch out for this: Doubling the previous number of steps but forgetting to add 1 — answering 14 instead of 15 for four discs, or 30 instead of 31 for five.

Try asking: "Can you show me how you got that? Did we miss a step?"
