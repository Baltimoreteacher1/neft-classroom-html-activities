Unit 2, Lesson 8: Describe Data Using the Mean6.DS.4

A quick guide for families and for any student who missed class.

What students are learning

The mean, or average, is a measure of center that describes a whole data set with one number. It is what every value would be if the total were leveled out and shared equally.

Key idea: Mean = total of all the values ÷ how many values there are.

Key words

  • Mean — The average of a data set. Add all the values, then divide by how many values there are.
    Español: Media — El promedio de un conjunto de datos. Suma todos los valores y divide entre cuántos valores hay.
  • Average — Another word for the mean — the amount each value would be if the total were shared equally.
    Español: Promedio — Otra palabra para la media: la cantidad que tendría cada valor si el total se repartiera en partes iguales.
  • Measure of center — A single number used to describe the middle, or typical value, of a whole data set.
    Español: Medida de centro — Un solo número que se usa para describir el centro, o valor típico, de todo un conjunto de datos.
  • Balance point — The value where the total distance of the data above it equals the total distance below it. The mean is the balance point.
    Español: Punto de equilibrio — El valor donde la distancia total de los datos por encima es igual a la distancia total por debajo. La media es el punto de equilibrio.
  • Data set — The whole collection of values that were gathered or measured.
    Español: Conjunto de datos — Toda la colección de valores que se recopilaron o midieron.

Example

  1. Miguel's 4 days of earnings are shown with counters. When I combine all of the counters, there are 60 of them, which means Miguel earned $60 in all.
  2. Now I redistribute the 60 counters equally among the 4 days. Each of the 4 groups ends up with 15 counters.
  3. The arithmetic does exactly the same thing: I find the total, 60, and divide it by the number of days, 4. So 60 ÷ 4 = 15.
  4. We can use $15 to describe Miguel's typical daily earnings. That leveled value is the mean.

Common mistake

The most common mistake with the mean is adding correctly and then dividing by the wrong number — or not dividing at all. Students report the total (for 8, 10, 6, 12 they say the mean is 36) or they divide by a count that does not match the data, such as dividing a 4-value total by 5, or skipping a zero when counting the values. Before you finish, do two things: count the values in the data set out loud, and check that your mean lands between the smallest and largest value. A mean of 36 for data that never goes above 12 is impossible.
