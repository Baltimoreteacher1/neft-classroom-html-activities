# Unit Rate Market

An offline-friendly, single-page best-buy simulator for teaching the complete unit-rate process:

1. Read a comparison-shopping problem.
2. Write each rate as a fraction.
3. Interpret the fraction bar as division.
4. Calculate and label each unit rate.
5. Use the unit rates as evidence to identify the best buy.

## Open

Double-click `index.html`, or serve the folder locally:

```bash
python3 -m http.server 4173
```

Then open `http://localhost:4173`.

The simulator includes six product aisles, twelve ready-made problems, Learn/Practice/Challenge modes, hints, read-aloud support, a custom problem builder, progress memory, responsive layouts, and keyboard-accessible controls.
