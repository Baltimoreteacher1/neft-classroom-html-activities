Understand Equations and Their Solutions

6.AT.8 · Unit 8 · Lesson 1

Name   Period

Objectives / Objetivos

Content Objective: I can write an equation for a real situation and check whether a given value is a solution by substituting it.

Language Objective: I can explain a solution using the words substitute, solution, true, and equal sign.

Key Idea / Idea clave

Equations & Solutions. Formula: Left Expression = Right Expression. 1. An equation is a mathematical sentence stating two expressions are equal. 2. A solution is a value for the variable that makes the equation true. 3. Check: Substitute the value into the equation and verify that both sides balance

I Notice / Observo

  • What quantity is unknown in this situation?
  • What does 'plus 8 more' tell you about the operation?

I Wonder / Me pregunto

  • What if the clue said 'twice a number equals 20' instead?
