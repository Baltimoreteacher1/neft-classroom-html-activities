How we did it in class today

  1. Clue: 'A number of stolen gems plus 8 more equals 20 total.'
  2. The unknown is the number of gems. I let n stand for it.
  3. 'Plus 8 more' means + 8. 'Equals 20 total' means = 20.
  4. So my equation is n + 8 = 20.

Pick one question to talk about. You don't need to do them all!

Which value is the solution of k + 7 = 15, and how do you know?

  1. k = 22, because 15 + 7 = 22
  2. k = 7, because 7 appears in the equation
  3. k = 8, because 8 + 7 = 15 is true
  4. k = 9, because 9 is close to 8
Check the answer

The answer is: k = 8, because 8 + 7 = 15 is true

If they get stuck...

Watch out for this: A common mistake in Write Equations is writing subtraction and division clues in the wrong order — putting the number from the clue first instead of the variable first. For 'a number decreased by 8 equals 5,' students often write 8 − n = 5 instead of the correct n − 8 = 5; for 'a number divided by 4 equals 6,' they write 4 ÷ n (or 4n) instead of n / 4 = 6. Always start with the variable, then attach the operation in the order the words describe it, and check by substituting your answer back in.

Try asking: "Can you show me how you got that? Did we miss a step?"
