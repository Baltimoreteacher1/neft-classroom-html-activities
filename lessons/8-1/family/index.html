Unit 8, Lesson 1: Understand Equations and Their Solutions6.AT.8

A quick guide for families and for any student who missed class.

What students are learning

An equation is a math sentence with an equal sign (=). To write one, I pick a letter (a variable) for the unknown number and match the words to math symbols.

Key idea: Equations & Solutions. Formula: Left Expression = Right Expression. 1. An equation is a mathematical sentence stating two expressions are equal. 2. A solution is a value for the variable that makes the equation true. 3. Check: Substitute the value into the equation and verify that both sides balance

Key words

  • Write Equations — Represent a relationship with expressions joined by an equal sign.
    Español: Escribir ecuaciones — Representar una relación con expresiones unidas por un signo igual.
  • Equation — A math sentence with an equal sign showing both sides are the same.
    Español: Ecuación — Una oración matemática con un signo igual que muestra que ambos lados son iguales.
  • Variable — A letter that stands for a number that is unknown or can change.
    Español: Variable — Una letra que representa un número desconocido o que puede cambiar.
  • Equal sign — The = sign, showing both sides are the same.
    Español: Signo igual — El signo =, que muestra que ambos lados son iguales.
  • Expression — A math phrase with numbers and letters, but no equal sign.
    Español: Expresión — Una frase matemática con números y letras, pero sin signo igual.
  • Constant — A fixed number in an expression or equation that does not change.
    Español: Constante — Un número fijo en una expresión o ecuación que no cambia.
  • Unknown — The value you are trying to find, usually shown with a variable.
    Español: Incógnita — El valor que intentas encontrar, mostrado normalmente con una variable.
  • Solution — A value that makes an equation true when it is substituted for the variable.
    Español: Solución — Un valor que hace verdadera una ecuación cuando se sustituye por la variable.
  • Substitute — To replace a variable with a number so the equation can be checked.
    Español: Sustituir — Reemplazar una variable por un número para poder comprobar la ecuación.

Example

  1. Clue: 'A number of stolen gems plus 8 more equals 20 total.'
  2. The unknown is the number of gems. I let n stand for it.
  3. 'Plus 8 more' means + 8. 'Equals 20 total' means = 20.
  4. So my equation is n + 8 = 20.

Common mistake

A common mistake in Write Equations is writing subtraction and division clues in the wrong order — putting the number from the clue first instead of the variable first. For 'a number decreased by 8 equals 5,' students often write 8 − n = 5 instead of the correct n − 8 = 5; for 'a number divided by 4 equals 6,' they write 4 ÷ n (or 4n) instead of n / 4 = 6. Always start with the variable, then attach the operation in the order the words describe it, and check by substituting your answer back in.
