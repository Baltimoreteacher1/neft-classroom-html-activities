      Answer Key

      Name: Date:
      1. 1

        A histogram shows these frequencies: 0–4: 3 players, 5–9: 8 players, 10–14: 12 players, 15–19: 5 players. How many players are represented in total?

        1. A28
        2. B12
        3. C20
        4. D15

        Add all frequencies: 3 + 8 + 12 + 5 = 28 players.

      2. 2

        In a histogram, what does the height of each bar represent?

        1. AThe frequency (count) of data in that interval
        2. BThe average of the data in that interval
        3. CThe range of the interval
        4. DThe median of the data

        Each bar's height shows the frequency — how many data values fall within that interval.

      3. 3

        How is a histogram different from a regular bar graph?

        1. AHistogram bars touch (no gaps) because the intervals are continuous ranges
        2. BHistograms use colors and bar graphs don't
        3. CBar graphs show numbers and histograms show words
        4. DThere is no difference

        In a histogram, bars touch because each interval connects to the next (0–9, 10–19, etc.) — the data is continuous.

      4. 4

        A histogram has intervals: 0–4, 5–9, 10–14, 15–19. What is the width of each interval?

        1. A5
        2. B4
        3. C10
        4. D19

        Each interval covers 5 values (0,1,2,3,4 then 5,6,7,8,9 etc.), so the width is 5.
