Statistical Questions and Data

6.DS.1 · Unit 8 · Lesson 1

Name   Period

Objectives / Objetivos

Content Objective: I can tell the difference between a statistical question and a non-statistical question.

Language Objective: I can explain my reasoning using the words statistical question, data, variability, and survey.

Key Idea / Idea clave

If you expect the answers to vary, it is a statistical question.

I Notice / Observo

  • Which questions could have many different answers?
  • Which questions have only one exact answer?

I Wonder / Me pregunto

  • Why would a coach care about questions with variability?

Vocabulary / Vocabulario

Term / TérminoDefinition / Definición
Statistical Question
Pregunta estadística		A question where the answers will be different for different people.
Una pregunta cuyas respuestas serán distintas para distintas personas.
Data
Datos		Facts and numbers you collect, like answers to a survey.
Datos y números que recoges, como respuestas a una encuesta.
Variability
Variabilidad		How spread out the numbers are.
Qué tan separados están los números.
Survey
Encuesta		Collecting facts by asking people questions.
Recoger datos haciendo preguntas a las personas.
Data distribution
Distribución de datos		How the data looks: where it sits and how spread out it is.
Cómo se ven los datos: dónde están y qué tan separados están.

Practice Preview / Vista previa de práctica

  1. Which of the following is a statistical question?
    1. How many points did each player score this season?
    2. How many points are scored for a free throw?
    3. What sport does this team play?
    4. How many halves are in a soccer game?
  2. A coach asks: "How many hours does each athlete on the track team sleep the night before a meet?" Why is this a statistical question?
    1. Because the answers will vary from athlete to athlete
    2. Because it is about sports
    3. Because it has a numerical answer
    4. Because the coach asked it
  3. Decide if each question is statistical and explain why.
  4. Find the Reasoning Error
