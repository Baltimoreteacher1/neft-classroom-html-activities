Explore Relationships Between Two Variables

6.AT.11 · Unit 9 · Lesson 1

Name   Period

Objectives / Objetivos

Content Objective: I can recognize when two quantities change together, and identify which one is the independent variable and which is the dependent variable.

Language Objective: I can explain which quantity depends on the other using the words independent variable, dependent variable, and depends on.

Key Idea / Idea clave

The independent variable is subject to choice. The dependent variable changes in response to it.

Vocabulary / Vocabulario

Term / TérminoDefinition / Definición
independent variable
variable independiente		The quantity that is subject to choice. It does not depend on the other quantity.
La cantidad que se elige. No depende de la otra cantidad.
dependent variable
variable dependiente		The quantity that changes in response to the independent variable.
La cantidad que cambia en respuesta a la variable independiente.
depends on
depende de		One quantity depends on another when changing the first causes the second to change.
Una cantidad depende de otra cuando cambiar la primera hace cambiar la segunda.
quantity
cantidad		Something that can be counted or measured.
Algo que se puede contar o medir.
relationship
relación		How two quantities change together.
Cómo dos cantidades cambian juntas.

Practice Preview / Vista previa de práctica

  1. Akela chooses how many hours of sunlight each tray gets. Which is the INDEPENDENT variable?
    1. Hours of sunlight
    2. Plant height
    3. Number of trays
    4. Number of seeds
  2. A gym charges $24.95 per month. Which pair correctly names the variables?
    1. Independent: months; Dependent: total cost
    2. Independent: total cost; Dependent: months
    3. Independent: $24.95; Dependent: months
    4. Independent: months; Dependent: $24.95
  3. Claire jogs 30 minutes and burns 123 Calories. At the same rate, how many Calories would a 90-minute jog burn?
    1. 369
    2. 246
    3. 410
    4. 300
  4. Two quantities are related. Which statement is ALWAYS true?
    1. The independent variable is subject to choice
    2. The independent variable is always the larger number
    3. The dependent variable is always measured in dollars
    4. The independent variable is always listed first in a table
