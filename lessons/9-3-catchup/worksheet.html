    (Lesson 9.1) Which ordered pair names a point 3 units right and 7 units up from the origin?

    1. A(3, 7)
    2. B(7, 3)
    3. C(3, 3)
    4. D(0, 7)

    The first coordinate is horizontal (right 3), the second is vertical (up 7). So (3, 7).

    Watch for: A common mistake in Compare and Order Integers is thinking that a negative number with a bigger digit is the bigger value — for example, believing -15 is greater than -8 because 15 is greater than 8. It's the opposite for negatives: the number farther to the left on the number line (farther from zero) is always the LESSER value, so -15 < -8.
