🎯 The big ideaLa idea principal

In one sentence: To test a value, substitute it and ask whether the statement is true. An inequality has MANY solutions, not one. Testing the boundary itself is the fastest way to decide whether the circle is open or closed.

En una frase: Para probar un valor, sustitúyelo y pregunta si la afirmación es verdadera. Una desigualdad tiene MUCHAS soluciones, no una. Probar el propio límite es la forma más rápida de decidir si el círculo es abierto o cerrado.

  1. 1
    🎯Set upPlanteaStep 1Paso 1

    Real example: a rocket club launches only when the wind speed is less than 14 mph.

    Ejemplo real: un club de cohetes lanza solo cuando el viento es menor a 14 mph.

    More detailMás detalle

    Let s = wind speed, so s < 14.

    Sea s = velocidad del viento, así que s < 14.

  2. 2
    🧩ModelModelaStep 2Paso 2

    Substitute 11: the statement 11 < 14 is TRUE, so 11 is a solution.

    Sustituye 11: la afirmación 11 < 14 es VERDADERA, así que 11 es solución.

  3. 3
    ✏️SolveResuelveStep 3Paso 3

    Substitute the boundary 14: the statement 14 < 14 is FALSE, so 14 is not a solution.

    Sustituye el límite 14: la afirmación 14 < 14 es FALSA, así que 14 no es solución.

  4. 4
    ✅CheckRevisaStep 4Paso 4

    Graph it: an OPEN dot at 14 with an arrow pointing left toward slower speeds.

    Grafícalo: un punto ABIERTO en 14 con una flecha hacia la izquierda, a velocidades menores.

Watch for these (3)Ten en cuenta (3)
  • 👀

    Listen for "boundary point" (punto límite) — the number where the solution set starts or stops.

    Escucha "punto límite" — el número donde empieza o termina el conjunto solución.

  • 🎯

    Check the symbol twice: once for the circle (is there an "or equal to" line?) and once for the arrow direction.

    Revisa el símbolo dos veces: una para el círculo (¿tiene la línea de "o igual a"?) y otra para la dirección de la flecha.

  • ✋

    Test one shaded value and one unshaded value. The shaded one should be true and the other false.

    Prueba un valor sombreado y uno sin sombrear. El sombreado debe ser verdadero y el otro falso.

🔍 WHY THIS MATTERS¿POR QUÉ IMPORTA?

Testing before trusting Probar antes de confiar

Before a quality check passes a package, a worker tests a real example. Testing a number in an inequality works the same way: if the statement comes out true, that number is a solution. Antes de aprobar un paquete, un trabajador prueba un ejemplo real. Probar un número en una desigualdad funciona igual: si la afirmación sale verdadera, ese número es una solución.
