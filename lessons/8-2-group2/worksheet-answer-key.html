    A shirt costs $d. After a $15 discount, it costs $38. What is d?

    1. A$53
    2. B$23
    3. C$38
    4. D$45

    d − 15 = 38 → d = 38 + 15 = 53.

    Watch for: A common mistake is applying the same operation instead of the inverse — for example, solving x − 7 = 15 by subtracting 7 from both sides (getting the wrong x = 8) instead of adding 7 to both sides (the correct x = 22). Another common mistake is doing the inverse operation to only one side, like solving x + 6 = 14 by subtracting 6 from the left but forgetting the right side. Before you submit, name the operation shown in the equation, choose its inverse, apply it to BOTH sides, and check by substituting your answer back into the original equation.

  2. 2

    Spot the Common Mistake

    1. 1Equationy − 13 = 28
    2. 2Choose inverseThe inverse of − 13 is + 13, so add 13 to both sides.
    3. 3Apply to both sidesy = 28 + 13
    4. 4Simplifyy = 31

    Which step has the mistake? Explain it and write the correct work.

    The mistake is in Step 4. Correct work: The inverse operation was correct, but the addition was done wrong: 28 + 13 = 41, not 31. So y = 41. Check: 41 − 13 = 28 ✓ The plan was correct — adding 13 to both sides is the right inverse for y − 13 = 28 — but the "Simplify" step adds wrong. 28 + 13 = 41, not 31, so y = 41. Substituting back confirms it: 41 − 13 = 28, while 31 − 13 would give 18.

  3. 3

    Find the Equation Error

    1. 1Equationx − 18 = 45
    2. 2Identify inverseInverse of subtraction is subtraction
    3. 3Apply to both sidesx − 18 − 18 = 45 − 18
    4. 4Simplifyx = 27

    Which step has the mistake? Explain it and write the correct work.

    The mistake is in Step 2. Correct work: Inverse of subtraction is ADDITION. Add 18 to both sides: x = 45 + 18 = 63. The "Identify inverse" step claims subtraction undoes subtraction, which pushes the equation further from the answer instead of isolating x. Addition undoes subtraction, so add 18 to both sides of x − 18 = 45: x = 45 + 18 = 63. Checking, 63 − 18 = 45, while the answer 27 would give 9.

    Level 2 Extension — Crack the Detective's Mistake

    1. 1Equationx + 8 = 21
    2. 2Choose inverseUndo the + 8
    3. 3Apply to both sidesx + 8 + 8 = 21 + 8
    4. 4Simplifyx = 29

    Which step has the mistake? Explain it and write the correct work.

    The mistake is in Step 3. Correct work: To undo + 8 you SUBTRACT 8 from both sides, not add: x + 8 − 8 = 21 − 8, so x = 13. Check: 13 + 8 = 21 ✓ The "Apply to both sides" step adds 8 again, which leaves x + 16 on the left instead of x alone. To undo + 8 you subtract 8 from both sides: x + 8 − 8 = 21 − 8, so x = 13. Checking, 13 + 8 = 21, while x = 29 would give 37.
