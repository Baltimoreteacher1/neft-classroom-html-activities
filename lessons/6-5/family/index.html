Unit 6, Lesson 5: Write and Evaluate Algebraic Expressions

Standard 6.AT.6a

What students are learning Qué aprenden

Key idea: A letter like s can stand for a number that changes, such as how many students there are. If shirts cost $4 each and shipping is $20 once, the cost is 4s + 20. For 10 students: 4 × 10 + 20 = $60.
Idea clave: Una letra como s puede representar un número que cambia, como la cantidad de estudiantes. Si cada camiseta cuesta $4 y el envío cuesta $20 una sola vez, el costo es 4s + 20. Para 10 estudiantes: 4 × 10 + 20 = $60.

Try at home Para hacer en casa

Think of a trip where each ticket costs the same and there is one extra fee, like $3 per ticket plus a $2 bag fee. Let t be the number of tickets and write an algebraic expression for the total cost. Make a table for t = 1, 2, 3 and 4, and put each number into your expression to find the total.

Piensa en un paseo donde cada boleto cuesta lo mismo y hay un cargo extra, por ejemplo $3 por boleto más $2 por la bolsa. Sea t el número de boletos y escribe una expresión algebraica para el costo total. Haz una tabla para t = 1, 2, 3 y 4, y pon cada número en tu expresión para hallar el total.

How we did it in class today Cómo lo hicimos hoy en clase

  1. Tickets cost $12 each, plus a flat $50 venue fee. Let t be the number of tickets.
  2. "$12 each ticket" means 12 times t, which I write as 12t.
  3. The flat fee $50 is added once, so I add 50.
  4. I put them together: total revenue = 12t + 50.

If they get stuck... Si se traban...

Watch out for this: Choosing an operation from a keyword alone. A word like "more" does not always mean add. Ask what the letter stands for and how the quantities relate.
Atención: Elegir una operación solo por una palabra clave. Una palabra como "más" no siempre significa sumar. Pregunta qué representa la letra y cómo se relacionan las cantidades.

Try asking: "Can you show me how you got that? Did we miss a step?"
