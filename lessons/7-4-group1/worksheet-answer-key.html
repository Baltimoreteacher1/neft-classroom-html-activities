    Spot the Common Mistake

    1. 1ReadCompare -5 and -2. Write the comparison using > or <.
    2. 2AttemptThe student wrote -5 > -2, reasoning that 5 is bigger than 2, so -5 must be bigger than -2.
    3. 3CheckOn a number line, -5 is farther LEFT than -2, so -5 is actually less. The correct comparison is -5 < -2.

    Which step has the mistake? Explain it and write the correct work.

    The mistake is in Step 2. Correct work: -5 < -2. For negative numbers the one farther to the left is less, even though 5 > 2. The student compared only the digits 5 and 2 and ignored the negative signs. Below zero the order flips: -5 sits farther left than -2, so -5 is the smaller value and the correct comparison is -5 < -2.

    Level 2 Extension — The Mis-Ranked Treasure Map

    1. 1ProblemOrder the chest depths from least to greatest: -8 m and -15 m.
    2. 2Crew thinking15 has bigger digits than 8, so -15 must be the bigger number. I'll list -8 first because it must be smaller.
    3. 3Crew answerLeast to greatest: -8, -15

    Which step has the mistake? Explain it and write the correct work.

    The mistake is in Step 2. Correct work: For negative numbers, MORE distance from zero means SMALLER, not bigger. -15 is 15 below the surface (deeper and farther left), so -15 is actually less than -8. The correct order from least to greatest is -15, -8. The crew read 15 as bigger than 8 and assumed -15 must be the bigger number too. Depth works the other way: -15 m is deeper and farther left on the number line, so -15 < -8 and the correct order from least to greatest is -15, -8.

  6. 6

    Find the Comparison Error

    1. 1ProblemCompare -3 and -8. Which is greater?
    2. 2Student thinking8 is bigger than 3, so -8 must be greater than -3
    3. 3Student answer-8 > -3

    Which step has the mistake? Explain it and write the correct work.

    The mistake is in Step 2. Correct work: With negative numbers, the number closer to zero is GREATER. -3 is closer to zero than -8, so -3 > -8. The student compared the digits without considering that negatives work in the opposite direction. The student's reasoning stops at the digits: because 8 > 3, they concluded -8 > -3. Distance from zero works in the opposite direction for negatives, so -3, which is only 3 units below zero, is greater than -8, which is 8 units below, making the correct statement -3 > -8.
