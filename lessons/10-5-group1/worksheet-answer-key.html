  1. 1

    In geometric design, what is repetition?

    1. AThe same object or shape repeated multiple times
    2. BA set of different shapes arranged randomly
    3. CShapes that vary in size and order of appearance
    4. DAny drawing that uses color

    Repetition involves one repeated object, shape, or form — and because of that, it has predictability.

    Watch for: Calling every repeated design a 'pattern.' One identical shape repeated is repetition; a pattern needs a unit of shapes repeating in a regular order; and rhythm varies the shapes' size and order, so it is neither.

  2. 2

    A border shows: pink circle, purple square, blue triangle, pink circle, purple square, blue triangle. What are the next three shapes?

    1. APink circle, purple square, blue triangle
    2. BBlue triangle, purple square, pink circle
    3. CPink circle, blue triangle, purple square
    4. DIt is impossible to predict

    The pattern unit is circle, square, triangle, so it repeats in the same order: a pink circle, a purple square, and a blue triangle.

    Watch for: Calling every repeated design a 'pattern.' One identical shape repeated is repetition; a pattern needs a unit of shapes repeating in a regular order; and rhythm varies the shapes' size and order, so it is neither.

  3. 3

    In the circle-square-triangle border, how many shapes long is the pattern unit?

    1. A3 shapes
    2. B6 shapes
    3. C2 shapes
    4. D1 shape

    The smallest repeating chunk is circle, square, triangle — 3 shapes.

    Watch for: Calling every repeated design a 'pattern.' One identical shape repeated is repetition; a pattern needs a unit of shapes repeating in a regular order; and rhythm varies the shapes' size and order, so it is neither.

Name: Date:
  1. 1

    The pattern unit circle-square-triangle repeats. What is shape number 12?

    1. AThe blue triangle
    2. BThe pink circle
    3. CThe purple square
    4. DIt cannot be determined

    12 ÷ 3 = 4 with no remainder, so shape 12 ends a complete unit — the triangle, which is the last shape of the unit.

    Watch for: Calling every repeated design a 'pattern.' One identical shape repeated is repetition; a pattern needs a unit of shapes repeating in a regular order; and rhythm varies the shapes' size and order, so it is neither.

  2. 2

    Same pattern. What is shape number 20?

    1. AThe purple square
    2. BThe pink circle
    3. CThe blue triangle
    4. DThe 20th shape starts a new pattern

    20 ÷ 3 = 6 remainder 2 (since 6 × 3 = 18 and 20 − 18 = 2), and the second shape in the unit is the purple square.

    Watch for: Calling every repeated design a 'pattern.' One identical shape repeated is repetition; a pattern needs a unit of shapes repeating in a regular order; and rhythm varies the shapes' size and order, so it is neither.

  3. 3

    How many COMPLETE pattern units appear in the first 18 shapes of the circle-square-triangle border?

    1. A6 units
    2. B15 units
    3. C9 units
    4. D3 units

    Each unit is 3 shapes, and 18 ÷ 3 = 6 complete units.

    Watch for: Calling every repeated design a 'pattern.' One identical shape repeated is repetition; a pattern needs a unit of shapes repeating in a regular order; and rhythm varies the shapes' size and order, so it is neither.

    How is a design with rhythm different from a pattern?

    1. ARhythm varies size, orientation, and order, so it often lacks predictability; a pattern repeats in a regular order
    2. BRhythm uses shapes and a pattern does not
    3. CA pattern varies its shapes and rhythm never does
    4. DThere is no difference between them

    A pattern repeats its unit in a regular arrangement, so it is predictable. Rhythm keeps the same objects but varies how they appear, giving flow without predictability.

    Watch for: Calling every repeated design a 'pattern.' One identical shape repeated is repetition; a pattern needs a unit of shapes repeating in a regular order; and rhythm varies the shapes' size and order, so it is neither.
