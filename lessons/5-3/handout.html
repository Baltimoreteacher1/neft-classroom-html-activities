Area of Triangles

6.GR.1 · Unit 5 · Lesson 3

Name   Period

Objectives / Objetivos

Content Objective: I can find the area of a triangle using the formula A = ½ × base × height.

Language Objective: I can explain my steps using the words base, height, area, and perpendicular.

Key Idea / Idea clave

Area of a triangle = ½ × base × height. A triangle is exactly half of a rectangle with the same base and height.

I Notice / Observo

  • What shape are the garden beds?
  • What measurements do we need to find the area?

I Wonder / Me pregunto

  • Why do we divide by 2 when finding the area of a triangle?

Vocabulary / Vocabulario

Term / TérminoDefinition / Definición
Area of Triangles
Área de triángulos		The space inside a triangle. Formula: A = 1/2bh, using the perpendicular height.
El espacio dentro de un triángulo. Fórmula: A = 1/2bh, usando la altura perpendicular.
Base
Base		A side of the triangle you use to find the area.
Un lado del triángulo que usas para hallar el área.
Height
Altura		The straight-up distance from the base to the top corner.
La distancia recta desde la base hasta la esquina de arriba.
Area
Área		How much space is inside a flat shape.
Cuánto espacio hay dentro de una figura plana.
Perpendicular
Perpendicular		Two lines that meet to make a square corner (90 degrees).
Dos líneas que se unen formando una esquina recta (90 grados).
Composite figure
Figura compuesta		A shape made by putting two or more simple shapes together.
Una figura formada al juntar dos o más figuras simples.

  3. Match each shape to its area. Watch the rule: triangles use A = ½ × base × height, but parallelograms and rectangles use A = base × height (do NOT take half).
  4. Find the Area Error
    1. Step 1: Identify base and height — b = 14 m, h = 9 m
    2. Step 2: Write the formula — A = ½ × b × h
    3. Step 3: Substitute values — A = ½ × 14 × 9
    4. Step 4: Calculate — A = ½ × 23 = 11.5 sq m

    Which step has the mistake? Explain it and write the correct work.
