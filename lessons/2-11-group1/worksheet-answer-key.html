Learning target With my small group, I can add and subtract decimals by lining up the place values and the decimal points — one step at a time, with support.

Start here pageNow you try — model solution

  1. How do we write 7.8 with two decimal places? (7.80)
  2. Line up the points. Add the hundredths. What do you get? (5 + 0 = 5)
  3. Add the tenths. What do you write, and what do you regroup? (4 + 8 = 12 tenths. Write 2 and regroup 1 one.)
  4. Add the ones and the tens. What is the sum? (12.45 + 7.80 = 20.25)
Part 1Understand the ideamodels and meaning
  1. 1Mark and label each value on the number line.

    Show 6.5 − 2.8 and 3.25 + 1.5 on the number line

    Hint Each label shows an operation — work out the value first, then find that exact spot between the whole numbers.

    Answer: 6.5 − 2.8 at 3.7; 3.25 + 1.5 at 4.75

    Why: 6.5 − 2.8 = 3.7, so that mark sits between the 3.5 and 4 ticks. 3.25 + 1.5 = 4.75, which lands between the 4.5 and 5 ticks. Writing each pair with the decimal points lined up (6.50 − 2.80 and 3.25 + 1.50) keeps tenths under tenths and hundredths under hundredths, so every place is combined with its own place.

  2. 2Complete the table. Show how you found each value.

    Compute each decimal sum or difference.

    ProblemAnswer
    5.63 + 2.7
    12.4 − 8.56
    9.08 + 4.925
    25.1 − 13.47
    7.006 + 3.94

    Hint Every problem mixes decimal lengths — pad the shorter number with zeros so the columns match before you compute.

    Why: Every row mixes numbers that have different amounts of decimal places, so annex zeros first and the columns line up: 5.63 + 2.70 = 8.33, 12.40 − 8.56 = 3.84, 9.080 + 4.925 = 14.005, 25.10 − 13.47 = 11.63, and 7.006 + 3.940 = 10.946. Adding zeros to the right of the last decimal digit never changes the value; it just gives every column a digit to work with.

Part 2Practice the skillshow every step
  1. 3Circle the letter of the best answer. Show how you know.

    What is 14.6 + 3.85?

    1. A17.45
    2. B18.35
    3. C18.45
    4. D18.55

    Hint Notice the mismatch: 14.6 has one decimal place but 3.85 has two. Lining up the POINTS is the whole trick here.

    Answer: C — 18.45

    Why: Line up decimals: 14.60 + 3.85. Hundredths: 0 + 5 = 5. Tenths: 6 + 8 = 14, write 4 carry 1. Ones: 4 + 3 + 1 = 8. Tens: 1. Answer: 18.45.

    Watch for: A common mistake in Add and Subtract Decimals is lining up the last digits (the right edges) of each number instead of lining up the decimal points — for example, adding 8.3 and 2.45 as if the 3 and the 5 belong in the same column. Before you add or subtract, add zeros so every number has the same number of decimal places (write 8.3 as 8.30), then check that the decimal points sit directly above one another.

Part 3Apply itreal-world problems
  1. 5Circle the letter of the best answer. Show how you know.

    What is 20.3 − 7.48?

    1. A12.18
    2. B12.82
    3. C12.92
    4. D13.82

    Hint 20.3 stops at the tenths but 7.48 has hundredths — you can't subtract from an empty column until you annex a zero.

    Answer: B — 12.82

    Why: Rewrite as 20.30 − 7.48. Annex a zero so both have two decimal places. Work carefully with borrowing: 20.30 − 7.48 = 12.82.

    Watch for: A common mistake in Add and Subtract Decimals is lining up the last digits (the right edges) of each number instead of lining up the decimal points — for example, adding 8.3 and 2.45 as if the 3 and the 5 belong in the same column. Before you add or subtract, add zeros so every number has the same number of decimal places (write 8.3 as 8.30), then check that the decimal points sit directly above one another.

  2. 6Circle the letter of the best answer. Show how you know.

    What is 50 − 23.47?

    1. A26.53
    2. B26.63
    3. C27.47
    4. D27.53

    Hint 50 is a whole number but 23.47 has hundredths — you'll need to give 50 decimal places before you can subtract.

    Answer: A — 26.53

    Why: Rewrite 50 as 50.00. Then 50.00 − 23.47 = 26.53. You must borrow across multiple places.

    Watch for: A common mistake in Add and Subtract Decimals is lining up the last digits (the right edges) of each number instead of lining up the decimal points — for example, adding 8.3 and 2.45 as if the 3 and the 5 belong in the same column. Before you add or subtract, add zeros so every number has the same number of decimal places (write 8.3 as 8.30), then check that the decimal points sit directly above one another.
