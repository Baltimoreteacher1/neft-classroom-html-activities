What students are learning

A histogram is a bar graph that groups numbers into equal ranges called intervals. The height of each bar is the frequency: how many values fall in that interval. The bars touch because the intervals are continuous.

Key idea: A histogram is a bar graph that puts numbers into equal groups, like 0–9, 10–19, and 20–29. The height of each bar shows how many numbers are in that group. The bars touch, with no gaps between them.

How we did it in class today

  1. My data: 3, 7, 12, 15, 18, 24. I will use intervals of 10: 0–9, 10–19, 20–29.
  2. Interval 0–9: the values 3 and 7 fit, so the frequency is 2.
  3. Interval 10–19: the values 12, 15, and 18 fit, so the frequency is 3.
  4. Interval 20–29: only the value 24 fits, so the frequency is 1.
  5. Now I draw three bars with heights 2, 3, and 1, touching each other. The tallest bar (10–19) is where most values are.

If they get stuck...

Watch out for this: A common mistake in Display Data: Histograms is counting a boundary value in two intervals at once — for example, putting the value 10 in both the '0–9' bin and the '10–19' bin. Each data value belongs to exactly ONE interval. Before you submit, add up all your frequencies and check that the total matches the number of data values you started with.

What to ask: "Can you show me how you got that? Did we miss a step?"
