■ CONCEPT SUMMARY & GUIDED NOTES: What is a histogram?
1Histograms & Frequency Distributions
  • A histogram is a bar graph that groups numbers into equal ranges called intervals. The height of each bar is the frequency: how many values fall in that interval. The bars touch because the intervals are continuous.
2Strategy Model — step by step
  1. Set equal intervals along the horizontal axis with no gaps.
  2. Count the frequency (how many data values fall into each interval).
  3. Draw adjacent bars with heights equal to frequency
3Worked Example — Watch me
  1. My data: 3, 7, 12, 15, 18, 24. I will use intervals of 10: 0–9, 10–19, 20–29.
  2. Interval 0–9: the values 3 and 7 fit, so the frequency is 2.
  3. Interval 10–19: the values 12, 15, and 18 fit, so the frequency is 3.
  4. Interval 20–29: only the value 24 fits, so the frequency is 1.
  5. Now I draw three bars with heights 2, 3, and 1, touching each other. The tallest bar (10–19) is where most values are.
4Mathematical Word Bank
  • Display Data with Histograms (Representar datos con histogramas) — Group numerical data into intervals and show each interval's frequency with a bar.
  • Histogram (Histograma) — A bar graph that groups data into equal ranges. The bars touch.
  • Frequency (Frecuencia) — How many times a value shows up.
  • Interval (Intervalo) — A range of numbers used to group data.
  • Distribution (Distribución) — How the data is spread out.
  • Variability (Variabilidad) — How spread out the numbers are.
5Watch out
  • A common mistake in Display Data: Histograms is counting a boundary value in two intervals at once — for example, putting the value 10 in both the '0–9' bin and the '10–19' bin. Each data value belongs to exactly ONE interval. Before you submit, add up all your frequencies and check that the total matches the number of data values you started with.
