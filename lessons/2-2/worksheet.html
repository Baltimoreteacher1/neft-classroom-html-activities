✏️ Worked Example

  1. Data: Test scores: 55, 62, 68, 70, 72, 75, 78, 80, 82, 85, 88, 90, 95
  2. Intervals: 50–59, 60–69, 70–79, 80–89, 90–100
  3. Frequency table: 50–59: 1, 60–69: 2, 70–79: 3, 80–89: 4, 90–100: 2
  4. Conclusion: The histogram is symmetric because the bars go 1, 2, 3, 4, 2.
