Lesson 2.2Represent and Describe Data in a Histogram

Learning target I can make and read a histogram to display data in intervals.

Part 1Understand the ideamodels and meaning
  1. 1Write the letter of the matching item on each line.

    Match each word to what it means on a histogram.

    1. AFrequency
    2. BInterval
    3. CBars touch
    • AHow many values are in an interval (the bar height)
    • BAn equal-width range like 10–19
    • CWhy a histogram has no gaps between bars

    Hint Three vocab cards: one is a count, one is a range of values, and one explains the histogram's no-gap look.

    Why: Frequency answers 'how many?', so it pairs with the count of values in an interval — that count is the bar's height. Interval is a range like 10–19 that groups values together, and 'Bars touch' explains why a histogram has no gaps: the intervals run right into each other with no numbers left out.

Part 2Apply itreal-world problems
  1. 2Circle the letter of the best answer. Show how you know.

    Which of these is a statistical question?

    1. AHow many minutes are in one hour?
    2. BHow many days are in September?
    3. CHow many sides does a hexagon have?
    4. DHow many minutes did each student read last night?

    Answer: D — How many minutes did each student read last night?

    Why: Different students read for different amounts of time, so the answers vary. The others each have one fixed answer.

    Watch for: A common mistake in Display Data: Histograms is counting a boundary value in two intervals at once — for example, putting the value 10 in both the '0–9' bin and the '10–19' bin. Each data value belongs to exactly ONE interval. Before you submit, add up all your frequencies and check that the total matches the number of data values you started with.

  2. 3Circle the letter of the best answer. Show how you know.

    'How tall is our flagpole?' is NOT a statistical question. Why not?

    1. AIt is about height
    2. BIt uses numbers
    3. CIt has only one answer, so there is no variability
    4. DNobody can measure it

    Answer: C — It has only one answer, so there is no variability

    Why: A statistical question expects answers that vary. One flagpole has one height.

Part 3Explain and correctreasoning
  1. 5Find the mistake. Explain it, then show the correct work.

    Spot the Counting Mistake

    1. 1Data (points per game)3, 7, 11, 13, 16, 22
    2. 2Intervals0–9, 10–19, 20–29
    3. 3Frequency count0–9: 2, 10–19: 2, 20–29: 1
    4. 4ConclusionSo the histogram bars have heights 2, 2, and 1.

    Which step has the mistake? Explain what went wrong, then show the correct work.

    Hint Count the data values first: 3, 7, 11, 13, 16, 22 is 6 values, but the frequencies add to only 5. A value was missed.

    Mistake: Step 3. There are 6 data values but the student's frequencies add to only 5, which is the tip-off. The interval 10–19 holds 11, 13, and 16, so its frequency is 3, making the correct bar heights 2, 3, and 1.

    Correct work: The student missed a value in the 10–19 interval. The values 11, 13, AND 16 all fall in 10–19, so its frequency is 3, not 2. The correct frequency counts are 0–9: 2 (the 3 and 7), 10–19: 3 (the 11, 13, and 16), and 20–29: 1 (the 22), which totals 6 — the same as the 6 data values.

  2. 6Find the mistake. Explain it, then show the correct work.

    Spot the Interval Mistake

    1. 1Data (assists per game)1, 4, 6, 9, 12, 15, 18
    2. 2Intervals the student chose0–5, 6–10, 12–18
    3. 3Frequency count0–5: 2, 6–10: 2, 12–18: 3
    4. 4ConclusionThe student drew three bars and said the histogram was complete.

    Which step has the mistake? Explain what went wrong, then show the correct work.

    Hint Check the width of each interval the student used. Are 0–5, 6–10, and 12–18 all the same size?

    Mistake: Step 2. The problem starts at the interval-choosing step: 0–5 and 6–10 are 6 wide, 12–18 is 7 wide, and the value 11 has nowhere to go. Equal-width bins of 5 fix both problems — 0–4: 2, 5–9: 2, 10–14: 1, 15–19: 2, totaling all 7 assist values.

    Correct work: The intervals are not equal in width and they leave a gap. 0–5 and 6–10 each cover 6 values, but 12–18 covers 7 values and the value 11 has no bin at all. Histogram intervals must be equal-width and cover every value with no gaps. Using equal intervals of 5 (0–4, 5–9, 10–14, 15–19) gives frequencies 0–4: 2 (the 1 and 4), 5–9: 2 (the 6 and 9), 10–14: 1 (the 12), and 15–19: 2 (the 15 and 18), totaling 7.
