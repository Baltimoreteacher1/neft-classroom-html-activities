Lesson 2.2Represent and Describe Data in a Histogram

Version A · Answer KeySupported practice

Learning target I can make and read a histogram to display data in intervals.

Part 1Understand the ideamodels and meaning
  1. 1Circle the letter of the best answer. Show how you know.

    In a histogram, what does the height of each bar represent?

    1. AThe frequency (count) of data in that interval
    2. BThe average of the data in that interval
    3. CThe range of the interval
    4. DThe median of the data

    Hint Think about what you'd count to draw one bar: you'd tally how many data values land inside that interval.

    Answer: A — The frequency (count) of data in that interval

    Why: Each bar's height shows the frequency — how many data values fall within that interval.

    Watch for: A common mistake in Display Data: Histograms is counting a boundary value in two intervals at once — for example, putting the value 10 in both the '0–9' bin and the '10–19' bin. Each data value belongs to exactly ONE interval. Before you submit, add up all your frequencies and check that the total matches the number of data values you started with.

  2. 2Write the name of the correct group on each line.

    Order the steps for making a histogram.

    Groups: Steps (in order)
    • Steps (in order)Step 1: Choose equal-sized intervals that cover all the data
    • Steps (in order)Step 2: Count how many data values fall in each interval (frequency)
    • Steps (in order)Step 3: Draw bars for each interval — height = frequency
    • Steps (in order)Step 4: Make sure bars touch with no gaps

    Hint You must decide on intervals before counting data in each one.

    Why: The order is: choose equal-sized intervals, count the frequency in each one, draw bars whose heights match those frequencies, then make sure the bars touch. Counting cannot happen until the intervals exist, and the bar heights cannot be drawn until you know the counts.

  3. 3Circle the letter of the best answer. Show how you know.

    A histogram bar for the interval 20–29 reaches a height of 7. What does the 7 tell you?

    1. AThe largest value is 7
    2. BThere are 7 intervals
    3. CThe interval is 7 wide
    4. D7 data values fall between 20 and 29

    Hint Two numbers appear here: the interval (20–29) and the height (7). Keep straight which one is a range and which is a count.

    Answer: D — 7 data values fall between 20 and 29

    Why: A bar's height is the frequency — here, 7 values land in the 20–29 interval.

    Watch for: A common mistake in Display Data: Histograms is counting a boundary value in two intervals at once — for example, putting the value 10 in both the '0–9' bin and the '10–19' bin. Each data value belongs to exactly ONE interval. Before you submit, add up all your frequencies and check that the total matches the number of data values you started with.

    1. A12
    2. B15

    Hint The question asks for the TOTAL across all four intervals — not the tallest bar and not the biggest interval.

    Answer: D — 28

    Why: Add all frequencies: 3 + 8 + 12 + 5 = 28 players.

    How is a histogram different from a regular bar graph?

    1. AHistogram bars touch (no gaps) because the intervals are continuous ranges
    2. BThere is no difference
    3. CHistograms use colors and bar graphs don't
    4. DBar graphs show numbers and histograms show words

    Hint Picture both graphs side by side: one has spaces between its bars, one doesn't. Ask why that would be.

    Answer: A — Histogram bars touch (no gaps) because the intervals are continuous ranges

    Why: In a histogram, bars touch because each interval connects to the next (0–9, 10–19, etc.) — the data is continuous.

    1. A4
    2. B5
    3. C10
    4. D19

    Hint Width means how many whole-number values fit inside one interval — count them, don't just subtract the endpoints.

    Answer: B — 5

    Why: Each interval covers 5 values (0,1,2,3,4 then 5,6,7,8,9 etc.), so the width is 5.

Part 3Explain and correctreasoning
  1. 4Find the mistake. Explain it, then show the correct work.

    Find the Histogram Error

    1. 1DataTest scores: 55, 62, 68, 70, 72, 75, 78, 80, 82, 85, 88, 90, 95
    2. 2Intervals50–59, 60–69, 70–79, 80–89, 90–100
    3. 3Frequency table50–59: 1, 60–69: 2, 70–79: 3, 80–89: 4, 90–100: 2
    4. 4ConclusionThe histogram is symmetric because the bars go 1, 2, 3, 4, 2.

    Which step has the mistake? Explain what went wrong, then show the correct work.

    Mistake: Step 4. The frequency table is right; the Conclusion step is what fails. Symmetric means the left half mirrors the right half, but 1, 2, 3, 4, 2 climbs steadily and peaks at 80–89 near the right end, so the data is skewed left with most scores on the high side.

    Correct work: The frequencies are correct (1, 2, 3, 4, 2), but this is NOT symmetric. In a symmetric histogram, the bars rise and fall evenly from the center. Here the bars increase from left to right and only drop at the end — the data is skewed LEFT (most scores are on the higher end).

  2. 5Answer in complete sentences.

    A teacher collected test scores and made two different histograms — one with intervals of 5 (50–54, 55–59, etc.) and one with intervals of 20 (50–69, 70–89, 90–109). Both use the same data. How might the two histograms look different? Which interval size gives you more detail about the distribution? When might the larger interval be better?

    Look for: more bars, fewer bars, detail, pattern, shape, interval width, frequency

    Why: Intervals of 5 across 50–109 make 12 narrow bars with small frequencies, so peaks, gaps, and the exact shape show up clearly. Intervals of 20 make only 3 tall bars that smooth those details away, which is useful when the data set is large or you only want the big-picture comparison of low, middle, and high scores.
