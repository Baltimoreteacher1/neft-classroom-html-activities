6.NS.8 Version A — Answer Key

Distance on the Coordinate Plane

Answer Key

Name: Date:
  1. 1

    What is the distance between (-4, 3) and (2, 3)?

    1. A2 units
    2. B4 units
    3. C6 units
    4. D8 units

    Both points have y = 3, so this is a horizontal distance. |2 - (-4)| = |2 + 4| = 6 units.

  2. 2

    What is the distance between (5, -2) and (5, 4)?

    1. A2 units
    2. B4 units
    3. C6 units
    4. D10 units

    Both points have x = 5, so this is a vertical distance. |4 - (-2)| = |4 + 2| = 6 units.

  3. 3

    A rectangle has vertices at (1, 1), (5, 1), (5, 4), (1, 4). What is its perimeter?

    1. A14 units
    2. B12 units
    3. C20 units
    4. D8 units

    Width = 5 - 1 = 4. Height = 4 - 1 = 3. Perimeter = 2(4 + 3) = 14.

  4. 4

    Find the distance between each pair of points.

    (-5, 1)(3, 1)y = 1
    (2, -4)(2, 6)x = 2
    (-3, -2)(-3, 4)x = -3
    (-1, 5)(4, 5)y = 5
  5. 5

    Plot -4 and 2 on the number line. Count the distance between them.
