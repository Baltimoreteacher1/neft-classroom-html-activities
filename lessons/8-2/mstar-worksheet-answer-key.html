Question 1Two-part question

Part A — correct answer: D

Which value of n is the solution of n − 18 = 27?

  • An = 9
  • Bn = 18
  • Cn = 27
  • Dn = 45

The variable has 18 subtracted from it, so add 18 to both sides to isolate n: n = 27 + 18 = 45. Check by substituting: 45 − 18 = 27.

  • A: That subtracts 18 from 27. The variable already had 18 taken away, so ADD it back.
  • B: That is the amount subtracted, not the solution. Add it to 27.
  • C: That is the value after 18 was subtracted, not n itself. Add 18 to recover n.

Part B — correct answer: A

Which reasoning justifies the step used to find that answer?

  • ABecause 18 is subtracted from n, adding 18 to both sides is the inverse operation that leaves n by itself.
  • BBecause the equation shows subtraction, 18 should be subtracted from both sides as well.
  • CBecause the number written after the equal sign is always the value of the variable.
  • DBecause the smaller number in a subtraction equation is always the solution.

Subtraction is undone by addition. Adding 18 to both sides keeps the equation balanced and isolates the variable, giving n = 45. Subtracting 18 from both sides instead would give 27 − 18 = 9, and 9 − 18 does not equal 27.

Question 2Written response · 2 points

Type II Reasoning: Adding When the Inverse Is Subtraction

Darius solved the equation x + 23 = 40. He wrote: 'x + 23 = 40, so x = 40 + 23, which means x = 63.'

Explain Darius's misconception and give the correct value of x.

Model answer: x = 17. The 23 is being added to x, so the inverse operation is subtraction: subtract 23 from both sides to get x = 40 − 23 = 17. Check by substituting: 17 + 23 = 40. Darius's answer fails the same check, because 63 + 23 = 86, not 40.

2 pointsStudent explains that adding 23 is undone by subtracting 23 from both sides, not by adding again, and gives x = 17.
1 pointStudent gives x = 17 but does not explain why subtraction is the inverse operation needed.
0 pointsStudent agrees with Darius or gives an unrelated response.
