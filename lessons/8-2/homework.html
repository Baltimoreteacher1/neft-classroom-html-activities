🎯 The big ideaLa idea principal

In one sentence: Undo the operation with its opposite (the inverse operation), and do the same thing to both sides to keep it balanced.

En una frase: Deshaz la operación con su opuesta (la operación inversa), y haz lo mismo a ambos lados para mantenerla en equilibrio.

  1. 1
    🎯Set upPlanteaStep 1Paso 1

    Real example: solve n + 23 = 58.

    Ejemplo real: resuelve n + 23 = 58.

    More detailMás detalle

    The 23 is added to n, and we want n by itself.

    El 23 está sumado a n, y queremos n sola.

  2. 2
    🧩ModelModelaStep 2Paso 2

    Find the inverse operation.

    Encuentra la operación inversa.

    More detailMás detalle

    The opposite of adding 23 is subtracting 23.

    Lo opuesto de sumar 23 es restar 23.

  3. 3
    ✏️SolveResuelveStep 3Paso 3

    Do the same thing to both sides: n + 23 − 23 = 58 − 23.

    Haz lo mismo a ambos lados: n + 23 − 23 = 58 − 23.

  4. 4
    ✅CheckRevisaStep 4Paso 4

    That leaves n = 35.

    Eso deja n = 35.

    More detailMás detalle

    Check by putting it back: 35 + 23 = 58. True!

    Comprueba poniéndolo de nuevo: 35 + 23 = 58. ¡Verdadero!

⚖️ WHY THIS MATTERS¿POR QUÉ IMPORTA?

Working back to the start Volver al inicio

If you had x dollars, earned 4 more, and now have 11, the equation x + 4 = 11 lets you work backward to find what you started with. Si tenías x dólares, ganaste 4 más y ahora tienes 11, la ecuación x + 4 = 11 te deja volver atrás para hallar con cuánto empezaste.

⚠️
Watch out:Cuidado con este error común:

To get x alone in x + 4 = 11, you only need to subtract 4 from the left side. Para dejar x sola en x + 4 = 11, solo necesitas restar 4 del lado izquierdo.
