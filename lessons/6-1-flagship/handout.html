Powers and Exponents

6.AT.5 · Unit 6 · Lesson 1

Name   Period

Objectives / Objetivos

Content Objective: I can write and evaluate numbers in exponent form using a base and a power.

Language Objective: I can explain my work using the words exponent, base, power, and evaluate.

Key Idea / Idea clave

A power like 2³ is a short way to write repeated multiplication: 2 × 2 × 2.

I Notice / Observo

  • What happens to the volume each time you flip a switch?
  • Why is 2³ equal to 8, not 6?

I Wonder / Me pregunto

  • What if the volume tripled each time instead of doubled?

Practice Preview / Vista previa de práctica

  1. What is the value of 4³?
    1. 64
    2. 12
    3. 43
    4. 7
  2. Evaluate each exponential expression. Show the repeated multiplication and the final value.
  3. Sort each power by whether its value is greater than 50 or not.
  4. Find the Exponent Error
    1. Step 1: Expression — 2³
    2. Step 2: Student's thinking — 2 × 3
    3. Step 3: Calculate — = 6

    Which step has the mistake? Explain it and write the correct work.
