    (Lesson 8.1) Crack the Equation Error

    1. 1ClueA number of case files divided by 3 equals 6.
    2. 2Choose a variableLet n be the number of case files.
    3. 3Write the equation3n = 6

    Which step has the mistake? Explain it and write the correct work.

    The mistake is in Step 3. Correct work: 'Divided by 3' means division, not multiplication. The correct equation is n / 3 = 6, not 3n = 6. Check: 18 / 3 = 6. The clue says the case files are divided by 3, but the equation 3n = 6 multiplies instead. Dividing means splitting n into 3 equal groups, so the equation is n / 3 = 6, and 18 / 3 = 6 confirms it.

    (Lesson 8.2) Spot the Common Mistake

    1. 1Equationy − 13 = 28
    2. 2Choose inverseThe inverse of − 13 is + 13, so add 13 to both sides.
    3. 3Apply to both sidesy = 28 + 13
    4. 4Simplifyy = 31

    Which step has the mistake? Explain it and write the correct work.

    The mistake is in Step 4. Correct work: The inverse operation was correct, but the addition was done wrong: 28 + 13 = 41, not 31. So y = 41. Check: 41 − 13 = 28 ✓ The plan was correct — adding 13 to both sides is the right inverse for y − 13 = 28 — but the "Simplify" step adds wrong. 28 + 13 = 41, not 31, so y = 41. Substituting back confirms it: 41 − 13 = 28, while 31 − 13 would give 18.

    (Lesson 8.3) Spot the Common Mistake

    1. 1Equationn / 4 = 12
    2. 2Choose operationn is in a fraction, so I will divide both sides by 4.
    3. 3Apply to both sidesn / 4 ÷ 4 = 12 ÷ 4
    4. 4Simplifyn = 3

    Which step has the mistake? Explain it and write the correct work.

    The mistake is in Step 2. Correct work: n is divided by 4, so the inverse is MULTIPLICATION. Multiply both sides by 4: n = 12 × 4 = 48. Check: 48 ÷ 4 = 12 ✓ Dividing again does not undo division. Since n is divided by 4, multiply both sides by 4: n = 12 × 4 = 48, and 48 ÷ 4 = 12 confirms it. The answer 3 is a clue on its own — n has to be bigger than 12, not smaller, because it was cut into fourths.

    (Lesson 8.1) Find the Equation Error

    1. 1SituationTwice a number is 16
    2. 2Identify operationTwice means addition
    3. 3Write equationn + 2 = 16

    Which step has the mistake? Explain it and write the correct work.

    The mistake is in Step 2. Correct work: 'Twice' means multiply by 2, not add 2. The correct equation is 2n = 16. The operation was named wrong at the start: 'twice' was called addition, which led to n + 2 = 16. Twice a number means two of that number, which is multiplication, so the equation is 2n = 16.

  2. 2

    (Lesson 8.2) Find the Equation Error

    1. 1Equationx − 18 = 45
    2. 2Identify inverseInverse of subtraction is subtraction
    3. 3Apply to both sidesx − 18 − 18 = 45 − 18
    4. 4Simplifyx = 27

    Which step has the mistake? Explain it and write the correct work.

    The mistake is in Step 2. Correct work: Inverse of subtraction is ADDITION. Add 18 to both sides: x = 45 + 18 = 63. The "Identify inverse" step claims subtraction undoes subtraction, which pushes the equation further from the answer instead of isolating x. Addition undoes subtraction, so add 18 to both sides of x − 18 = 45: x = 45 + 18 = 63. Checking, 63 − 18 = 45, while the answer 27 would give 9.

  3. 3

    (Lesson 8.3) Find the Equation Error

    1. 1Equationx / 5 = 12
    2. 2Identify inverseInverse of division is division
    3. 3Apply to both sidesx / 5 / 5 = 12 / 5
    4. 4Simplifyx = 2.4

    Which step has the mistake? Explain it and write the correct work.

    The mistake is in Step 2. Correct work: Inverse of division is MULTIPLICATION. Multiply both sides by 5: x = 12 × 5 = 60. Check: 60 / 5 = 12 ✓ The inverse named in that step is wrong: division is undone by multiplication, not by more division. Multiply both sides by 5 to get x = 12 × 5 = 60, and 60 / 5 = 12 checks. Dividing again shrank x to 2.4, far below the 12 it was supposed to produce.
