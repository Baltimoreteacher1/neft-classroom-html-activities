How do you plot points in all four quadrants?

The coordinate plane has four parts called quadrants. A negative coordinate means you move left (for x) or down (for y) from the origin instead of right or up.

Key idea: The Four Quadrants. Formula: Quadrant I: (+, +) | Quadrant II: (−, +) | Quadrant III: (−, −) | Quadrant IV: (+, −). 1. Quadrant I: Upper-right (+, +). 2. Quadrant II: Upper-left (−, +). 3. Quadrant III: Lower-left (−, −); Quadrant IV: Lower-right (+, −)

Watch me

  • I will plot (-3, -4). I start at the origin (0, 0).
  • The x is -3, which is negative, so I move 3 units to the LEFT.
  • The y is -4, which is negative, so I move 4 units DOWN. I place my dot.
  • Both coordinates are negative, so the point is in Quadrant III.

Let's try together

  • Now let's plot (-5, 2). The x is -5, so which way do we move? Left 5 units.
  • The y is 2, which is positive, so which way? Up 2 units.
  • Left and up lands us in which quadrant? Quadrant II.
