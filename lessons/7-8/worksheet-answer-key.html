  1. The y is 2, which is positive, so which way? Up 2 units.
  2. Left and up lands us in which quadrant? Quadrant II.
Part 1Understand the ideamodels and meaning
  1. 1Write the letter of the matching item on each line.

    Match each ordered pair to its quadrant.

    1. A(3, 4)
    2. B(-2, 5)
    3. C(-6, -1)
    4. D(1, -3)
    5. E(-4, 2)
    6. F(5, -6)
    • AQuadrant I
    • BQuadrant II
    • CQuadrant III
    • DQuadrant IV
    • EQuadrant II
    • FQuadrant IV

    Hint Only the SIGNS matter: (+, +), (-, +), (-, -), and (+, -) each belong to one quadrant.

    Why: The signs alone decide the quadrant: (+, +) is I, (-, +) is II, (-, -) is III, and (+, -) is IV. So (3, 4) is Quadrant I, (-2, 5) and (-4, 2) are both Quadrant II, (-6, -1) is Quadrant III, and (1, -3) and (5, -6) are Quadrant IV. How big the numbers are never matters — only whether each one is positive or negative.

  2. 2Write the name of the correct group on each line.

    Sort these points by their quadrant: I first, then II, III, IV.

    Groups:
    • (-3, -2)
    • (5, 1)
    • (-1, 4)
    • (2, -6)
    • (4, 3)
    • (-5, -7)

    Hint Work out each point's quadrant from its signs: (+,+) is I, (−,+) is II, (−,−) is III, (+,−) is IV.

    Why: Each card already shows its quadrant, so the task is grouping them in the order I, II, III, IV. Quadrant I holds (5, 1) and (4, 3) because both coordinates are positive; (-1, 4) is the only Quadrant II card; (-3, -2) and (-5, -7) are Quadrant III with both coordinates negative; and (2, -6) is Quadrant IV.

Part 2Apply itreal-world problems
  1. 3Circle the letter of the best answer. Show how you know.

    In which quadrant is the point (-4, 5)?

    1. AQuadrant I
    2. BQuadrant III
    3. CQuadrant II
    4. DQuadrant IV

    Hint Look at the signs: x = -4 is negative and y = 5 is positive.

    Answer: C — Quadrant II

    Why: The x-coordinate is negative (left) and the y-coordinate is positive (up). Left and up is Quadrant II.

    Watch for: A common mistake in Ordered Pairs in All Four Quadrants is matching each sign to the wrong axis — for example, seeing (-2, 5) and thinking "the x is negative so I move DOWN, and the y is positive so I move RIGHT," which lands the point in Quadrant IV. But the x-coordinate always controls left/right, never up/down: negative x means LEFT (not down), and positive y means UP (not right). So (-2, 5) is actually left 2, up 5 — Quadrant II. Before you submit, check that you used the x-coordinate for left/right and the y-coordinate for up/down, and never swapped them.

Part 1Understand the ideamodels and meaning
  1. 1Plot and label each point on the grid.

    Plot one point in each quadrant: (3, 2), (-4, 1), (-2, -3), (5, -4)

    Answer: I, II, III, IV

    Why: Each point starts at the origin, moves along x first and then along y, and the pair of signs tells you which region you end in. (3, 2) goes right and up to Quadrant I, (-4, 1) goes left and up to Quadrant II, (-2, -3) goes left and down to Quadrant III, and (5, -4) goes right and down to Quadrant IV.

  2. 2Complete the table. Show how you found each value.

    Pointx signy signQuadrant or Axis
    (6, -2)
    (-3, -5)

    Why: Write each coordinate's sign, then read the pair off the map: (6, -2) is (+, -) so Quadrant IV, (-3, -5) is (-, -) so Quadrant III, and (-1, 8) is (-, +) so Quadrant II. A zero means the point sits on an axis instead of inside a quadrant — (0, 7) is on the y-axis and (4, 0) is on the x-axis.

    • A(+, +)

    Why: Quadrants are numbered counterclockwise from the top-right, so Quadrant I is (+, +), Quadrant II is (-, +), Quadrant III is (-, -), and Quadrant IV is (+, -). The two axis cards work differently: a point on the x-axis has no vertical move, so y = 0, and a point on the y-axis has no horizontal move, so x = 0.

  1. 7Find the mistake. Explain it, then show the correct work.

    Spot the Common Mistake

    1. 1ProblemName the quadrant for the point (6, -1).
    2. 2Student thinkingI'll read the coordinates as (y, x), so I treat this like (-1, 6): the first number -1 is negative (left) and the second number 6 is positive (up).
    3. 3Student answer(6, -1) is in Quadrant II.

    Which step has the mistake? Explain what went wrong, then show the correct work.

    Mistake: Step 2. An ordered pair is always (x, y), so the first number is the horizontal move and the order cannot be swapped. Here x = 6 sends you right and y = -1 sends you down, which is the bottom-right region — Quadrant IV. Reading it as (-1, 6) described a completely different point.

    Correct work: The order was reversed. In an ordered pair (x, y), x ALWAYS comes first. Here x = 6 (positive → right) and y = -1 (negative → down). Right and down is Quadrant IV, not Quadrant II.

    Plot these 4 points and connect them in order to form a shape. Name the shape and identify which quadrants it spans: (-3, 2), (3, 2), (3, -2), (-3, -2)

    Answer: A, B, C, D

    Why: The four points reuse 3 and 2 with different signs, so connecting A(-3, 2), B(3, 2), C(3, -2), D(-3, -2) in order draws a rectangle 6 units wide and 4 units tall centered on the origin. One corner sits in each region — A in Quadrant II, B in Quadrant I, C in Quadrant IV, and D in Quadrant III — so the shape spans all four quadrants.

  1. 4Find the mistake. Explain it, then show the correct work.

    Find the Quadrant Error

    1. 1ProblemIdentify the quadrant for (-3, -5)
    2. 2Student thinkingThe x is -3, so I go left 3. The y is -5, so I go up 5.
    3. 3Student answer(-3, -5) is in Quadrant II

    Correct work: A negative y-coordinate means DOWN, not up. Go left 3 and DOWN 5. The point (-3, -5) is in Quadrant III (both negative), not Quadrant II.

    Look for: negative, quadrant, left, down, x-coordinate, y-coordinate, sign change

    Why: Quadrant III is the bottom-left region, so both coordinates have to end up negative.
