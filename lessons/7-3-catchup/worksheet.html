    1. 1ProblemPlot -2.25 on the number line.
    2. 2Student thinkingIt is negative, so I go past -2. The .25 is one quarter, so I count toward 0 (to the right) by a quarter unit and land between -2 and -1.

    4. D|-4| = 0 because negatives cancel out

    (Lesson 7.3) Confusing Opposite with Absolute Value

    1. 1ProblemComplete the table for the integer 9: find its absolute value and its opposite.
    2. 2Student's thinkingAbsolute value and opposite both just make a number positive, so they should give the same answer as each other.
    3. 3Student's answerAbsolute value of 9 = 9, and opposite of 9 = 9.

    Which step has the mistake? Explain it and write the correct work.
