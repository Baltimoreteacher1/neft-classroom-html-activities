Write and Solve Equations Using Multiplication or Division

6.AT.8 · Unit 8 · Lesson 3

Name   Period

Objectives / Objetivos

Content Objective: I can solve one-step multiplication and division equations using inverse operations.

Language Objective: I can explain my steps using the words inverse operation, multiply, divide, and isolate.

Key Idea / Idea clave

Solving Multiplication & Division Equations. Formula: ax = b → x = b/a | x/a = b → x = a · b. 1. Identify the operation applied to the variable. 2. Use the inverse operation: Divide to undo multiplication; multiply to undo division. 3. Balance: Apply the inverse operation to both sides to isolate the variable

I Notice / Observo

  • What does the 3 represent in the equation?
  • What does x represent?

I Wonder / Me pregunto

  • What if there were 5 boxes instead of 3?
