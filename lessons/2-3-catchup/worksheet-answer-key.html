    (Lesson 2.3) The Even-Count Median Mistake

    1. 1Data setPoints per game, in order: 3, 8, 10, 14, 16, 20 (6 values)
    2. 2GoalFind the MEDIAN number of points.
    3. 3Pick the middleWith 6 values the student grabs a single middle number and says median = 10.
    4. 4AnswerMedian = 10

    Which step has the mistake? Explain it and write the correct work.

    The mistake is in Step 3. Correct work: When a data set has an EVEN number of values there is no single middle number. You must average the TWO middle values. Here the 3rd and 4th values are 10 and 14, so the median = (10 + 14) ÷ 2 = 12, not 10. With 6 values there is no single number sitting in the middle — positions 3 and 4 tie for the center. The 3rd and 4th values are 10 and 14, so the median is their average, (10 + 14) ÷ 2 = 12, not just the lower one.

    (Lesson 2.1) Find the Reasoning Error

    1. 1QuestionHow many touchdowns did the quarterback throw this season?
    2. 2Student saysThis is NOT a statistical question.
    3. 3ReasonIt only asks about one player, so there is no variability.

    Which step has the mistake? Explain it and write the correct work.

    The mistake is in Step 3. Correct work: Even though it asks about one player, "this season" means multiple games. The number of touchdowns per game varies, so there IS variability in the data. This IS a statistical question. The reasoning step assumes one player means no variability, but 'this season' covers many games and the touchdown count changes from game to game. That game-to-game variation is real data variability, so the question is statistical.

  2. 2

    (Lesson 2.2) Find the Histogram Error

    1. 1DataTest scores: 55, 62, 68, 70, 72, 75, 78, 80, 82, 85, 88, 90, 95
    2. 2Intervals50–59, 60–69, 70–79, 80–89, 90–100
    3. 3Frequency table50–59: 1, 60–69: 2, 70–79: 3, 80–89: 4, 90–100: 2
    4. 4ConclusionThe histogram is symmetric because the bars go 1, 2, 3, 4, 2.

    Which step has the mistake? Explain it and write the correct work.

    The mistake is in Step 4. Correct work: The frequencies are correct (1, 2, 3, 4, 2), but this is NOT symmetric. In a symmetric histogram, the bars rise and fall evenly from the center. Here the bars increase from left to right and only drop at the end — the data is skewed LEFT (most scores are on the higher end). The frequency table is right; the Conclusion step is what fails. Symmetric means the left half mirrors the right half, but 1, 2, 3, 4, 2 climbs steadily and peaks at 80–89 near the right end, so the data is skewed left with most scores on the high side.

  3. 3

    (Lesson 2.3) Find the Stats Error

    1. 1Data set12, 15, 18, 15, 20
    2. 2Find meanSum = 80, Count = 5, Mean = 80 ÷ 5 = 16
    3. 3Find medianOrdered: 12, 15, 15, 18, 20 → Median = 15
    4. 4Find modeMode = 18 (the biggest number)

    Which step has the mistake? Explain it and write the correct work.

    The mistake is in Step 4. Correct work: Mode = 15 (appears twice, more than any other value). Mode is the most frequent value, not the largest. The mean and median steps are both correct; the mode step picks 18 because it is the biggest number. Mode means most often, not most, and in 12, 15, 15, 18, 20 only 15 repeats, so the mode is 15.
