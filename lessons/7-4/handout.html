Compare and Order Integers and Rational Numbers

6.NOS.8 · Unit 7 · Lesson 4

Name   Period

Objectives / Objetivos

Content Objective: I can compare and order integers using a number line.

Language Objective: I can explain my reasoning using the words compare, order, greater than, and less than.

Key Idea / Idea clave

The number farther to the left is always less; the number farther to the right is always greater.

I Notice / Observo

  • Which treasure is closest to the surface?
  • Is -7 greater than or less than -2?

I Wonder / Me pregunto

  • Why does a bigger negative number mean a deeper location?

Vocabulary / Vocabulario

Term / TérminoDefinition / Definición
Compare and Order Integers
Comparar y ordenar enteros		Use a number line to decide which integers are greater or less and place them in order.
Usar una recta numérica para decidir cuáles enteros son mayores o menores y colocarlos en orden.
Number line
Recta numérica		A straight line where numbers are placed in order; numbers get smaller to the left and larger to the right.
Una recta donde los números se colocan en orden; los números son menores a la izquierda y mayores a la derecha.
Compare
Comparar		To see if a number is bigger, smaller, or equal to another.
Ver si un número es mayor, menor o igual que otro.
Order
Ordenar		To arrange numbers by size, from least to greatest or greatest to least.
Acomodar números por tamaño, de menor a mayor o de mayor a menor.
Greater than
Mayor que		The > sign, showing one number is bigger.
El signo >, que muestra que un número es mayor.
Less than
Menor que		The < sign, showing one number is smaller.
El signo <, que muestra que un número es menor.

Practice Preview / Vista previa de práctica

  1. Which statement is TRUE?
    1. -3 > -1
    2. -5 < -2
    3. -4 > 0
    4. -1 < -6
  2. Plot these integers and write them in order from greatest to least: -8, 4, -3, 1, -1, 6
  3. Compare each pair of integers using < , > , or =.
  4. Find the Comparison Error
    1. Step 1: Problem — Compare -3 and -8. Which is greater?
    2. Step 2: Student thinking — 8 is bigger than 3, so -8 must be greater than -3
    3. Step 3: Student answer — -8 > -3

    Which step has the mistake? Explain it and write the correct work.
