Lesson 7.4Compare and Order Integers and Rational Numbers

Version A · Answer KeySupported practice

Learning target I can compare and order integers using a number line.

Part 1Understand the ideamodels and meaning
  1. 1Circle the letter of the best answer. Show how you know.

    Which statement is TRUE?

    1. A-5 < -2
    2. B-4 > 0
    3. C-3 > -1
    4. D-1 < -6

    Hint Sketch a quick number line. For negatives, 'greater' means closer to zero, not a bigger digit.

    Answer: A — -5 < -2

    Why: -5 is farther to the left on the number line than -2, so -5 < -2 is true.

    Watch for: A common mistake in Compare and Order Integers is thinking that a negative number with a bigger digit is the bigger value — for example, believing -15 is greater than -8 because 15 is greater than 8. It's the opposite for negatives: the number farther to the left on the number line (farther from zero) is always the LESSER value, so -15 < -8. Before you submit, check your comparison against the number line, not just the digits.

  2. 2Write the name of the correct group on each line.

    Drag to order these integers from LEAST to GREATEST.

    Groups:
    • 3
    • -1
    • -6
    • 0
    • -4
    • 5

    Hint Least to greatest reads left to right on a number line — all the negatives come before 0.

    Why: Least to greatest matches left to right on a number line, so every negative comes before 0 and every positive comes after it. Among the negatives, -6 sits farthest below zero and -1 sits closest, giving the order -6, -4, -1, 0, 3, 5.

  3. 3Mark and label each value on the number line.

    Plot -3, 1, -7, 4, and -1 on the number line to help you compare them.

    Hint Negatives (-3, -7, -1) go left of 0; positives (1, 4) go right.

    Answer: ? at -3; ? at 1; ? at -7; ? at 4; ? at -1

    Why: The three negatives land to the left of 0 and the two positives to the right, so -7 is 7 ticks left, -3 is 3 ticks left, -1 is 1 tick left, and 1 and 4 sit to the right. Seeing them plotted makes the comparison obvious: -1 is the greatest of the negatives because it is closest to zero, and -7 is the least of all five.

    Spot the Common Mistake

    1. 1ReadCompare -5 and -2. Write the comparison using > or <.
    2. 2AttemptThe student wrote -5 > -2, reasoning that 5 is bigger than 2, so -5 must be bigger than -2.
    3. 3CheckOn a number line, -5 is farther LEFT than -2, so -5 is actually less. The correct comparison is -5 < -2.

    Which step has the mistake? Explain what went wrong, then show the correct work.

    Hint Where do -5 and -2 sit on the number line?

    Mistake: Step 2. The student compared only the digits 5 and 2 and ignored the negative signs. Below zero the order flips: -5 sits farther left than -2, so -5 is the smaller value and the correct comparison is -5 < -2.

    Correct work: -5 < -2. For negative numbers the one farther to the left is less, even though 5 > 2.

    Spot the Common Mistake

    1. 1ReadOrder -8 and -15 from least to greatest.
    2. 2AttemptThe student wrote -8, -15, because 8 is smaller than 15.

Part 1Understand the ideamodels and meaning
  1. 1Write the name of the correct group on each line.

    These integers represent bank account changes. Sort from the WORST change (biggest loss) to the BEST change (biggest gain).

    Groups:
    • +50 deposit
    • -25 withdrawal
    • +10 deposit
    • -100 withdrawal
    • 0 no change
    • -5 fee

    Why: Ranking the changes is the same as ordering the integers from least to greatest, since the most negative change is the worst for the account: -100, -25, -5, 0, +10, +50. The -100 withdrawal is worst because it is farthest below zero, and the +50 deposit is best because it is farthest above it.

Part 2Explain and correctreasoning
  1. 2Find the mistake. Explain it, then show the correct work.

    Find the Comparison Error

    1. 1ProblemCompare -3 and -8. Which is greater?
    2. 2Student thinking8 is bigger than 3, so -8 must be greater than -3
    3. 3Student answer-8 > -3

    Which step has the mistake? Explain what went wrong, then show the correct work.

    Mistake: Step 2. The student's reasoning stops at the digits: because 8 > 3, they concluded -8 > -3. Distance from zero works in the opposite direction for negatives, so -3, which is only 3 units below zero, is greater than -8, which is 8 units below, making the correct statement -3 > -8.

    Correct work: With negative numbers, the number closer to zero is GREATER. -3 is closer to zero than -8, so -3 > -8. The student compared the digits without considering that negatives work in the opposite direction.

  2. 3Answer in complete sentences.

    A student says: 'Negative numbers are always less than positive numbers, so -100 is less than 1.' Is this correct? Now the student says: '-100 is less than -1 because 100 is greater than 1.' Is THIS correct? Explain the difference.

    Look for: negative, positive, less than, greater than, number line, left, right, closer to zero, farther

    Why: The first statement is true: -100 is negative and 1 is positive, so -100 sits left of 1 on the number line and is less. The second answer, -100 < -1, is also true, but the reason given is wrong — it is not because 100 > 1, it is because -100 lies 100 units below zero while -1 lies only 1 unit below, putting -100 farther left.
