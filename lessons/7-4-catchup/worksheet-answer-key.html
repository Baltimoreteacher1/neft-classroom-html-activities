  2. 2

    (Lesson 7.3) Confusing Opposite with Absolute Value

    1. 1ProblemComplete the table for the integer 9: find its absolute value and its opposite.
    2. 2Student's thinkingAbsolute value and opposite both just make a number positive, so they should give the same answer as each other.
    3. 3Student's answerAbsolute value of 9 = 9, and opposite of 9 = 9.

    Which step has the mistake? Explain it and write the correct work.

    The mistake is in Step 2. Correct work: Absolute value and opposite are different operations. Absolute value measures distance from zero and is never negative: |9| = 9. Opposite reflects a number to the other side of zero, flipping its sign: the opposite of 9 is -9, not 9. The two operations only give the same result for the number 0 — every other number has a different absolute value and opposite. The student's thinking step treats absolute value and opposite as the same operation, but they are not. Absolute value gives the distance from zero, so |9| = 9, while the opposite reflects the number across zero, so the opposite of 9 is -9 — the two only agree for the number 0.

    (Lesson 7.4) Spot the Common Mistake

    1. 1ReadOrder -8 and -15 from least to greatest.
    2. 2AttemptThe student wrote -8, -15, because 8 is smaller than 15.
    3. 3Check-15 is farther left than -8 on the number line, so -15 is the least. The correct order is -15, -8.

    Which step has the mistake? Explain it and write the correct work.

    The mistake is in Step 2. Correct work: Least to greatest: -15, -8. The more negative a number is, the less its value — so -15 < -8. The reasoning treats -8 and -15 like 8 and 15, so it puts -8 first. On the number line -15 sits farther left than -8, which makes it the smaller value, so least to greatest is -15, -8.

    (Lesson 7.5) Spot the Common Mistake

    1. 1CluePlot the point (4, 0).
    2. 2Move rightMove 4 units to the right along the x-axis. Good.
    3. 3Move upMove 4 units up, because the pair has a 4 in it.
    4. 4Plot the pointPlace the dot at (4, 4).

    Which step has the mistake? Explain it and write the correct work.

    The mistake is in Step 3. Correct work: The y-coordinate is 0, not 4. After moving 4 right, the up move is 0 units, so the point stays on the x-axis at (4, 0). The student reused the x-value instead of reading the second number (0). The up move comes from the SECOND number, and the second number in (4, 0) is 0. Reusing the 4 pushes the point off the axis to (4, 4). With a y-coordinate of 0 there is no upward move at all, so the point stays right on the x-axis at (4, 0).

    (Lesson 7.3) Find the Absolute Value Error

    1. 1ProblemFind |-6|
    2. 2Student thinkingThe number is -6, and absolute value makes it the opposite
    3. 3Student answer|-6| = 6, and since we take the opposite, the answer is -6

    Which step has the mistake? Explain it and write the correct work.

    The mistake is in Step 3. Correct work: Absolute value gives the DISTANCE from zero, which is always positive or zero. |-6| = 6. The student incorrectly applied 'opposite' a second time. The student found |-6| = 6 correctly and then took the opposite a second time, landing back on -6. Absolute value is a distance from zero, so it stops at 6 — there is no extra sign flip after the bars come off.

  2. 2

    (Lesson 7.4) Find the Comparison Error

    1. 1ProblemCompare -3 and -8. Which is greater?
    2. 2Student thinking8 is bigger than 3, so -8 must be greater than -3
    3. 3Student answer-8 > -3

    Which step has the mistake? Explain it and write the correct work.

    The mistake is in Step 2. Correct work: With negative numbers, the number closer to zero is GREATER. -3 is closer to zero than -8, so -3 > -8. The student compared the digits without considering that negatives work in the opposite direction. The student's reasoning stops at the digits: because 8 > 3, they concluded -8 > -3. Distance from zero works in the opposite direction for negatives, so -3, which is only 3 units below zero, is greater than -8, which is 8 units below, making the correct statement -3 > -8.

    (Lesson 7.5) Miscounted Grid Lines

    1. 1Ordered pair(7, 3)
    2. 2Move along the x-axisStart at the origin (0, 0) and count 7 units to the right.
    3. 3Move along the y-axisCount up from the x-axis: 1, 2, 3, 4 — stop on 4.
    4. 4Plot the pointPlace the dot at (7, 4).

    Which step has the mistake? Explain it and write the correct work.

    The mistake is in Step 3. Correct work: The x-axis itself is 0, not 1. Counting up correctly: 1, 2, 3 — the third count lands on y = 3, so the point is (7, 3), not (7, 4). The student started counting one gridline too high by treating the x-axis as unit 1 instead of unit 0. Counting up has to start with the x-axis as 0, not 1. The first line above the x-axis is 1, the second is 2, and the third is 3, so 3 units up lands on y = 3. Treating the axis itself as unit 1 pushes every count one gridline too high, which is how (7, 3) turned into (7, 4).
