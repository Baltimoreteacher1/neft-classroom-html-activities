Warm-up

Let's do 8.4 ÷ 2.1. STEP 0 — MOVE THE POINT: how many places make 2.1 a whole number? (1 place, so 2.1 becomes 21.)

Teaching notes

Key idea: Move the decimal point the same number of places in BOTH the divisor and the dividend, put the point in the quotient straight above it, then repeat Divide → Multiply → Subtract → Bring Down.

I do:

  1. I want 18.9 ÷ 6.3. The divisor is 6.3, and long division needs a whole-number divisor.
  2. STEP 0 — MOVE THE POINT: I move the decimal point 1 place right in the divisor, so 6.3 becomes 63.
  3. I must move the dividend the same 1 place right: 18.9 becomes 189, and the point in the quotient goes straight above its new spot. The problem is now 189 ÷ 63.
  4. DIVIDE: 63 does not fit into 1 or 18, so my first working number is 189. How many 63s fit into 189? Three. I write 3 above the 9.
  5. MULTIPLY: 3 × 63 = 189. I write it underneath.
  6. SUBTRACT: 189 − 189 = 0.
  7. BRING DOWN: there are no digits left to bring down, so the cycle is finished and the remainder is 0. 18.9 ÷ 6.3 = 3.
  8. I check by multiplying: 6.3 × 3 = 18.9. Correct — 3 pods can be filled.

You do: Next, you will move the point so the divisor is a whole number, then run the divide, multiply, subtract, bring down cycle on your own. Remember: move the point in both numbers, put the point in the quotient, then divide, multiply, subtract, bring down.

Common misconception

A common mistake in Divide Decimals is moving the decimal point in the divisor but forgetting to move it the same number of places in the dividend. For example, in 6.4 ÷ 0.8 a student changes 0.8 to 8 but leaves the dividend as 6.4, then divides 6.4 ÷ 8 = 0.8 instead of moving both points to get 64 ÷ 8 = 8. A second version of this mistake happens when the divisor has two decimal places, like 0.12: students move both points only 1 place instead of 2, turning 9.6 ÷ 0.12 into 96 ÷ 1.2 instead of the correct 960 ÷ 12. Count the divisor's decimal places first, then move BOTH points that same number of places.

ESOL / SPED supports

  • Pre-teach: Divide Decimals, Dividend, Divisor, Quotient, Decimal division, Equivalent division (Spanish + visuals are in the lesson vocabulary).
  • Offer the sentence frames: “I know ___ because ___.” “First, I ___. Then, I ___.” “The answer is ___, so ___.”
  • Chunk the I-do steps; let students restate each step to a partner before moving on.
  • Provide the worked example as a reference while they practice.
