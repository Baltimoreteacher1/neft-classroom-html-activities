    A histogram shows these frequencies: 0–4: 3 players, 5–9: 8 players, 10–14: 12 players, 15–19: 5 players. How many players are represented in total?

    1. A20
    2. B15
    3. C28
    4. D12

    Add all frequencies: 3 + 8 + 12 + 5 = 28 players.

    Watch for: A common mistake in Display Data: Histograms is counting a boundary value in two intervals at once — for example, putting the value 10 in both the '0–9' bin and the '10–19' bin. Each data value belongs to exactly ONE interval. Before you submit, add up all your frequencies and check that the total matches the number of data values you started with.

  2. 2

    In a histogram, what does the height of each bar represent?

    1. AThe average of the data in that interval
    2. BThe range of the interval
    3. CThe median of the data
    4. DThe frequency (count) of data in that interval

    Each bar's height shows the frequency — how many data values fall within that interval.

    Watch for: A common mistake in Display Data: Histograms is counting a boundary value in two intervals at once — for example, putting the value 10 in both the '0–9' bin and the '10–19' bin. Each data value belongs to exactly ONE interval. Before you submit, add up all your frequencies and check that the total matches the number of data values you started with.

  3. 3

    How is a histogram different from a regular bar graph?

    1. AThere is no difference
    2. BHistogram bars touch (no gaps) because the intervals are continuous ranges
    3. CHistograms use colors and bar graphs don't
    4. DBar graphs show numbers and histograms show words

    In a histogram, bars touch because each interval connects to the next (0–9, 10–19, etc.) — the data is continuous.

    Watch for: A common mistake in Display Data: Histograms is counting a boundary value in two intervals at once — for example, putting the value 10 in both the '0–9' bin and the '10–19' bin. Each data value belongs to exactly ONE interval. Before you submit, add up all your frequencies and check that the total matches the number of data values you started with.

  4. 4

    A histogram has intervals: 0–4, 5–9, 10–14, 15–19. What is the width of each interval?

    1. A10
    2. B19
    3. C5
    4. D4

    Each interval covers 5 values (0,1,2,3,4 then 5,6,7,8,9 etc.), so the width is 5.

    2. 2

      Spot the Counting Mistake

      1. 1Data (points per game)3, 7, 11, 13, 16, 22
      2. 2Intervals0–9, 10–19, 20–29
      3. 3Frequency count0–9: 2, 10–19: 2, 20–29: 1
      4. 4ConclusionSo the histogram bars have heights 2, 2, and 1.

      Which step has the mistake? Explain it and write the correct work.

      The mistake is in Step 3. Correct work: The student missed a value in the 10–19 interval. The values 11, 13, AND 16 all fall in 10–19, so its frequency is 3, not 2. The correct frequency counts are 0–9: 2 (the 3 and 7), 10–19: 3 (the 11, 13, and 16), and 20–29: 1 (the 22), which totals 6 — the same as the 6 data values. There are 6 data values but the student's frequencies add to only 5, which is the tip-off. The interval 10–19 holds 11, 13, and 16, so its frequency is 3, making the correct bar heights 2, 3, and 1.

      A histogram of goals-per-game shows: 0–1: 9 players, 2–3: 6, 4–5: 3, 6–7: 1. What shape is this distribution?

      1. APerfectly symmetric
      2. BFlat / uniform (all bars equal)
      3. CSkewed right (most players low, tail toward high values)
      4. DSkewed left (most players high, tail toward low values)

      Find the tallest bars first: they are at the low end, 0–1. The bars shrink as goals increase. That means the tail stretches to the right. A tail pointing right means the distribution is skewed right.

    5. 5

      Spot the Interval Mistake

      1. 1Data (assists per game)1, 4, 6, 9, 12, 15, 18
      2. 2Intervals the student chose0–5, 6–10, 12–18
      3. 3Frequency count0–5: 2, 6–10: 2, 12–18: 3
      4. 4ConclusionThe student drew three bars and said the histogram was complete.

      Which step has the mistake? Explain it and write the correct work.

      The mistake is in Step 2. Correct work: The intervals are not equal in width and they leave a gap. 0–5 and 6–10 each cover 6 values, but 12–18 covers 7 values and the value 11 has no bin at all. Histogram intervals must be equal-width and cover every value with no gaps. Using equal intervals of 5 (0–4, 5–9, 10–14, 15–19) gives frequencies 0–4: 2 (the 1 and 4), 5–9: 2 (the 6 and 9), 10–14: 1 (the 12), and 15–19: 2 (the 15 and 18), totaling 7. The problem starts at the interval-choosing step: 0–5 and 6–10 are 6 wide, 12–18 is 7 wide, and the value 11 has nowhere to go. Equal-width bins of 5 fix both problems — 0–4: 2, 5–9: 2, 10–14: 1, 15–19: 2, totaling all 7 assist values.
