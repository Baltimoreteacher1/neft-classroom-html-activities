6.NS.3 Version A — Answer Key

Add and Subtract Decimals

Answer Key

Name: Date:
  1. 1

    What is 14.6 + 3.85?

    1. A18.45
    2. B18.35
    3. C17.45
    4. D18.55

    Line up decimals: 14.60 + 3.85. Hundredths: 0 + 5 = 5. Tenths: 6 + 8 = 14, write 4 carry 1. Ones: 4 + 3 + 1 = 8. Tens: 1. Answer: 18.45.

  2. 2

    What is 20.3 − 7.48?

    1. A12.82
    2. B13.82
    3. C12.92
    4. D12.18

    Rewrite as 20.30 − 7.48. Annex a zero so both have two decimal places. Work carefully with borrowing: 20.30 − 7.48 = 12.82.

  3. 3

    What is 9.05 + 4.7?

    1. A13.75
    2. B13.12
    3. C14.75
    4. D13.57

    Line up decimals: 9.05 + 4.70. Hundredths: 5 + 0 = 5. Tenths: 0 + 7 = 7. Ones: 9 + 4 = 13. Answer: 13.75.

  4. 4

    Show 6.5 − 2.8 and 3.25 + 1.5 on the number line

  5. 5

    What is 50 − 23.47?

    1. A26.53
    2. B27.53
    3. C26.63
    4. D27.47

    Rewrite 50 as 50.00. Then 50.00 − 23.47 = 26.53. You must borrow across multiple places.
