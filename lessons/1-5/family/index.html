Unit 1, Lesson 5: Math is Finding Patterns5.OA.B.3

A quick guide for families and for any student who missed class.

What students are learning

The value of each coin is a pattern. Noticing patterns — and the calculations that repeat — lets us solve problems we could never solve by counting one coin at a time.

Key idea: Write what you notice in a table. Look for the rule that stays the same from one step to the next. Then write that rule so you can predict what comes next.
Idea clave: Se anota en una tabla lo que se observa. Se busca la regla que se mantiene igual de un paso al siguiente. Luego se escribe esa regla para poder predecir lo que sigue.

Example

  1. A change jar is full of pennies, nickels, dimes, and quarters worth $53.50 in total. How many of each coin could there be?
  2. Each penny has a value of $0.01, so 100 pennies have a value of $1.00.
  3. Each nickel has a value of $0.05, so 100 nickels have a value of $5.00. Each dime has a value of $0.10, so 100 dimes have a value of $10. Each quarter has a value of $0.25, so 100 quarters have a value of $25.
  4. I multiply the number of each coin by its value. And I notice a generalization: because the jar's total, $53.50, ends in 0, the number of pennies can only be a multiple of 5.

Practice at home

  1. Ana is laying stepping stones along a garden path, and each new section of the path adds the same number of stones. Which way of thinking best fits the idea that math is finding patterns?
    1. Notice how the stones grow from section to section, use that rule to figure out longer paths, and check that the answer makes sense
    2. Draw the stones in a neat design, because patterns are mainly there to look nice
    3. Find the rule, but still count every single stone one at a time to be sure
    4. Find the rule once, and after that never check whether the totals make sense
