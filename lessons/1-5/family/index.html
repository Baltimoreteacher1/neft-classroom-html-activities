Unit 1, Lesson 5: Math is Finding Patterns5.OA.B.3

A quick guide for families and for any student who missed class.

What students are learning

The value of each coin is a pattern. Noticing patterns — and the calculations that repeat — lets us solve problems we could never solve by counting one coin at a time.

Key idea: We use the patterns and relationships we notice to solve problems, make generalizations, and check that our solutions are reasonable.

Key words

  • pattern — Something that repeats or changes in a predictable way.
    Español: patrón — Algo que se repite o cambia de una manera predecible.
  • pattern rule — The instruction that tells how to get from one number in a pattern to the next.
    Español: regla del patrón — La instrucción que dice cómo pasar de un número del patrón al siguiente.
  • generalization — A statement that is true for a whole pattern, made by noticing repeated calculations.
    Español: generalización — Una afirmación verdadera para todo un patrón, hecha al notar cálculos repetidos.
  • table of values — A table that lists each step of a pattern so you can check that a solution is reasonable.
    Español: tabla de valores — Una tabla que muestra cada paso de un patrón para comprobar que una solución es razonable.
  • reasonableness — Whether an answer makes sense — checked as you work, with adjustments made when needed.
    Español: sensatez del resultado — Si una respuesta tiene sentido — se comprueba mientras trabajas y se ajusta cuando es necesario.

Example

  1. A change jar is full of pennies, nickels, dimes, and quarters worth $53.50 in total. How many of each coin could there be?
  2. Each penny has a value of $0.01, so 100 pennies have a value of $1.00.
  3. Each nickel has a value of $0.05, so 100 nickels have a value of $5.00. Each dime has a value of $0.10, so 100 dimes have a value of $10. Each quarter has a value of $0.25, so 100 quarters have a value of $25.
  4. I multiply the number of each coin by its value. And I notice a generalization: because the jar's total, $53.50, ends in 0, the number of pennies can only be a multiple of 5.
