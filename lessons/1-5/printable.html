📚 Vocabulary

WordWhat it meansExample
pattern
patrón		Something that repeats or changes in a predictable way.
Algo que se repite o cambia de una manera predecible.		18, 20, 22, 24 … — The change is the same every step.
pattern rule
regla del patrón		The instruction that tells how to get from one number in a pattern to the next.
La instrucción que dice cómo pasar de un número del patrón al siguiente.		“Double the steps and add 1” — It tells you how to reach the next term from this one.
generalization
generalización		A statement that is true for a whole pattern, made by noticing repeated calculations.
Una afirmación verdadera para todo un patrón, hecha al notar cálculos repetidos.		“Any tower of n discs takes 2ⁿ − 1 steps.” — It covers every case, including ones you never played.
table of values
tabla de valores		A table that lists each step of a pattern so you can check that a solution is reasonable.
Una tabla que muestra cada paso de un patrón para comprobar que una solución es razonable.		Hours in one column and kilometers in the other — Each row pairs the two quantities at the same step.
reasonableness
sensatez del resultado		Whether an answer makes sense — checked as you work, with adjustments made when needed.
Si una respuesta tiene sentido — se comprueba mientras trabajas y se ajusta cuando es necesario.		Noticing 650 cannot be 5/6 of 540 and going back — You checked the answer against the situation and adjusted.

🚀 Launch

Akela's change jar is full of pennies, nickels, dimes, and quarters. The value of the coins is $53.50. How many of each coin could be in the jar? There is more than one answer — and patterns are the way in.

When we do math, we look for patterns and relationships

The value of each coin is a pattern. Noticing patterns — and the calculations that repeat — lets us solve problems we could never solve by counting one coin at a time.

Key idea: Math Practices: Patterns & Generalizations. 1. Organize observations into a table of values. 2. Identify the constant change or rule connecting inputs to outputs. 3. Write a general rule or expression to predict future terms

Watch me find the coin patterns

GIVEN DATA / MODEL
  • A change jar is full of pennies, nickels, dimes, and quarters worth $53.50 in total. How many of each coin could there be?
  • Each penny has a value of $0.01, so 100 pennies have a value of $1.00.
  • Each nickel has a value of $0.05, so 100 nickels have a value of $5.00. Each dime has a value of $0.10, so 100 dimes have a value of $10. Each quarter has a value of $0.25, so 100 quarters have a value of $25.
  • I multiply the number of each coin by its value. And I notice a generalization: because the jar's total, $53.50, ends in 0, the number of pennies can only be a multiple of 5.
STUDENT THINKING & SENTENCE FRAME

Because ___ , therefore ___ .

Let's build one combination together

GIVEN DATA / MODEL
  • Try 200 quarters: 200 × $0.25 = $50.00.
  • Add 25 dimes: 25 × $0.10 = $2.50, bringing the total to $52.50.
  • Add 15 nickels: 15 × $0.05 = $0.75, and 25 pennies: 25 × $0.01 = $0.25.
  • $50.00 + $2.50 + $0.75 + $0.25 = $53.50. It works — and 25 pennies is a multiple of 5, just as the pattern predicted. Now use the patterns to find a different combination.
