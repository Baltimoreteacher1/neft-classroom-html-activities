Teaching notes

Key idea: A power like 2³ is a short way to write repeated multiplication: 2 × 2 × 2.

I do:

  1. I want to find the value of 2³.
  2. The small 3 tells me to multiply 2 by itself 3 times.
  3. So I write 2 × 2 × 2.
  4. First 2 × 2 = 4. Then 4 × 2 = 8.
  5. So 2³ = 8.

You do: In the table, write each power as repeated multiplication and find its value. Start with 2⁴ = 2 × 2 × 2 × 2.

Common misconception

A common mistake in Powers and Exponents is multiplying the base by the exponent instead of using the base as a repeated factor — for example, thinking 2³ = 2 × 3 = 6 instead of 2³ = 2 × 2 × 2 = 8. Before you submit, rewrite the power as repeated multiplication first, then multiply step by step.

ESOL / SPED supports

  • Pre-teach: Powers and Exponents, Exponent, Base, Power, Evaluate (Spanish + visuals are in the lesson vocabulary).
  • Offer the sentence frames: “I know ___ because ___.” “First, I ___. Then, I ___.” “The answer is ___, so ___.”
  • Chunk the I-do steps; let students restate each step to a partner before moving on.
  • Provide the worked example as a reference while they practice.

Exit ticket

What is the value of 3⁴?

  • 81 ✓ correct
  • 12
  • 34
  • 64

3⁴ means use 3 as a factor 4 times: 3 × 3 × 3 × 3 = 81. Choosing 12 means you multiplied the base by the exponent (3 × 4) instead of repeating the base as a factor. Choosing 34 means you just wrote the base and exponent digits side by side instead of evaluating. Choosing 64 mixes up this base and exponent with 4³ (4 × 4 × 4 = 64).
