Lesson 6.6Identify Equivalent Algebraic Expressions

Version A · Answer KeySupported practice

Learning target I can show that two expressions are equivalent by simplifying and combining like terms.

Part 1Understand the ideamodels and meaning
  1. 1Circle the letter of the best answer. Show how you know.

    Which expression is equivalent to 4x + 3x?

    1. A7x
    2. B7x²
    3. C12x
    4. D43x

    Hint 4x and 3x share the exact same variable, x — that makes them like terms.

    Answer: A — 7x

    Why: 4x + 3x = 7x. Combine the coefficients: 4 + 3 = 7.

    Watch for: A common mistake in Equivalent Expressions is adding the exponents instead of the coefficients when combining like terms — writing 3x + 2x as 5x² instead of 5x. Remember: 3x means 3 groups of x and 2x means 2 more groups of x, so you add the coefficients (3 + 2 = 5) and keep the variable's power the same (x¹, not x²).

  2. 2Circle the letter of the best answer. Show how you know.

    Which expression is equivalent to 2(m + 5)?

    1. A2m + 10
    2. B2m + 5
    3. C7m
    4. Dm + 10

    Hint The 2 outside the parentheses must multiply both the m and the 5.

    Answer: A — 2m + 10

    Why: 2(m + 5) = 2m + 10 using the distributive property.

    Watch for: A common mistake in Equivalent Expressions is adding the exponents instead of the coefficients when combining like terms — writing 3x + 2x as 5x² instead of 5x. Remember: 3x means 3 groups of x and 2x means 2 more groups of x, so you add the coefficients (3 + 2 = 5) and keep the variable's power the same (x¹, not x²).

  3. 3Write the name of the correct group on each line.

    Sort each pair of expressions by whether they are equivalent or not.

    Groups: Equivalent Not Equivalent
    • Equivalent3x + 2x and 5x
    • Equivalent2(n + 4) and 2n + 8
    • Not Equivalent4a + 3 and 7a
    • Equivalentx + x and 2x
    • Not Equivalent3y + 2 and 5y

    Hint Equivalent means always equal. Simplify the first expression in each pair and compare with the second.

    Why: Simplify the first expression on each card and see whether it matches the second. 3x + 2x = 5x, 2(n + 4) = 2n + 8, and x + x = 2x, so those three pairs are equivalent. 4a + 3 and 3y + 2 cannot be combined at all, because a plain number is not a like term with a variable term — so 4a + 3 is not 7a and 3y + 2 is not 5y.

Part 2Apply itreal-world problems
  1. 4Circle the letter of the best answer. Show how you know.

    Which property is shown: 3(x + 7) = 3x + 21?

    1. ACommutative
    2. BDistributive
    3. CAssociative
    4. DIdentity

    Hint Watch what happened to the 3: it multiplied the x AND the 7 across the parentheses.

    Answer: B — Distributive

    Why: Multiplying 3 by each term inside the parentheses is the distributive property.

    Watch for: A common mistake in Equivalent Expressions is adding the exponents instead of the coefficients when combining like terms — writing 3x + 2x as 5x² instead of 5x. Remember: 3x means 3 groups of x and 2x means 2 more groups of x, so you add the coefficients (3 + 2 = 5) and keep the variable's power the same (x¹, not x²).

  2. 5Circle the letter of the best answer. Show how you know.

    Simplify: 5n + 2n

    1. A7n
    2. B7n²
    3. C10n
    4. D52n

    Hint 5n and 2n both have the variable n — they're like terms, so they can combine.

    Answer: A — 7n

    Why: 5n + 2n = 7n. Add the coefficients: 5 + 2 = 7. The variable stays as n.

    Watch for: A common mistake in Equivalent Expressions is adding the exponents instead of the coefficients when combining like terms — writing 3x + 2x as 5x² instead of 5x. Remember: 3x means 3 groups of x and 2x means 2 more groups of x, so you add the coefficients (3 + 2 = 5) and keep the variable's power the same (x¹, not x²).

Part 3Explain and correctreasoning
  1. 6Find the mistake. Explain it, then show the correct work.

    Spot the Distributive Mistake

    1. 1Expression3(x + 4)
    2. 2DistributeMultiply the 3 by the first term only: 3 · x + 4
    3. 3Result3(x + 4) = 3x + 4

    Which step has the mistake? Explain what went wrong, then show the correct work.

    Hint How many terms are inside the parentheses? The 3 multiplies each one.

    Mistake: Step 2. The 3 sits outside parentheses that hold two terms, so it must multiply BOTH of them: 3 · x + 3 · 4 = 3x + 12. Multiplying only the x leaves the 4 untouched. Testing x = 2 shows the difference: 3(2 + 4) = 18 and 3(2) + 12 = 18, but 3(2) + 4 = 10.

    Correct work: The 3 must multiply BOTH terms inside the parentheses, not just the first one: 3 · x + 3 · 4 = 3x + 12. Check x = 2: 3(2 + 4) = 18 and 3(2) + 12 = 18, but 3(2) + 4 = 10 — so 3x + 4 is wrong.

    Match each expression with its simplified form.

    Groups: Correctly Matched
    • Correctly Matched8y + 2y → 10y
    • Correctly Matched3(a + 6) → 3a + 18
    • Correctly Matched5n + 4 + 2n → 7n + 4
    • Correctly Matched9p − 3p → 6p
    • Correctly Matched4(2x − 1) → 8x − 4

    Why: Every card on this deck checks out. 8y + 2y = 10y and 6t + t = 7t come from adding coefficients, 9p − 3p = 6p from subtracting them, and 5n + 4 + 2n = 7n + 4 combines only the n terms while the 4 stays put. The other two come from distributing to BOTH terms inside the parentheses: 3(a + 6) = 3a + 18 and 4(2x − 1) = 8x − 4.

  2. 2Write the letter of the matching item on each line.

    Match each expression to its simplified equivalent.

    1. A6x + 2x
    2. B3(n + 5)
    3. C4a + 7 + a
    4. D2(3y − 4)
    5. E10m − 4m + 1
    6. F5(x + 2)
    • A8x
    • B3n + 15
    • C5a + 7
    • D6y − 8

    • F5x + 10

    Why: Each expression on the left simplifies to exactly one card on the right. Combining like terms gives 6x + 2x = 8x, 4a + 7 + a = 5a + 7, and 10m − 4m + 1 = 6m + 1. Distributing gives 3(n + 5) = 3n + 15, 2(3y − 4) = 6y − 8, and 5(x + 2) = 5x + 10, since the outside factor multiplies both terms inside.

  3. 3Complete the table. Show how you found each value.

    Simplify each expression. Then evaluate both the original and simplified form when x = 3 to verify they are equivalent.

    OriginalSimplifiedValue when x = 3
    2x + 5x + 1
    4(x + 2)
    3x + 4 + x − 1

    Why: Simplify first, then substitute to check. 2x + 5x + 1 = 7x + 1, and at x = 3 that is 21 + 1 = 22. 4(x + 2) = 4x + 8, and at x = 3 that is 12 + 8 = 20. 3x + 4 + x − 1 = 4x + 3, and at x = 3 that is 12 + 3 = 15. Each simplified form gives the same value as the original, which is exactly what equivalent means.

Part 2Explain and correctreasoning
  1. 5Find the mistake. Explain it, then show the correct work.

    Spot the Combining Mistake

    1. 1Expression7x + 3 + 2x
    2. 2CombineCombine every number you see: 7x + 2x + 3 = 9x + 3, then add the 9 and 3 too
    3. 3Result7x + 3 + 2x = 12x

    Which step has the mistake? Explain what went wrong, then show the correct work.

    Mistake: Step 2. 7x and 2x are like terms, so 7x + 2x = 9x is fine — but the step keeps going and adds the 9 to the 3. A constant like 3 has no variable, so it cannot join 9x in one term. The simplified form is 9x + 3. Check with x = 2: 7(2) + 3 + 2(2) = 21 and 9(2) + 3 = 21, but 12(2) = 24.

    Correct work: Only LIKE terms combine. 7x and 2x are like terms (7x + 2x = 9x), but the 3 is a constant and cannot be added to the 9x. The simplified form is 9x + 3. Check x = 2: 7(2) + 3 + 2(2) = 21 and 9(2) + 3 = 21, but 12(2) = 24 — so 12x is wrong.

Part 1Understand the ideamodels and meaning
  1. 1Complete the table. Show how you found each value.

    For each expression, find an equivalent expression using a DIFFERENT method (distributive property, combining like terms, or factoring).

    ExpressionEquivalent FormMethod Used
    4x + 8
    3a + 2a + 5
    6(n − 2)

    Why: Each row asks for a different-looking but equal form. 4x + 8 has terms that share a factor of 4, so factor it: 4(x + 2). 3a + 2a + 5 has like terms to combine: 5a + 5. And 6(n − 2) has parentheses to distribute: 6n − 12. All three moves change how the expression looks without changing its value.

Part 2Explain and correctreasoning
  1. 2Find the mistake. Explain it, then show the correct work.

    Find the Simplification Error

    1. 1Expression3x + 5 + 2x + 1
    2. 2Combine3x + 2x + 5 + 1
    3. 3Simplify5x² + 6

    Which step has the mistake? Explain what went wrong, then show the correct work.

    Mistake: Step 3. Rearranging to 3x + 2x + 5 + 1 is correct. The error is in the last step: combining like terms adds the COEFFICIENTS, so 3x + 2x = 5x, not 5x². The exponent never changes when you add like terms, so the answer is 5x + 6.

    Correct work: 3x + 2x = 5x (NOT 5x²). When you combine like terms, you add the coefficients, not multiply them. The correct answer is 5x + 6.

  2. 3Answer in complete sentences.

    A student says 2x + 3 and 5x are equivalent because both equal 5 when x = 1. Is the student correct? Explain why testing one value is not enough to prove equivalence, and find a value of x where they give different results.

    Look for: equivalent, substitute, all values, counterexample, not equal, test

    Why: The student is not correct. Both expressions really do equal 5 when x = 1, but equivalence means equal for EVERY value of x, and one lucky match proves nothing. Testing x = 2 gives 2(2) + 3 = 7 while 5(2) = 10 — that single counterexample settles it.
