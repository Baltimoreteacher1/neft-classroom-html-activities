SECTION 1 CONCEPTUAL UNDERSTANDING & VISUAL MODELS [Visual Modeling]
  1. 1 MULTIPLE CHOICE

    Which expression is equivalent to 4x + 3x?

    1. A7x
    2. B7x²
    3. C12x
    4. D43x

    💡 Solution Rationale: 4x + 3x = 7x. Combine the coefficients: 4 + 3 = 7.

    ⚠️ Watch for (Misconception): A common mistake in Equivalent Expressions is adding the exponents instead of the coefficients when combining like terms — writing 3x + 2x as 5x² instead of 5x. Remember: 3x means 3 groups of x and 2x means 2 more groups of x, so you add the coefficients (3 + 2 = 5) and keep the variable's power the same (x¹, not x²).

  2. 2 MULTIPLE CHOICE

    Which expression is equivalent to 2(m + 5)?

    1. A2m + 10
    2. B2m + 5
    3. C7m
    4. Dm + 10

    💡 Solution Rationale: 2(m + 5) = 2m + 10 using the distributive property.

    ⚠️ Watch for (Misconception): A common mistake in Equivalent Expressions is adding the exponents instead of the coefficients when combining like terms — writing 3x + 2x as 5x² instead of 5x. Remember: 3x means 3 groups of x and 2x means 2 more groups of x, so you add the coefficients (3 + 2 = 5) and keep the variable's power the same (x¹, not x²).

    SECTION 3 MATHEMATICAL WRITING & ERROR ANALYSIS [Reasoning & Critique]
    1. 6 ERROR ANALYSIS

      Spot the Distributive Mistake

      1. 1Expression:3(x + 4)
      2. 2Distribute:Multiply the 3 by the first term only: 3 · x + 4
      3. 3Result:3(x + 4) = 3x + 4

      Which step contains the error? Explain the mathematical misconception and write the correct calculation below.

      Key Analysis: Mistake is in Step 2. Correct Work: The 3 must multiply BOTH terms inside the parentheses, not just the first one: 3 · x + 3 · 4 = 3x + 12. Check x = 2: 3(2 + 4) = 18 and 3(2) + 12 = 18, but 3(2) + 4 = 10 — so 3x + 4 is wrong.. Misconception: The 3 sits outside parentheses that hold two terms, so it must multiply BOTH of them: 3 · x + 3 · 4 = 3x + 12. Multiplying only the x leaves the 4 untouched. Testing x = 2 shows the difference: 3(2 + 4) = 18 and 3(2) + 12 = 18, but 3(2) + 4 = 10.

      SECTION 2 MATHEMATICAL WRITING & ERROR ANALYSIS [Reasoning & Critique]
      1. 5 ERROR ANALYSIS

        Spot the Combining Mistake

        1. 1Expression:7x + 3 + 2x
        2. 2Combine:Combine every number you see: 7x + 2x + 3 = 9x + 3, then add the 9 and 3 too
        3. 3Result:7x + 3 + 2x = 12x

        Which step contains the error? Explain the mathematical misconception and write the correct calculation below.

        Key Analysis: Mistake is in Step 2. Correct Work: Only LIKE terms combine. 7x and 2x are like terms (7x + 2x = 9x), but the 3 is a constant and cannot be added to the 9x. The simplified form is 9x + 3. Check x = 2: 7(2) + 3 + 2(2) = 21 and 9(2) + 3 = 21, but 12(2) = 24 — so 12x is wrong.. Misconception: 7x and 2x are like terms, so 7x + 2x = 9x is fine — but the step keeps going and adds the 9 to the 3. A constant like 3 has no variable, so it cannot join 9x in one term. The simplified form is 9x + 3. Check with x = 2: 7(2) + 3 + 2(2) = 21 and 9(2) + 3 = 21, but 12(2) = 24.

      1. 2 ERROR ANALYSIS

        Find the Simplification Error

        1. 1Expression:3x + 5 + 2x + 1
        2. 2Combine:3x + 2x + 5 + 1
        3. 3Simplify:5x² + 6

        Which step contains the error? Explain the mathematical misconception and write the correct calculation below.

        Key Analysis: Mistake is in Step 3. Correct Work: 3x + 2x = 5x (NOT 5x²). When you combine like terms, you add the coefficients, not multiply them. The correct answer is 5x + 6.. Misconception: Rearranging to 3x + 2x + 5 + 1 is correct. The error is in the last step: combining like terms adds the COEFFICIENTS, so 3x + 2x = 5x, not 5x². The exponent never changes when you add like terms, so the answer is 5x + 6.
      2. 3 OPEN RESPONSE

        A student says 2x + 3 and 5x are equivalent because both equal 5 when x = 1. Is the student correct? Explain why testing one value is not enough to prove equivalence, and find a value of x where they give different results.

        💡 Exemplar Response: Key Terms to Look For: equivalent, substitute, all values, counterexample, not equal, test Explanation: The student is not correct. Both expressions really do equal 5 when x = 1, but equivalence means equal for EVERY value of x, and one lucky match proves nothing. Testing x = 2 gives 2(2) + 3 = 7 while 5(2) = 10 — that single counterexample settles it.
