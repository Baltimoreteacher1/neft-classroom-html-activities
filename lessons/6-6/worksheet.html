6.EE.4 Version A — Answer Key

Equivalent Expressions

Answer Key

Name: Date:
  1. 1

    Which expression is equivalent to 4x + 3x?

    1. A7x
    2. B12x
    3. C7x²
    4. D43x

    4x + 3x = 7x. Combine the coefficients: 4 + 3 = 7.

  2. 2

    Which expression is equivalent to 2(m + 5)?

    1. A2m + 10
    2. B2m + 5
    3. Cm + 10
    4. D7m

    2(m + 5) = 2m + 10 using the distributive property.

  3. 3

    Which property is shown: 3(x + 7) = 3x + 21?

    1. ADistributive
    2. BCommutative
    3. CAssociative
    4. DIdentity

    Multiplying 3 by each term inside the parentheses is the distributive property.

  4. 4

    Simplify: 5n + 2n

    1. A7n
    2. B10n
    3. C7n²
    4. D52n

    5n + 2n = 7n. Add the coefficients: 5 + 2 = 7. The variable stays as n.

  5. 5

    Sort each pair of expressions by whether they are equivalent or not.

    Categories: equivalent · not-equivalent

    • equivalent3x + 2x and 5x
    • equivalent2(n + 4) and 2n + 8
    • not-equivalent4a + 3 and 7a
    • equivalentx + x and 2x
    • not-equivalent3y + 2 and 5y
