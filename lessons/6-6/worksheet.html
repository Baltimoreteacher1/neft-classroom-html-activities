  1. 1

    Which expression is equivalent to 4x + 3x?

    1. A7x
    2. B12x
    3. C7x²
    4. D43x

    4x + 3x = 7x. Combine the coefficients: 4 + 3 = 7.

    Watch for: A common mistake in Equivalent Expressions is adding the exponents instead of the coefficients when combining like terms — writing 3x + 2x as 5x² instead of 5x. Remember: 3x means 3 groups of x and 2x means 2 more groups of x, so you add the coefficients (3 + 2 = 5) and keep the variable's power the same (x¹, not x²).

    1. 1Expression3(x + 4)
    2. 2DistributeMultiply the 3 by the first term only: 3 · x + 4

Multiplying only the x leaves the 4 untouched. Testing x = 2 shows the difference: 3(2 + 4) = 18 and 3(2) + 12 = 18, but 3(2) + 4 = 10.

    1. 1Expression7x + 3 + 2x

Check x = 2: 7(2) + 3 + 2(2) = 21 and 9(2) + 3 = 21, but 12(2) = 24 — so 12x is wrong. 7x and 2x are like terms, so 7x + 2x = 9x is fine — but the step keeps going and adds the 9 to the 3.     1. 1Expression3x + 5 + 2x + 1

    Which step has the mistake? Explain it and write the correct work.

    The mistake is in Step 3. Correct work: 3x + 2x = 5x (NOT 5x²). When you combine like terms, you add the coefficients, not multiply them. The correct answer is 5x + 6. Rearranging to 3x + 2x + 5 + 1 is correct. The error is in the last step: combining like terms adds the COEFFICIENTS, so 3x + 2x = 5x, not 5x². The exponent never changes when you add like terms, so the answer is 5x + 6.
