Question 1Two-part question

Part A

A class has 12 sixth graders and 18 seventh graders. What is the ratio of sixth graders to the TOTAL number of students, written in simplest form?

Fill in the bubble next to the one best answer.

  • A2 : 5
  • B2 : 3
  • C3 : 5
  • D12 : 18

Part B

Answer Part A before Part B — Part B asks about your reasoning.

Which statement explains why 2 : 3 is NOT the answer to Part A?

  • A2 : 3 is the part-to-part ratio of sixth graders to seventh graders, not part-to-whole.
  • B2 : 3 has not been simplified completely.
  • C2 : 3 reverses the order of the quantities.
  • D2 : 3 counts each student twice.
Question 2Select all that apply

Select ALL statements that are true about ratios:

Mark the box next to EVERY answer that is true. More than one is correct.

  • AThe order of the quantities in a ratio matters.

  • C3 : 4 and 6 : 8 describe the same relationship.
