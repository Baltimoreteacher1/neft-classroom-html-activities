    Spot the Common Mistake

    1. 1CluePlot the point (4, 0).
    2. 2Move rightMove 4 units to the right along the x-axis. Good.
    3. 3Move upMove 4 units up, because the pair has a 4 in it.
    4. 4Plot the pointPlace the dot at (4, 4).

    Which step has the mistake? Explain it and write the correct work.

    The mistake is in Step 3. Correct work: The y-coordinate is 0, not 4. After moving 4 right, the up move is 0 units, so the point stays on the x-axis at (4, 0). The student reused the x-value instead of reading the second number (0). The up move comes from the SECOND number, and the second number in (4, 0) is 0. Reusing the 4 pushes the point off the axis to (4, 4). With a y-coordinate of 0 there is no upward move at all, so the point stays right on the x-axis at (4, 0).

  2. 2

    Miscounted Grid Lines

    1. 1Ordered pair(7, 3)
    2. 2Move along the x-axisStart at the origin (0, 0) and count 7 units to the right.
    3. 3Move along the y-axisCount up from the x-axis: 1, 2, 3, 4 — stop on 4.
    4. 4Plot the pointPlace the dot at (7, 4).

    Which step has the mistake? Explain it and write the correct work.

    The mistake is in Step 3. Correct work: The x-axis itself is 0, not 1. Counting up correctly: 1, 2, 3 — the third count lands on y = 3, so the point is (7, 3), not (7, 4). The student started counting one gridline too high by treating the x-axis as unit 1 instead of unit 0. Counting up has to start with the x-axis as 0, not 1. The first line above the x-axis is 1, the second is 2, and the third is 3, so 3 units up lands on y = 3. Treating the axis itself as unit 1 pushes every count one gridline too high, which is how (7, 3) turned into (7, 4).

  3. 3

    A student says that (3, 5) and (5, 3) are the same point because they use the same numbers. Is the student correct? Explain why or why not, and describe where each point is located on the coordinate plane.

    Look for: order, x-coordinate, y-coordinate, horizontal, vertical, different, right, up.

  4. 4

    Spot 1 — Captain Vega's first clue says the Sandy Dock is right 7 and up 2 from the origin. Which ordered pair names the Sandy Dock?

    1. A(7, 2)
    2. B(2, 7)
    3. C(7, 0)
    4. D(2, 2)

    The x-coordinate is the sideways move (right 7) and the y-coordinate is the up move (up 2), so the Sandy Dock is (7, 2).

    Watch for: A common mistake in Graph on the Coordinate Plane is swapping the order of the coordinates — moving up/down first instead of right/left first. For example, when plotting (5, 2), students often move up 5 and right 2, landing on the wrong point (2, 5) instead of (5, 2). Remember: the x-coordinate (first number) always tells you how far to move right or left along the x-axis; the y-coordinate (second number) tells you how far up or down along the y-axis.

    Level 2 Extension — Captain Vega's Misread Coordinate

    1. 1ClueThe Pirate Flag is at (3, 6).
    2. 2Read the x-coordinateMove 3 units to the right along the x-axis.
    3. 3Read the y-coordinateMove 1 unit up along the y-axis.
    4. 4Plot the pointPlace the flag where (3, 1) would go.

    Which step has the mistake? Explain it and write the correct work.

    The mistake is in Step 3. Correct work: The x move is correct (3 right), but the y-coordinate is 6, not 1. The navigator should move 6 units up, placing the flag at (3, 6) — not (3, 1). The x move is right: 3 units across. The mistake is the y move — the second number in (3, 6) is 6, not 1, so the flag should rise 6 units after the 3 right. Placing it at (3, 1) puts the Pirate Flag five units too low.
