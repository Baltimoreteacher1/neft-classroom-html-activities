Unit 7, Lesson 3: Understand Absolute Value of Rational Numbers

Standard 6.NOS.8

What students are learning Qué aprenden

Key idea: The absolute value of a number is how far it is from 0 on the number line. Distance is never negative, so |-7| = 7 and |7| = 7. This works for fractions and decimals too: |-2.5| = 2.5.
Idea clave: El valor absoluto de un número es qué tan lejos está del 0 en la recta numérica. Una distancia nunca es negativa, así que |-7| = 7 y |7| = 7. También sirve para fracciones y decimales: |-2.5| = 2.5.

Try at home Para hacer en casa

Draw a number line from −10 to 10. Find the distance from 0 for −6, 4 and −2.5 by counting steps. Write each as |number| = distance. Then write two different numbers that have the same absolute value.

Dibuja una recta numérica de −10 a 10. Halla la distancia al 0 de −6, 4 y −2.5 contando pasos. Escribe cada una como |número| = distancia. Luego escribe dos números distintos que tengan el mismo valor absoluto.

Talk about it:

How far is this number from 0? Can a distance ever be negative?

¿A qué distancia del 0 está este número? ¿Una distancia puede ser negativa?

How we did it in class today Cómo lo hicimos hoy en clase

  1. I want to find the absolute value of -6, written |-6|.
  2. I find -6 on the number line. It sits 6 steps to the left of zero.
  3. Distance does not care about direction, so -6 is 6 units from zero.
  4. So |-6| = 6. Even though -6 is negative, its absolute value is positive 6.
