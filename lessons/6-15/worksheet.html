    Simplify 7x + 3x.

    1. A10x
    2. B10x²
    3. C21x
    4. D73x

    7x + 3x = 10x. Add the coefficients: 7 + 3 = 10.

    Watch for: A common mistake in Simplify Algebraic Expressions is sweeping a constant into the variable terms — for example, simplifying 6x + 4 + 2x as 12x by adding all three numbers (6 + 4 + 2 = 12) instead of recognizing that 4 has no variable and cannot combine with 6x and 2x. The correct simplified expression is 8x + 4 (combine 6x + 2x = 8x, and let the 4 stay on its own). Before you submit, check that every term you combined has the exact same variable part.

    Spot the Mistake — Exponent Slip

    1. 1Expression4x + 3x
    2. 2CombineAdd the coefficients: 4 + 3 = 7
    3. 3Simplify7x²

    Which step has the mistake? Explain it and write the correct work.

    The mistake is in Step 3. Correct work: 4x and 3x are like terms, so add the coefficients 4 + 3 = 7 and KEEP the variable exactly as it is: the answer is 7x, not 7x². Adding like terms never changes the exponent on the variable. (Check: at x = 2, 4x + 3x = 8 + 6 = 14, and 7x = 14, but 7x² = 28.) Adding the coefficients 4 + 3 = 7 was right, but the Simplify step also changed x into x². Combining like terms only counts how many x's you have, so 4x + 3x = 7x — check it at x = 2, where 8 + 6 = 14 matches 7x but not 7x² = 28.

The Combine step swept the constant 4 in with the coefficients 6 and 2, but 4 has no variable, so it is not a like term. Only 6x + 2x = 8x combine, and the 4 stays on its own, giving 8x + 4 — at x = 2 that is 20, while 12x would give 24.

    Find the Simplification Error

    1. 1Expression5x + 3 + 2y + 4x
    2. 2Combine5x + 2y + 4x + 3
    3. 3Simplify11xy + 3

    Which step has the mistake? Explain it and write the correct work.

    The mistake is in Step 3. Correct work: 5x + 4x = 9x (like terms). 2y stays separate (no other y-term). The constant 3 stays. Correct answer: 9x + 2y + 3. You cannot combine x-terms and y-terms into xy. The Simplify step merged the x-terms and the y-term into 11xy, but terms with different variables can never be combined. Only 5x + 4x = 9x are like terms; 2y and the constant 3 each stand alone, so the expression simplifies to 9x + 2y + 3.
