Lesson 6-15: Simplify Algebraic Expressions

Grade 6 Mathematics · Standard 6.AT.7

Part A — Skills Check

One point each.

Question 1Selected response — correct: A

Simplify 7x + 3x.

  • A10x
  • B10x²
  • C21x
  • D73x

7x + 3x = 10x. Add the coefficients: 7 + 3 = 10.

Question 2Selected response — correct: A

Simplify 9n + 4 + 2n.

  • A11n + 4
  • B11n² + 4
  • C15n
  • D92n + 4

9n + 2n = 11n. The constant 4 has no like term, so it stays. Result: 11n + 4.

Question 3Selected response — correct: A

Which pair are like terms?

  • A6x and 2x
  • B6x and 6y
  • C6x and 6
  • D6x and 2x²

6x and 2x are like terms because they both have the same variable (x) raised to the same power (1).

Question 4Selected response — correct: A

Simplify 5a + 3 + 2a.

  • A7a + 3
  • B7a² + 3
  • C10a
  • D52a + 3

5a + 2a = 7a. The constant 3 stays. Result: 7a + 3.

Question 5Selected response — correct: A

The board shows 3x + 5x on one channel. Simplify it.

  • A8x
  • B8x²
  • C15x
  • D35x

3x and 5x are like terms, so add the coefficients: 3 + 5 = 8. The variable x stays, giving 8x.

Question 6Selected response — correct: A

Simplify the track: 4a + 2 + a.

  • A5a + 2
  • B5a²+ 2
  • C6a
  • D7a

4a + a = 5a (remember a means 1a). The 2 has no like term, so it stays. Result: 5a + 2.

Part B — Test-Format Questions

Scoring notes and distractor rationales below each item.

Question 7Two-part question

Part A — correct answer: B

Simplify the expression 8x + 3 + 2x − 1.

  • A6x + 2
  • B10x + 2
  • C10x + 4
  • D12x

The terms 8x and 2x are like terms, so add their coefficients: 8 + 2 = 10, giving 10x. The constants 3 and −1 combine to 2. The simplified expression is 10x + 2.

  • A: The x terms were subtracted. Both are positive, so 8 plus 2 gives 10x.
  • C: The constants were added as 3 plus 1. The second is minus 1, so they combine to 2.
  • D: The constants were folded in with the x terms. 3 and negative 1 are not like terms with 8x.

Part B — correct answer: A

Which reasoning shows why your answer to Part A is correct?

  • A8x and 2x share the same variable part, so add their coefficients to get 10x. The constants 3 and −1 combine separately to 2, giving 10x + 2.
  • BCombine every number in the expression into one coefficient: 8 + 3 + 2 − 1 = 12, giving 12x.
  • CSubtract the coefficients of the variable terms: 8 − 2 = 6, giving 6x + 2.
  • DAdd the coefficients of the variable terms and then add both constants: 10x + 4.

Only terms with the same variable part can be combined, and constants combine with constants. The constant 1 is being subtracted, so 3 − 1 = 2, and the x terms are added, not subtracted.

Question 8Select all that apply — correct: A, B, C, E

Select ALL statements that are true about the expression 5y + 7 + 3y + y.

  • A5y, 3y, and y are like terms.
  • BThe coefficient of the term y is 1.
  • CThe simplified expression is 9y + 7.
  • DThe simplified expression is 16y.
  • E7 is a constant and cannot be combined with the y terms.
  • FThe simplified expression is 8y + 7.

All three variable terms have the same variable part y, so they are like terms. A term written as y has an understood coefficient of 1, so 5 + 3 + 1 = 9, giving 9y. The constant 7 has no variable and stays separate, so the simplified expression is 9y + 7. The answer 8y + 7 leaves out the coefficient 1, and 16y wrongly folds the constant into the variable terms.

Model answer and scoring guidance.

Question 9Written response · 2 points

Three students simplified 4x + 3 + 2x + 5 + x differently. Student A got 7x + 8. Student B got 7x² + 8. Student C got 6x + 9. Who is correct? Explain the mistakes the other two students made.

Model answer: Student A is correct: 4x + 2x + x = 7x (the lone x counts as 1x) and 3 + 5 = 8, giving 7x + 8. Student B added the coefficients correctly but changed x into x², which combining like terms never does, and Student C left out the lone x and instead pulled a 1 into the constants, landing on 6x + 9.

Award 2 points for a complete explanation with correct mathematics, 1 point for a correct answer with thin reasoning, 0 for an unrelated response.
