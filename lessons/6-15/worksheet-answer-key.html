    Hint Like terms match in BOTH the variable letter and its exponent. Plain numbers only pair with plain numbers.

    Why: Terms are alike only when the variable AND its exponent match: 4m and 7m, 5n and n, and 6a and 9a all pass that test. The pairs 3x and 3y use different letters, 8 and 2p pair a constant with a variable term, and 2x² and 2x use different exponents, so none of those can be combined.

    Spot the Mistake — Exponent Slip

    1. 1Expression4x + 3x
    2. 2CombineAdd the coefficients: 4 + 3 = 7
    3. 3Simplify7x²

    Which step has the mistake? Explain what went wrong, then show the correct work.

    Hint When you add like terms, does the little exponent on x change?

    Mistake: Step 3. Adding the coefficients 4 + 3 = 7 was right, but the Simplify step also changed x into x². Combining like terms only counts how many x's you have, so 4x + 3x = 7x — check it at x = 2, where 8 + 6 = 14 matches 7x but not 7x² = 28.

    Correct work: 4x and 3x are like terms, so add the coefficients 4 + 3 = 7 and KEEP the variable exactly as it is: the answer is 7x, not 7x². Adding like terms never changes the exponent on the variable. (Check: at x = 2, 4x + 3x = 8 + 6 = 14, and 7x = 14, but 7x² = 28.)

Part 1Understand the ideamodels and meaning
  1. 1Complete the table. Show how you found each value.

    Simplify each expression by combining like terms.

    ExpressionLike Terms CombinedSimplified
    3a + 5a + 23a + 5a = 8a
    6x + 4 + 2x + 7
    10m − 3m + 5
    4y + 3 + y + 9

    Why: In each row you combine the variable terms and the constants separately: 3a + 5a = 8a leaves 8a + 2; 6x + 2x = 8x with 4 + 7 = 11 gives 8x + 11; 10m − 3m = 7m gives 7m + 5; and 4y + y = 5y with 3 + 9 = 12 gives 5y + 12. The constants never merge with the variable terms because they have no variable.

  2. 2Write the letter of the matching item on each line.

    Match each expression to its simplified form.

    1. A8x + 3x + 1
    2. B5a − 2a + 7
    3. C4n + n + 6
    4. D12y − 5y
    5. E3m + 8 + 4m + 2
    6. F9p + 1 − 3p
    • A11x + 1
    • B3a + 7
    • C5n + 6
    • D7y
    • E7m + 10
    • F6p + 1

    Why: Each match comes from combining like terms and carrying the signs: 8x + 3x + 1 = 11x + 1, 5a − 2a + 7 = 3a + 7, 4n + n + 6 = 5n + 6 (the lone n counts as 1n), 12y − 5y = 7y, 3m + 4m = 7m with 8 + 2 = 10 for 7m + 10, and 9p − 3p = 6p leaves 6p + 1.

  3. 3Write the name of the correct group on each line.

    Simplify each expression, then sort by whether the simplified coefficient of the variable is greater than 6 or not.

    Groups: Coefficient > 6 Coefficient ≤ 6
    • Coefficient > 64x + 5x
    • Coefficient ≤ 68n − 3n
    • Coefficient > 63a + a + 4a
    • Coefficient ≤ 610m − 7m
    • Coefficient > 62y + 5y
    • Coefficient ≤ 66p − p

    Why: Combining like terms gives each card's coefficient, and that number is what you compare to 6: 9x, 8a, and 7y are all greater than 6, while 5n, 3m, and 5p (from 6p − p, since the lone p is 1p) are 6 or less. Only the coefficient changes when you combine — the variable stays the same.

Part 2Explain and correctreasoning
  1. 5Find the mistake. Explain it, then show the correct work.

    Spot the Mistake — Swept-Up Constant

    1. 1Expression6x + 4 + 2x
    2. 2CombineAdd everything: 6 + 4 + 2 = 12
    3. 3Simplify12x

    Which step has the mistake? Explain what went wrong, then show the correct work.

    Mistake: Step 2. The Combine step swept the constant 4 in with the coefficients 6 and 2, but 4 has no variable, so it is not a like term. Only 6x + 2x = 8x combine, and the 4 stays on its own, giving 8x + 4 — at x = 2 that is 20, while 12x would give 24.

    Correct work: The 4 is a constant with no variable, so it cannot be combined with the x-terms. Combine only the like terms: 6x + 2x = 8x, and the 4 stays on its own. The correct simplified expression is 8x + 4. (Check: at x = 1, 6x + 4 + 2x = 6 + 4 + 2 = 12, and 8x + 4 = 12, but 12x = 12 only by accident — at x = 2 it gives 24 instead of the true 20.)

Part 1Understand the ideamodels and meaning
  1. 1Complete the table. Show how you found each value.

    Simplify each multi-variable expression. Only combine like terms (same variable).

    ExpressionSimplified
    3x + 2y + 5x + y
    7a + 4b − 2a + b
    6m + 3 + 2m + n + 1

    Why: Each row groups terms by letter and combines only within a group: 3x + 5x = 8x with 2y + y = 3y gives 8x + 3y; 7a − 2a = 5a with 4b + b = 5b gives 5a + 5b; and 6m + 2m = 8m with the lone n and 3 + 1 = 4 gives 8m + n + 4. A variable with no partner, like n, simply stays as it is.

Part 2Explain and correctreasoning
  1. 2Find the mistake. Explain it, then show the correct work.

    Find the Simplification Error

    1. 1Expression5x + 3 + 2y + 4x
    2. 2Combine5x + 2y + 4x + 3
    3. 3Simplify11xy + 3

    Which step has the mistake? Explain what went wrong, then show the correct work.

    Mistake: Step 3. The Simplify step merged the x-terms and the y-term into 11xy, but terms with different variables can never be combined. Only 5x + 4x = 9x are like terms; 2y and the constant 3 each stand alone, so the expression simplifies to 9x + 2y + 3.

    Correct work: 5x + 4x = 9x (like terms). 2y stays separate (no other y-term). The constant 3 stays. Correct answer: 9x + 2y + 3. You cannot combine x-terms and y-terms into xy.

  2. 3Answer in complete sentences.

    Three students simplified 4x + 3 + 2x + 5 + x differently. Student A got 7x + 8. Student B got 7x² + 8. Student C got 6x + 9. Who is correct? Explain the mistakes the other two students made.

    Look for: like terms, combine, coefficient, add, variable, error, simplify

    Why: Student A is correct: 4x + 2x + x = 7x (the lone x counts as 1x) and 3 + 5 = 8, giving 7x + 8. Student B added the coefficients correctly but changed x into x², which combining like terms never does, and Student C left out the lone x and instead pulled a 1 into the constants, landing on 6x + 9.
