✏️ Worked Example

  1. Read the order: A trail mix recipe uses 2 cups of nuts for every 5 cups of raisins (2:5). Priya wants to make a bigger batch using a scale factor of 4.
  2. Pick a scale factor: Priya's scale factor is 4. A scale factor should multiply BOTH parts of the ratio.
  3. Scale the nuts: 2 × 4 = 8 cups of nuts
  4. Scale the raisins: 5 + 4 = 9 cups of raisins

    Catch Marcus's Mistake

    1. 1Read the tableA ratio table starts with 3:8. Marcus needs to find the row where the first value is 12.

    4. 4Write the new rowMarcus's answer: 12:17

    Which step has the mistake? Explain it and write the correct work.
