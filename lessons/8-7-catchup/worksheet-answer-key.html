    1. 1ClueThe report says no fewer than 9 witnesses saw the suspect.
    2. 2Choose a variableLet w stand for the number of witnesses.
    3. 3Write the inequalityw < 9

    Which step has the mistake? Explain it and write the correct work.

    The mistake is in Step 3. Correct work: 'No fewer than 9' means the count cannot drop below 9 — 9 or more witnesses is required. That is w ≥ 9, not w < 9, which would only allow numbers below 9, the opposite of what the clue says. The inequality step pointed the symbol the wrong way. "No fewer than 9" means the count can never drop below 9, so 9 and every larger number works: w ≥ 9. The w < 9 that was written allows only counts under 9, which is the opposite of the clue.

    (Lesson 8.7) Spot the Common Mistake

    1. 1ProblemSeven evidence lockers hold 84 case files in all, split equally. How many files per locker?
    2. 2Model7f = 84
    3. 3Solvef = 84 − 7 = 77
    4. 4Answer77 files per locker.

    Which step has the mistake? Explain it and write the correct work.

    The mistake is in Step 3. Correct work: The variable f is multiplied by 7, so you undo it by dividing both sides by 7 (the inverse operation), not by subtracting 7. 7f = 84 becomes f = 84 ÷ 7 = 12. So there are 12 files per locker. Check: 7 × 12 = 84 ✓ The model 7f = 84 is correct, but f is MULTIPLIED by 7, and subtracting 7 does not undo a multiplication. Divide both sides by 7 instead: f = 84 ÷ 7 = 12 files per locker. Check: 7 × 12 = 84 ✓

    (Lesson 8.4) Find the Inequality Error

    1. 1SituationNo more than 25 students can join the field trip
    2. 2Identify key phrase'No more than' means greater than
    3. 3Write inequalitys > 25

    Which step has the mistake? Explain it and write the correct work.

    The mistake is in Step 2. Correct work: 'No more than' means less than or equal to (≤), not greater than. The correct inequality is s ≤ 25. The key-phrase step read "no more than" as greater than, but that phrase puts a cap on the group — the number of students can never go above 25. It means "at most," so the model is s ≤ 25, which allows 25 and every smaller count.

  2. 2

    (Lesson 8.5) Find the Graphing Error

    1. 1Inequalityx > 6
    2. 2Circle typeClosed circle at 6
    3. 3Shade directionShade right
    4. 4GraphClosed circle at 6, shaded right

    Which step has the mistake? Explain it and write the correct work.

    The mistake is in Step 2. Correct work: x > 6 uses a strict inequality (no 'equal to'), so the circle should be OPEN, not closed. Open circle at 6, shaded right. The shading right matches x > 6, but the circle type step used a closed circle. Since > is strict, 6 > 6 is false and 6 is not a solution, so the graph needs an open circle at 6 shaded right.

  3. 3

    (Lesson 8.6) Find the Solving Error

    1. 1Inequalityx − 8 ≥ 15
    2. 2Inverse operationSubtract 8 from both sides
    3. 3Simplifyx ≥ 7
    4. 4GraphClosed circle at 7, shade right

    Which step has the mistake? Explain it and write the correct work.

    The mistake is in Step 2. Correct work: The inverse of subtracting 8 is ADDING 8, not subtracting. Add 8 to both sides: x ≥ 15 + 8 = 23. Graph: closed circle at 23, shade right. The inequality shows − 8, and the inverse of subtracting is adding. Adding 8 to both sides gives x ≥ 15 + 8 = 23, not 7. The graph is a closed circle at 23 shaded to the right, since ≥ includes the boundary value.

  4. 4

    (Lesson 8.7) Find the Problem-Solving Error

    1. 1ProblemA parking lot holds at most 200 cars. There are 134 already. How many more can park?
    2. 2Model134 + c = 200
    3. 3Solvec = 66
    4. 4AnswerExactly 66 more cars can park.

    Which step has the mistake? Explain it and write the correct work.

    The mistake is in Step 2. Correct work: 'At most' means less than or equal to, so the model should be an inequality: 134 + c ≤ 200. Solving: c ≤ 66. Up to 66 more cars can park, not exactly 66. The arithmetic is fine, but the model is too strict. 'At most 200 cars' means the lot can hold 200 or fewer, which is ≤, not =. The model should be 134 + c ≤ 200, giving c ≤ 66 — up to 66 more cars can park, not exactly 66.
