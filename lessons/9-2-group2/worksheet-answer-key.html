Lesson 9.29.2 Small Group · Group 2

Group 2 · Answer KeyChallenge practice

Learning target I can use a table and a graph to determine and analyze the relationship between two variable quantities, explain what each part stands for, and build one for a situation I have not seen before.

Part 1Understand the ideamodels and meaning
  1. 1Plot and label each point on the grid.

    Plot the ticket-cost relationship: one point for each number of tickets.

    Answer: (1, 45), (2, 90), (3, 135), (4, 180)

    Why: The four points (1, 45), (2, 90), (3, 135), (4, 180) line up on a straight path from the origin: each extra ticket adds exactly $45. That constant climb IS the rate of change, and seeing it in the lined-up points is what 'analyzing a graph' means in this lesson.

  2. 2Circle the letter of the best answer. Show how you know.

    The ticket table and ticket graph are two representations. Which statement about them is true?

    1. AThe graph shows a different relationship than the table
    2. BOnly the table can show that cost increases with tickets
    3. COnly the graph is a real mathematical representation
    4. DBoth show the same relationship — the table with numerical values, the graph in a more visual way

    Answer: D — Both show the same relationship — the table with numerical values, the graph in a more visual way

    Why: Every row of the table is plotted as a point, so both show cost = 45 × tickets — the table numerically, the graph visually.

    Watch for: Reversing the coordinates of a point — writing (cost, tickets) instead of (tickets, cost). The independent variable always comes first in the ordered pair.

Part 2Apply itreal-world problems
  1. 3Circle the letter of the best answer. Show how you know.

    After 10 minutes, the Sandia Peak tram has traveled 12,000 feet. The whole ascent is 18,000 feet. How much farther must it travel to reach the top?

    1. A1,200 feet
    2. B5,000 feet
    3. C6,000 feet
    4. D12,000 feet

    Answer: C — 6,000 feet

    Why: The remaining distance is 18,000 − 12,000 = 6,000 feet — which matches the last 5 minutes at 1,200 feet per minute.

    Watch for: Reversing the coordinates of a point — writing (cost, tickets) instead of (tickets, cost). The independent variable always comes first in the ordered pair.

  2. 4Circle the letter of the best answer. Show how you know.

    Two trams both start at the bottom at 0 minutes. One climbs 1,200 feet each minute, the other 900. Both are graphed on the same axes with minutes across. Without working out a single point, how can you tell which line belongs to the faster tram?

    1. AIts line starts higher up the vertical axis
    2. BIts line is longer than the other one
    3. CIts line rises more steeply — it gains more feet in the same minute
    4. DYou cannot tell without plotting points for both

    Answer: C — Its line rises more steeply — it gains more feet in the same minute

    Why: Both trams start at 0 feet at 0 minutes, so both lines begin at the same corner. The only thing that can differ is how fast they climb, and that is the steepness: 1,200 feet in one minute against 900.

    Watch for: Reversing the coordinates of a point — writing (cost, tickets) instead of (tickets, cost). The independent variable always comes first in the ordered pair.

  3. 5Circle the letter of the best answer. Show how you know.

    Claim: “If two quantities grow together, the points on their graph always lie on a straight line.” Always, sometimes, or never true?

    1. AAlways — growing together is what makes a line
    2. BNever — real data never lines up
    3. CSometimes — only when the quantity grows by the same amount each step
    4. DSometimes — only when both quantities are measured in the same unit

    Answer: C — Sometimes — only when the quantity grows by the same amount each step

    Why: The tickets rise by the same $45 every time, so they line up. The side and area of a square both grow — (1, 1), (2, 4), (3, 9) — but the jumps are 3 then 5, so those points bend upward instead of forming a line.

    Watch for: Reversing the coordinates of a point — writing (cost, tickets) instead of (tickets, cost). The independent variable always comes first in the ordered pair.

Part 3Explain and correctreasoning
  1. 6Answer in complete sentences.

    The ticket graph has “Number of tickets” across the bottom and “Total cost ($)” up the side. Rowan plots the first ticket as the point (45, 1). What did Rowan misunderstand — and what does his point actually claim about tickets and money?

    Sample answer: Rowan swapped the order. The independent variable goes first, so one ticket at $45 is the point (1, 45). His point (45, 1) says that 45 tickets cost one dollar altogether, which is not what the table shows.
