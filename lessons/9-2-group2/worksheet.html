WordWhat it meansExample
graphSpanish: gráfica A picture on a coordinate plane that shows how two quantities are related. points that rise in a line
table of valuesSpanish: tabla de valores A list of matched pairs of values that shows a relationship using numbers. months 1, 2, 4 beside cost 24.95, 49.90, 99.80 — one row per pair.
ordered pairSpanish: par ordenado Two numbers written as (x, y) that name one point on a graph. The independent variable comes first. (3, 12)
axisSpanish: eje One of the two number lines that frame a graph. Each axis is labeled with a quantity from the problem. x-axis and y-axis
coordinatesSpanish: coordenadas The numbers in an ordered pair that tell how far to move along each axis to reach a point. x-coordinate, y-coordinate
Rate of changeSpanish: Tasa de cambio How much y changes each time x goes up by one. Up $4 for each hour.

How it worksWorked exampleturning a table into points on a graph

These numbers are not on your problems. The steps are. Follow them with your own numbers.

A rental site charges $7 per movie. Make a table for 1, 2, and 3 movies, then list the points to plot.

  1. Independent: number of movies (x). Dependent: total cost (y).
  2. Multiply each x by the rate: 1 → 7 · 2 → 14 · 3 → 21
  3. Write each row as an ordered pair (x, y): (1, 7), (2, 14), (3, 21).
  4. Plot each pair: move right along the x-axis first, then up to the y value.

Answer: Points to plot: (1, 7), (2, 14), and (3, 21). They rise in a straight path.

Watch outA common mistake

Reversing the coordinates of a point — writing (cost, tickets) instead of (tickets, cost). The independent variable always comes first in the ordered pair.
