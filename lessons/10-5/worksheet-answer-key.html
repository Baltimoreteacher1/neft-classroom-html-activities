SECTION 1 REAL-WORLD CONTEXTS & PROBLEM SOLVING [Applications]
  1. 1 MULTIPLE CHOICE

    In geometric design, what is repetition?

    1. AThe same object or shape repeated multiple times
    2. BA set of different shapes arranged randomly
    3. CShapes that vary in size and order of appearance
    4. DAny drawing that uses color

    💡 Solution Rationale: Repetition involves one repeated object, shape, or form — and because of that, it has predictability.

    ⚠️ Watch for (Misconception): Calling every repeated design a 'pattern.' One identical shape repeated is repetition; a pattern needs a unit of shapes repeating in a regular order; and rhythm varies the shapes' size and order, so it is neither.

  2. 2 MULTIPLE CHOICE

    A border shows: pink circle, purple square, blue triangle, pink circle, purple square, blue triangle. What are the next three shapes?

    1. APink circle, purple square, blue triangle
    2. BBlue triangle, purple square, pink circle
    3. CPink circle, blue triangle, purple square
    4. DIt is impossible to predict

    💡 Solution Rationale: The pattern unit is circle, square, triangle, so it repeats in the same order: a pink circle, a purple square, and a blue triangle.

    ⚠️ Watch for (Misconception): Calling every repeated design a 'pattern.' One identical shape repeated is repetition; a pattern needs a unit of shapes repeating in a regular order; and rhythm varies the shapes' size and order, so it is neither.

  3. 3 MULTIPLE CHOICE

    In the circle-square-triangle border, how many shapes long is the pattern unit?

    1. A3 shapes
    2. B6 shapes
    3. C2 shapes
    4. D1 shape

    💡 Solution Rationale: The smallest repeating chunk is circle, square, triangle — 3 shapes.

    ⚠️ Watch for (Misconception): Calling every repeated design a 'pattern.' One identical shape repeated is repetition; a pattern needs a unit of shapes repeating in a regular order; and rhythm varies the shapes' size and order, so it is neither.

SECTION 2 REAL-WORLD CONTEXTS & PROBLEM SOLVING [Applications]
  1. 2 MULTIPLE CHOICE

    The pattern unit circle-square-triangle repeats. What is shape number 12?

    1. AThe blue triangle
    2. BThe pink circle
    3. CThe purple square
    4. DIt cannot be determined

    💡 Solution Rationale: 12 ÷ 3 = 4 with no remainder, so shape 12 ends a complete unit — the triangle, which is the last shape of the unit.

    ⚠️ Watch for (Misconception): Calling every repeated design a 'pattern.' One identical shape repeated is repetition; a pattern needs a unit of shapes repeating in a regular order; and rhythm varies the shapes' size and order, so it is neither.

  2. 3 MULTIPLE CHOICE

    Same pattern. What is shape number 20?

    1. AThe purple square
    2. BThe pink circle
    3. CThe blue triangle
    4. DThe 20th shape starts a new pattern

    💡 Solution Rationale: 20 ÷ 3 = 6 remainder 2 (since 6 × 3 = 18 and 20 − 18 = 2), and the second shape in the unit is the purple square.

    ⚠️ Watch for (Misconception): Calling every repeated design a 'pattern.' One identical shape repeated is repetition; a pattern needs a unit of shapes repeating in a regular order; and rhythm varies the shapes' size and order, so it is neither.

  3. 4 MULTIPLE CHOICE

    How many COMPLETE pattern units appear in the first 18 shapes of the circle-square-triangle border?

    1. A6 units
    2. B15 units
    3. C9 units
    4. D3 units

    💡 Solution Rationale: Each unit is 3 shapes, and 18 ÷ 3 = 6 complete units.

    ⚠️ Watch for (Misconception): Calling every repeated design a 'pattern.' One identical shape repeated is repetition; a pattern needs a unit of shapes repeating in a regular order; and rhythm varies the shapes' size and order, so it is neither.

  4. 5 MULTIPLE CHOICE

    How is a design with rhythm different from a pattern?

    1. ARhythm varies size, orientation, and order, so it often lacks predictability; a pattern repeats in a regular order
    2. BRhythm uses shapes and a pattern does not
    3. CA pattern varies its shapes and rhythm never does
    4. DThere is no difference between them

    💡 Solution Rationale: A pattern repeats its unit in a regular arrangement, so it is predictable. Rhythm keeps the same objects but varies how they appear, giving flow without predictability.

    ⚠️ Watch for (Misconception): Calling every repeated design a 'pattern.' One identical shape repeated is repetition; a pattern needs a unit of shapes repeating in a regular order; and rhythm varies the shapes' size and order, so it is neither.

SECTION 3 MATHEMATICAL WRITING & ERROR ANALYSIS [Reasoning & Critique]
  1. 6 OPEN RESPONSE

    A painting shows circles whose colors, sizes, and thickness vary, along with the number of concentric circles inside each one. Describe how the painting demonstrates rhythm.

    💡 Exemplar Response: Sample Answer: The painting demonstrates rhythm because it uses the same object — a circle — but everything about how the circles appear varies: their colors, their sizes, their thickness, and how many rings sit inside each one. There is a flow, but no repeating unit you could use to predict the next circle.
  2. 7 OPEN RESPONSE

    If a new row of circles were added to the rhythm painting, what would they look like? Explain your thinking.

    💡 Exemplar Response: Sample Answer: The new circles would still be circles, but their colors and sizes would vary and each would hold a different number of concentric rings — maybe a huge pale circle with many thin rings next to a small dark one with two thick rings. I cannot copy an existing row, because rhythm varies instead of repeating.

  1. 4 OPEN RESPONSE

    Create a design that has repetition, pattern, AND rhythm. Describe (or sketch) it, and label where each element appears.

    💡 Exemplar Response: Sample Answer: My design is a picture frame. The outer border is repetition: one gold square repeated all the way around. The inner border is a pattern: star, moon, star, moon in a regular order, so its pattern unit is 2 shapes. The center has rhythm: the same star shape scattered across the middle in different sizes, angles, and colors, so it flows but cannot be predicted.
  2. 5 OPEN RESPONSE

    Why do you think the lesson is called 'Math is Boundless'? Use repetition, pattern, and rhythm in your answer.

    💡 Exemplar Response: Sample Answer: A pattern unit can repeat forever — there is no last circle, square, or triangle, so the design has no boundary. Repetition can cover any wall, patterns let us predict shape 25 or shape 25,000, and rhythm shows that even without predictability, math ideas keep creating endless new designs. The designs, like math, never have to end.
