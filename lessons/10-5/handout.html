Math is Boundless

MPP.7 · Unit 10 · Lesson 5

Name   Period

Objectives / Objetivos

Content Objective: I can create and describe geometric designs using repetition, patterns, and rhythm, and use a pattern unit to predict what comes next.

Language Objective: I can describe a design using the words repetition, pattern, pattern unit, and rhythm.

Key Idea / Idea clave

Math can be used to create beautiful designs. These designs often have repetition, patterns, and rhythm — and the pattern unit lets you predict what comes next.

Vocabulary / Vocabulario

Term / TérminoDefinition / Definición
repetition
repetición		The same object, shape, or form repeated multiple times.
El mismo objeto, figura o forma repetido varias veces.
pattern
patrón		A set of objects or shapes that are repeated and arranged in a regular order.
Un conjunto de objetos o figuras que se repiten y se organizan en un orden regular.
pattern unit
unidad del patrón		The smallest chunk of a pattern that repeats.
La parte más pequeña de un patrón que se repite.
rhythm
ritmo		A design element created by varying the placement, size, orientation, or order of the same objects or shapes.
Un elemento de diseño creado al variar la posición, el tamaño, la orientación o el orden de los mismos objetos o figuras.
predictability
previsibilidad		Being able to know what comes next because the design follows a rule.
Poder saber qué viene después porque el diseño sigue una regla.

Practice Preview / Vista previa de práctica

  1. In geometric design, what is repetition?
    1. The same object or shape repeated multiple times
    2. A set of different shapes arranged randomly
    3. Shapes that vary in size and order of appearance
    4. Any drawing that uses color
  2. The pattern unit circle-square-triangle repeats. What is shape number 12?
    1. The blue triangle
    2. The pink circle
    3. The purple square
    4. It cannot be determined
  3. Same pattern. What is shape number 20?
    1. The purple square
    2. The pink circle
    3. The blue triangle
    4. The 20th shape starts a new pattern
  4. The circle-square-triangle pattern continues. What is shape number 25?
    1. The pink circle
    2. The purple square
    3. The blue triangle
    4. There is no shape 25
