🎯 Canvas Auto-Grade

Every lesson and activity, packaged for Canvas. Upload a package once and it grades itself when a student finishes — no completion codes, no IT.

How to set up an assignment (≈30 seconds each)

  1. Download a package below.
  2. In Canvas: SCORM (left menu) → Upload → choose the .zip.
  3. Click it → deploy as a graded assignment, give it points. Done.

Students open it in Canvas, finish the lesson, and the score lands in your gradebook automatically. Each package points at the live lesson, so when you edit a lesson later you never re-upload.
