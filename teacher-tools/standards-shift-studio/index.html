Standards Shift Studio

When Maryland revises the Grade-6 standards or the scope & sequence moves, model the change here before it lands: paste the proposed standards, review the auto-matched crosswalk, re-sequence units, see exactly which lessons are affected — then generate the ready-to-apply files the curriculum rebuild pipeline consumes.

Loading live curriculum data…

Coverage atlas — the curriculum you already have

Live from /data/ccss-standards.json and /data/curriculum-manifest.json — one row per current standard, with every lesson that teaches it. This is the baseline every proposed change is measured against.

Paste the proposed standards

One standard per line, in almost any format MSDE publishes — 6.AT.A.1 — Understand the concept of a ratio…, CSV (code, text), or tab-separated. The matcher scores every line against the current registry and drafts a crosswalk you review below.

Review the drafted crosswalk

Each proposed standard was matched by text similarity. Fix any mapping with the dropdown — your choice always wins over the auto-match. Verdicts update live.

Scope & sequence editor

The spine is each lesson's unit + lesson fields. Edit the numbers to model a reorder — the doctor below runs the same checks as npm run curriculum:scope (duplicate slots, numbering gaps) as you type. Folder ids and URLs never change from here; only the ordering fields do.

Impact analysis

Everything below is derived live from your crosswalk decisions and sequence edits — re-run the match or tweak a mapping and this page updates.

Generate the change kit

These files plug straight into the repo's standards pipeline (docs/standards/msde-standards-change-runbook.md): drop them in data/, run npm run standards-crosswalk:apply and npm run curriculum:rebuild, and every manifest, hub, and scope view regenerates. Nothing is hand-edited.
