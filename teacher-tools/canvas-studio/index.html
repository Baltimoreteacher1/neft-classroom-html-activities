    🔑 How grading works

    Completion codes are minted by each activity and decoded into your gradebook with the Canvas Grades tool — pure text entry, nothing to install. QTI quizzes grade themselves. Live links need no grading at all.

    SCORM is optional — the live-activity auto-grade path only works if your district has enabled the Canvas SCORM tool. You don't need it for any of the above.
