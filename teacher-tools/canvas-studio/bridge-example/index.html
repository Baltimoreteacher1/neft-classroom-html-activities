Ratio Quick Check

A tiny example activity. Answer three questions, then Finish to get a Canvas completion code — the same flow you can add to any activity with one script tag.

1. A recipe uses 2 cups flour to 3 cups water. What is the ratio of flour to water?

2. There are 4 red and 6 blue marbles. What is the ratio of red to total?

3. If 2 pencils cost $1, how much do 6 pencils cost (same rate)?

Answer all three, then finish to get your code.

The popup's code pastes into a Canvas text-entry assignment. Decode it in Canvas Grades. No name typed? The popup reminds the student.
