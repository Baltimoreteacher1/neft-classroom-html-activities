Canvas Grade Bridge

Turn student completion codes — or scores from the live gradebook — into a ready-to-import Canvas gradebook CSV. Teacher-only.

One-time setup: export your Canvas gradebook once (Grades → Export) and drop it below to save your class roster. After that, each assignment is just: provide scores (paste codes or pull the live gradebook) → name the assignment → download → Grades → Import. No more exports.

1Provide student scores

Option A — paste completion codes. One per line, straight from the Canvas SpeedGrader / submission column. Extra text is ignored.

— or —

Option B — pull from the live gradebook. No codes needed. Uses the scores students already saved through the activities (Save/Resume). Needs your teacher key. Student IDs never leave this page — only scores come from the server, matched by name against your saved roster.

2Name the assignment & points

Type the assignment name exactly as it appears in Canvas, and its total points.

3Download for Canvas import

Review the preview above, then download and import in Canvas (Grades → Import).

Advanced: fill an existing export instead

Prefer to fill a column inside this assignment's exact Canvas export? Drop it here — it also (re)saves your roster.
