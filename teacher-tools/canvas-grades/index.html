Canvas Grade Bridge

Turn pasted student completion codes into a ready-to-import Canvas gradebook CSV. Teacher-only.

How it works: In Canvas, create the assignment, then Grades → Export → Current Gradebook. Drop that CSV below, paste the completion codes students submitted, pick the assignment column, and download. Re-import the file in Canvas (Grades → Import). Scores scale to the column's Points Possible automatically.
