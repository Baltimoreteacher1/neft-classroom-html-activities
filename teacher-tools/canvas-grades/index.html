Canvas Grade Bridge

Turn pasted student completion codes into a ready-to-import Canvas gradebook CSV. Teacher-only.

One-time setup: export your Canvas gradebook once (Grades → Export) and drop it below to save your class roster. After that, each assignment is just: paste codes → name the assignment → download → Grades → Import. No more exports.

1Paste submitted completion codes

One per line. Paste straight from the Canvas SpeedGrader / submission column — extra text is ignored.

2Name the assignment & points

Type the assignment name exactly as it appears in Canvas, and its total points.

3Download for Canvas import

Review the preview above, then download and import in Canvas (Grades → Import).

Advanced: fill an existing export instead

Prefer to fill a column inside this assignment's exact Canvas export? Drop it here — it also (re)saves your roster.
