How to use it

  1. Pick the activity and a grading mode above, then Download.
  2. In Canvas: Assignments → + Assignment, set Submission Type to External Tool / SCORM, and upload the .zip (same steps you already use).
  3. Publish. Students open it inside Canvas — it plays the live activity.

You can keep editing the activity afterward. The package loads the live page, so changes you make on the site show up in Canvas automatically — no need to re-download or re-upload.
