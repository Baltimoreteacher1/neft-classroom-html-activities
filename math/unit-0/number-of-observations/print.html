Summarizing Data: Number of Observations

Grade 6 Math · Unit 0 · Standard 6.DS.B.6.a
Name: ______________________________Date: ____________

Goal: I can summarize a data set by reporting the number of observations (n).

  1. How many observations are in {3, 7, 7, 2, 9, 4} ?
  2. A survey asked 12 households how many pets they own. What is n?
  3. A dot plot shows these dots above the numbers: 2 dots on 4, 3 dots on 5, 1 dot on 7. How many observations?
  4. The number of observations tells you…
    A. how many data values were collected
    B. the largest value
    C. the average value
  5. Exit ticket. A class recorded {6, 8, 6, 10, 9, 7, 8}. State the number of observations and explain what n means.
Teacher answer key — remove before copying

Answer key

  1. 1. 6
  2. 2. 12
  3. 3. 6
  4. 4. how many data values were collected
  5. Exit ticket: answers will vary — look for correct reasoning about 6.DS.B.6.a (see the worked example and teaching tip).
