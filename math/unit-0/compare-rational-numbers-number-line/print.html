Comparing Rational Numbers on the Number Line

Grade 6 Math · Unit 0 · Standard 6.NOS.C.8.a
Name: ______________________________Date: ____________

Goal: I can interpret a statement of inequality (like −3 > −7) as a statement about the relative position of two numbers on a number line.

  1. Which symbol makes it true: −2 ___ −5 ?
    A. >
    B. <
    C. =
  2. A number to the LEFT of another number on the line is always…
    A. greater
    B. less
    C. equal
  3. Order from least to greatest (use commas): −4, 0, −1
  4. True or False: −8 > −3
    A. True
    B. False
  5. Exit ticket. Without computing, explain why −1 > −6 using the position of each number on a number line.
Teacher answer key — remove before copying

Answer key

  1. 1. >
  2. 2. less
  3. 3. -4, -1, 0
  4. 4. False
  5. Exit ticket: answers will vary — look for correct reasoning about 6.NOS.C.8.a (see the worked example and teaching tip).
