↔️ Comparing Rational Numbers on the Number Line

Objectives

Content: I can interpret a statement of inequality (like −3 > −7) as a statement about the relative position of two numbers on a number line.

Language: I can explain a comparison using the words greater than, less than, left, and right.

⚠️ Common misconception

Students compare the digits and conclude −8 > −3 because 8 > 3, instead of comparing position on the number line.

💡 Teaching tip

Keep a number line visible; have students physically point to each number before choosing > or <.

Vocabulary

  • Inequality: A statement that compares two values using > or <.
  • Number line: A line where every point stands for a number, with values increasing left to right.
  • Rational number: Any number that can be written as a fraction, including integers and negatives.

Answer key

  1. 1. >
  2. 2. less
  3. 3. -4, -1, 0
  4. 4. False
  5. Exit ticket: answers will vary — look for correct reasoning about 6.NOS.C.8.a (see the worked example and teaching tip).
