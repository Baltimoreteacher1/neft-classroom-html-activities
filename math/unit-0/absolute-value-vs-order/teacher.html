📏 Absolute Value vs. Order

Objectives

Content: I can tell the difference between comparing absolute values (size/distance from 0) and comparing the actual order of two numbers.

Language: I can explain the difference between 'greater' and 'bigger absolute value' using an example.

⚠️ Common misconception

Students confuse 'greater value' with 'greater absolute value,' especially for negative numbers.

💡 Teaching tip

Use money: −$30 is less than −$5 (order) but a bigger debt (absolute value). Treat them as two separate questions.

Vocabulary

  • Absolute value: The distance of a number from 0, written |x|. Always zero or positive.
  • Magnitude: The size of a number ignoring its sign — its absolute value.
  • Order: Which number is actually greater or less, signs included.

Answer key

  1. 1. 7
  2. 2. −2
  3. 3. −7
  4. 4. the $45 debt
  5. 5. False
  6. Exit ticket: answers will vary — look for correct reasoning about 6.NS.C.7.D (see the worked example and teaching tip).
