⚖️ Writing & Solving One-Step Inequalities

Objectives

Content: I can write and solve one-step inequalities for a context and show the solution set on a number line.

Language: I can describe a solution set using the words at least, at most, more than, and less than.

⚠️ Common misconception

Students treat an inequality like an equation with one answer, or use the wrong circle (open vs. closed) when graphing.

💡 Teaching tip

Stress the solution is a set, not one number; tie open/closed circles to whether the endpoint is included (> < open, ≥ ≤ closed).

Vocabulary

  • Inequality: A statement comparing values with >, <, ≥, or ≤.
  • Solution set: All the values that make an inequality true.
  • Open / closed circle: Open ○ for > or < (not included); closed ● for ≥ or ≤ (included).

Answer key

  1. 1. x > 5
  2. 2. x <= 4
  3. 3. open
  4. 4. n ≥ 10
  5. 5. Yes
  6. Exit ticket: answers will vary — look for correct reasoning about 6.AT.C.10 (see the worked example and teaching tip).
