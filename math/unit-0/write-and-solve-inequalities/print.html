Writing & Solving One-Step Inequalities

Grade 6 Math · Unit 0 · Standard 6.AT.C.10
Name: ______________________________Date: ____________

Goal: I can write and solve one-step inequalities for a context and show the solution set on a number line.

  1. Solve: x + 4 > 9 (write like x > 5 )
  2. Solve: 3x ≤ 12 (write like x <= 4 )
  3. The graph of x > 2 uses a(n) ___ circle at 2.
    A. open
    B. closed
  4. 'A number is at least 10' translates to…
    A. n ≥ 10
    B. n > 10
    C. n ≤ 10
  5. Is x = 6 a solution of x + 1 > 6 ?
    A. Yes
    B. No
  6. Exit ticket. Write and solve a one-step inequality for 'twice a number is less than 8,' then describe its graph (circle type and direction).
Teacher answer key — remove before copying

Answer key

  1. 1. x > 5
  2. 2. x <= 4
  3. 3. open
  4. 4. n ≥ 10
  5. 5. Yes
  6. Exit ticket: answers will vary — look for correct reasoning about 6.AT.C.10 (see the worked example and teaching tip).
