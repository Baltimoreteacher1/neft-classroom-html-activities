🏷️ Summarizing Data: Attribute & Units

Learning goal: I can describe a data set by naming the attribute under investigation, how it was measured, and its units.

Language goal: I can describe a data set using the sentence frame the attribute is ___ , measured in ___ .

📚 Vocabulary

Attribute: The characteristic being measured or counted (height, temperature, time).
Units of measurement: The standard the attribute is measured in (cm, °F, minutes, books).
Measurement tool: What you use to get the value (ruler, thermometer, stopwatch).

💡 Learn it

A full data summary explains what was measured (the attribute), how it was measured, and the units.

Example: 'heights of students' — attribute: height; tool: tape measure; units: centimeters.

Counts have units too: 'books read per month' is measured in books.

Worked example. Describe the data set: the daily high temperature for two weeks.
  1. Attribute: temperature.
  2. Measured with: a thermometer.
  3. Units: degrees Fahrenheit (°F).

✏️ Practice

Score: 0 / 4
1. Data: the daily high temperatures in a city. The attribute is…
💡 The attribute is the characteristic being measured.
2. Good units for that temperature data would be…
💡 Temperature is measured in degrees.
3. Data: number of books each student read this month. The units are…
💡 It is a count of books.
4. Best tool to measure 'length of each fish caught'?
💡 Length is measured with a ruler or tape.

🗣️ Sentence frames (ESOL support)

  • I know ___ because ___.
  • First, I ___. Then, I ___.
  • The answer is ___, so ___.

🎟️ Exit ticket

For the data set 'lengths of fish caught', name the attribute, a tool you could use to measure it, and appropriate units.
