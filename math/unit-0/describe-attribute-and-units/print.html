Summarizing Data: Attribute & Units

Grade 6 Math · Unit 0 · Standard 6.DS.B.6.b
Name: ______________________________Date: ____________

Goal: I can describe a data set by naming the attribute under investigation, how it was measured, and its units.

  1. Data: the daily high temperatures in a city. The attribute is…
    A. temperature
    B. the city
    C. the day
  2. Good units for that temperature data would be…
    A. degrees (°F or °C)
    B. inches
    C. students
  3. Data: number of books each student read this month. The units are…
    A. books
    B. minutes
    C. grams
  4. Best tool to measure 'length of each fish caught'?
    A. a ruler/measuring tape
    B. a thermometer
    C. a stopwatch
  5. Exit ticket. For the data set 'lengths of fish caught', name the attribute, a tool you could use to measure it, and appropriate units.
Teacher answer key — remove before copying

Answer key

  1. 1. temperature
  2. 2. degrees (°F or °C)
  3. 3. books
  4. 4. a ruler/measuring tape
  5. Exit ticket: answers will vary — look for correct reasoning about 6.DS.B.6.b (see the worked example and teaching tip).
