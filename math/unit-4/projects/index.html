For the Teacher

How to Use These Projects

Standards: 6.AT.2 (unit rates), 6.AT.2 (unit price / better buy), 6.AT.4 (percent of a number, discounts, tax, fraction-decimal-percent conversions), 6.AT.3c (measurement unit conversion using rate reasoning — featured in Version A's Level 2 challenge).

Both versions are parallel. They assess the same rate and percent skills through different real-world contexts, so you can assign Version A and Version B to different students and grade on the same rubric (built into each project). Great for choice boards, make-up work, or A/B class sections.

Built in: a Self → Peer → World arc, Visual Math Notes vocabulary, a Formula Bank and Sentence Frames, an EN/ES toggle, Level 1 / Level 2 differentiation, live calculators with self-checks, peer-compare and world-data tools, save/resume and a report export (.txt), a sticky progress bar, hints, a written deliverable, a student checklist, a rubric, and a print button.
