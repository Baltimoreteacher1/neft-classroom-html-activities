Letters Stand for Numbers

I can use a variable to represent an unknown number and write an expression for a situation.

📘 Word Bank + Sentence Frames

variableunknownexpressionrepresent

  • A variable (like n) stands for a number we don't know yet.
  • Frame: "Let ____ = ____. The expression is ____."

👀 See It

"5 more than a number" → let n = the number → n + 5.
