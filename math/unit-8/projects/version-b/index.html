Key Words Palabras clave

Learn these 5 math words before you begin Aprende estas 5 palabras de matemáticas antes de comenzar
⚖️
Equation Ecuación
A mathematical sentence stating that two expressions are equal (=). Una oración matemática que establece que dos expresiones son iguales (=).
Example: 180 + x = 500 Ejemplo: 180 + x = 500
↔️
Inequality Desigualdad
A statement comparing values using <, >, ≤, or ≥. Un enunciado que compara valores usando <, >, ≤ o ≥.
Example: amount raised > 350 Ejemplo: cantidad recaudada > 350
🔤
Variable Variable
A letter or symbol representing an unknown value. Una letra o símbolo que representa un valor desconocido.
Example: x = amount remaining Ejemplo: x = cantidad restante
🎯
Solution Solución
A value for the variable that makes the equation true. Un valor para la variable que hace que la ecuación sea verdadera.
Example: x = 320 Ejemplo: x = 320
🎒
Fundraiser Goal Meta de recaudación
The target amount of money your class wants to raise. La cantidad de dinero objetivo que tu clase quiere recaudar.
Example: Goal = $500 Ejemplo: Meta = $500

Step 1 — Fundraiser Goal & Progress Paso 1 — Meta y progreso de la recaudación

Write an addition equation to find the needed remaining funds Escribe una ecuación de suma para encontrar los fondos restantes necesarios
Your job: Enter a cause for your class fundraiser, set your total goal and current amount raised. Then write and solve an addition equation to find how much more you need. Tu trabajo: Ingresa una causa para la recaudación de fondos de tu clase, establece tu meta total y la cantidad ya recaudada. Luego, escribe y resuelve una ecuación de suma para encontrar cuánto más necesitas.
📊 Research you need for this step📊 Investigación que necesitas para este paso

🟠 Level 0: Track your money. Step 1: goal − raised = how much more. Tiny example: $100 − $40 = $60 to go. Starter: “I still need $___.” 🟠 Nivel 0: Lleva la cuenta. Paso 1: meta − recaudado = cuánto falta. Ejemplo: $100 − $40 = $60 por recaudar. Empieza: “Aún necesito $___.”
🟢 Level 1 suggestion: Use the default values: Goal $500, Raised $180, and variable x. 🟢 Sugerencia de Nivel 1: Usa los valores predeterminados: Meta $500, Recaudado $180 y variable x.
LEVEL 2 CHALLENGE DESAFÍO DE NIVEL 2

Choose your own unique fundraiser goal and variable name. Ensure your variable makes sense for the context! Elige tu propia meta de recaudación de fondos y nombre de variable únicos. ¡Asegúrate de que tu variable tenga sentido para el contexto!

Need a hint? ¿Necesitas una pista?

Your equation balances the money you have already raised plus the variable (needed amount) to equal your total goal: Raised + x = Goal. To solve it, subtract the raised amount from both sides. Tu ecuación equilibra el dinero que ya has recaudado más la variable (cantidad necesaria) para igualar tu meta total: Recaudado + x = Meta. Para resolverla, resta la cantidad recaudada de ambos lados.

Step 2 — Progress Milestones Paso 2 — Hitos de progreso

Write and evaluate inequalities to represent milestones Escribe y evalúa desigualdades para representar hitos
Your job: Plan a key progress milestone (e.g., getting a stretch goal or class reward). Write an inequality using y (total amount raised) to represent reaching this milestone. Tu trabajo: Planifica un hito clave de progreso (ej. obtener una meta extendida o una recompensa para la clase). Escribe una desigualdad usando y (cantidad total recaudada) para representar que se alcanza este hito.
📊 Research you need for this step📊 Investigación que necesitas para este paso
🎟️ GoFundMe — Campaigns ↗GoFundMe — Campañas ↗ Fill in: Goal $___; raised so far $___ (still need ___).Completa: Meta $___; recaudado $___ (falta ___).
🟠 Level 0: “More than” uses >. Step 1: write y > goal. Tiny example: raised must be more than $50 → y > 50. Starter: “y > ___.” 🟠 Nivel 0: “Más que” usa >. Paso 1: escribe y > meta. Ejemplo: recaudado debe ser más de $50 → y > 50. Empieza: “y > ___.”
🟢 Level 1 suggestion: Write an inequality showing that the total raised (y) must be more than $350. Use symbol > and write y > 350. 🟢 Sugerencia de Nivel 1: Escribe una desigualdad que muestre que el total recaudado (y) debe ser más de $350. Usa el símbolo > y escribe y > 350.

🕵️ Test the Milestone (Substitution Check) 🕵️ Probar el hito (Comprobación por sustitución)

Substitute different raised amounts (values for y) to see if they satisfy your inequality milestone. Sustituye diferentes cantidades recaudadas (valores de y) para ver si satisfacen tu desigualdad del hito.

Need a hint? ¿Necesitas una pista?

An inequality uses comparison signs like > (greater than) or ≥ (greater than or equal to). An open circle on the number line means that exact value is excluded (like >), while a closed circle means it is included (like ≥). Tip: you can type >= for ≥ and <= for ≤. Una desigualdad usa signos de comparación como > (mayor que) o ≥ (mayor o igual que). Un círculo abierto en la recta numérica significa que ese valor exacto está excluido (como >), mientras que un círculo cerrado significa que está incluido (como ≥). Consejo: puedes escribir >= para ≥ y <= para ≤.
