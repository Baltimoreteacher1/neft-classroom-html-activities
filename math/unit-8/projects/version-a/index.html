Key Words
Learn these 5 math words before you begin
⚖️
Equation — Ecuación
A mathematical sentence stating that two sides are equal (=).
x + 3 = 8
🔤
Variable — Variable
A letter or symbol that stands for an unknown number.
x is the variable
🔁
Inverse Operation — Op. Inversa
Operations that undo each other, like + and −.
Addition undoes subtraction
🎯
Solution — Solución
The value of the variable that makes the equation true.
In x + 3 = 8, solution is x = 5
🔎
Substitution — Sustitución
Replacing a variable with a value to check if it works.
Plug in 5: 5 + 3 = 8 ✓

Step 1 — Set the Code
Pick a secret code and write an addition/subtraction equation for it
Your job: Your escape room needs a secret code to unlock the first door. Pick your code, then write an equation that equals that code. Players will solve your equation to find the secret code!
🟢 Level 1 tip: Pick a secret code between 1 and 20 (e.g. 12) and a constant between 1 and 10.
LEVEL 2 CHALLENGE
Try using a secret number greater than 20, or include decimals (e.g., secret code = 25.5, equation constant = 4.5).
Need a hint?

To write an addition equation, start with your secret code (e.g., 12). Add a number to it (e.g., 12 + 5 = 17). Your equation is x + 5 = 17. When players subtract 5 from 17, they get 12!

Step 2 — Solve a Clue Equation
Choose a lock and solve its multiplication or division equation
Your job: Choose one of the pre-designed locks in your escape room. Solve its multiplication or division equation step-by-step using inverse operations to find the code.
🟢 Level 1 tip: Select a simple whole number equation like 3x = 36 or x / 4 = 8.
LEVEL 2 CHALLENGE
Select a decimal lock equation like 12x = 180 or x / 2.5 = 12.
Choose a lock clue above to begin
Need a hint?

If the variable is multiplied by a number (like 3x = 36), the inverse operation is division. Divide both sides of the equation by that number (36 ÷ 3) to get the solution x = 12.
