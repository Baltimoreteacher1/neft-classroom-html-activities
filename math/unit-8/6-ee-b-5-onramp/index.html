A Solution Makes the Equation True

I can check whether a number is a solution by seeing if it makes the equation true.

📘 Word Bank + Sentence Frames

equationsolutionsubstitutetrue / false

  • A solution is a value that makes the equation true.
  • Substitute and check if both sides are equal.

👀 See It

Is x = 3 a solution of x + 2 = 5? Substitute: 3 + 2 = 5. True → yes.
