Turning Words into Expressions

I can translate a word phrase into an algebraic expression.

📘 Word Bank + Sentence Frames

sum (+)difference (−)product (×)quotient (÷)variable

  • "more than / increased by" → +  ·  "less than / fewer" → −
  • "times / of / product" → ×  ·  "split / per / quotient" → ÷
  • Frame: "Let n = the number. The expression is ____."

👀 See It

"5 more than a number n" → n + 5.   "3 times a number n" → 3n.   "a number n split into 4" → n ÷ 4.
