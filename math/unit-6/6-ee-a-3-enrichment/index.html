Stretch: Distribute and Combine Like Terms

I can use the distributive property and combine like terms to write equivalent expressions.

🧠 The Challenge

Two expressions are equivalent if they give the same value for every value of the variable. You make equivalent expressions by distributing and combining like terms.

Example: 3(x + 2) = 3x + 6.   And 3x + 6 + 2x = 5x + 6.

✏️ Your Turn

0 of 3 checks complete

1. Distribute: 4(x + 3) = ?

2. Combine like terms: 5x + 2 + 3x = ?

3. Which is equivalent to 2(n + 4) + n?

💬 Explain Your Thinking

Show that two expressions are equivalent by testing a value:

"____________________ equals ____________________. I checked with x = ____: both give ____."
