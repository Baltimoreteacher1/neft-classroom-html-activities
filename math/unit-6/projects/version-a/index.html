Key Words
Learn these 6 algebraic vocabulary words before you begin
🔤
Variable
A letter or symbol that stands for a number that can change.
e.g. p for points, b for bonuses.
⬆️
Exponent
A number showing how many times a base is multiplied by itself.
e.g. In 23, the exponent is 3 (2×2×2).
🧱
Expression
A mathematical phrase with numbers, variables, and operators.
e.g. 10p + 5b has no equals sign.
🟰
Equivalent Expression
Two expressions that always equal the same value when evaluated.
e.g. 2(5p + 3b) = 10p + 6b.
📌
Constant
A fixed number that never changes value in an expression.
e.g. In 10p + 50, the constant is 50.
✖️
Coefficient
The number in front of and multiplying a variable term.
e.g. In 10p, the coefficient is 10.

Need a hint on exponents?

An exponent tells you how many times to multiply the base by itself.
Example (base 2): 23 = 2 × 2 × 2 = 8 (NOT 2 × 3 = 6).
Example (base 3): 33 = 3 × 3 × 3 = 27.

Step 3 — Equivalent Expressions
Simplify code using the distributive property and check equivalence (6.EE.3/4)
The Concept: Video game engines need to run fast. Sometimes, rewriting expressions in a factored form using the Distributive Property helps clean up calculations. Two expressions are equivalent if they give the same answer for any values of the variables.

Need a hint on equivalent expressions?

To check if expressions are equivalent, expand or simplify them using properties:
3(2p + 4b) = 3 × 2p + 3 × 4b = 6p + 12b. Since they simplify to the same form, they are equivalent.
