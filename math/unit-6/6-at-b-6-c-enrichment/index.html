Stretch: Substitute and Evaluate

I can evaluate an expression at a given value and use a formula by substituting numbers.

🧠 The Challenge

substituteevaluateformulaorder of operations

To evaluate, replace each variable with its value and compute. A formula like A = ℓ × w works the same way: substitute the numbers, then calculate.

👀 Worked Example

Evaluate 3x + 2 at x = 4: 3(4) + 2 = 12 + 2 = 14. Use A = ℓ × w with ℓ = 5, w = 3: A = 5 × 3 = 15.

💬 Explain Your Thinking

Show how to evaluate 4n + 1 when n = 6:

"I substitute n = 6, so 4n + 1 = 4 × ____ + 1 = ____ + 1 = ____."

"I substitute n = 6, so 4n + 1 = 4 × blank + 1 = blank + 1 = blank."
