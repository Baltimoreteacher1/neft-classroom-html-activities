Testing if Expressions Are Equivalent

I can check whether two expressions are equivalent by trying the same value in both.

📘 Word Bank + Sentence Frames

equivalentsubstituteevaluatesame value

  • Two expressions are equivalent if they give the same value for every number.
  • Test by substituting a number into both.

👀 See It

Is x + x equivalent to 2x? Try x = 3: 3 + 3 = 6 and 2 × 3 = 6. Same → equivalent.

✏️ Your Turn

0 of 3 checks complete

1. Which is equivalent to x + x?

2. Is 3x equivalent to x + x + x?

3. Test x = 2: which equals 2(x + 1)?

💬 Explain Your Thinking

Explain how you test for equivalence:

"I put ____ into both expressions. They gave ____ and ____, so they are ____ equivalent."

"I put blank into both expressions. They gave blank and blank, so they are blank equivalent."
