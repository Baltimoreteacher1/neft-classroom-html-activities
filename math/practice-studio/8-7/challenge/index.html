The case went cold, and the last files are smudged and out of order. Rebuild each model from the clues, decide between an equation and an inequality, and check every answer against the story.

El caso se enfrió, y los últimos expedientes están borrosos y desordenados. Reconstruye cada modelo con las pistas, decide entre una ecuación y una desigualdad, y comprueba cada respuesta con la historia.

1. Climb the skill ladder

Each rung is harder than the last, and the numbers change every time.

Cada peldaño es más difícil que el anterior y los números cambian cada vez.

  1. 6 fresh problems with new numbers each time (interactive only).

2. Multi-step missions

Real situations that need more than one step: plan, solve, then check that your answer makes sense.

Situaciones reales que necesitan más de un paso: planea, resuelve y revisa que tu respuesta tenga sentido.

  1. Find the Problem-Solving Error
  2. Create two word problems about the same situation: one that requires an equation and one that requires an inequality. Solve both and explain why the models are different.
  3. A reward r was split equally among 5 detectives, and each detective got $40. Which model fits, and what was the reward?
    • r ÷ 5 ≥ 40, so r ≥ 200
    • 5r = 40, so r = 8
    • r ÷ 5 = 40, so r = 200
    • r − 5 = 40, so r = 45
  4. The evidence locker holds at most 30 boxes, and 17 boxes are inside. Let b be the number of boxes that can still be added. Which model and solution are correct?
    • 17 + b ≤ 30, so b ≤ 13
    • 17 + b = 30, so b = 13
    • 17 + b ≤ 30, so b ≤ 47
    • 17 + b < 30, so b < 13
  5. Seven identical keys weigh 3.5 pounds in all. Let k be the weight of one key in pounds, so 7k = 3.5. How many pounds does one key weigh?
  6. Each row is a case model. Solve it. Type the solution, or for the inequality the boundary number.

3. Build it, move it, test it

Use the tools to build the idea. Then check it.

Usa las herramientas para construir la idea. Luego compruébala.

  1. Sort each clue by the model it needs: an equation for one exact value, or an inequality for a limit or a range.
  2. 2 fresh problems with new numbers each time (interactive only).

4. Detective work

Somebody made a mistake. Find the step, then decide who is right.

Alguien cometió un error. Encuentra el paso y decide quién tiene razón.

  1. Rhea models 'The elevator takes no more than 8 people'.
  2. Sione models 'A prize was split equally among 3 winners, and each got $25'.
  3. Carmen solves 7c = 3.5 for the weight c of one clue card, in ounces.
  4. Leo and Pilar both model 'Eight more than a number is at least 20' as n + 8 ≥ 20. Leo says n ≥ 12. Pilar says n = 12. Who is right?
    • Pilar, because solving always gives one number.
    • Leo, because an inequality has many solutions, 12 and greater.
    • Both, because both found the boundary 12.
    • Neither, because the answer should be n ≤ 12.

5. Boss level

Tell us how sure you are, then solve. Finish with a problem of your own.

Dinos qué tan seguro estás y luego resuelve. Termina con un problema tuyo.

  1. Which situation needs an inequality instead of an equation?
    • The clue weighs exactly 9 grams.
    • The vault code has exactly 6 digits.
    • The reward was split equally, $40 each.
    • The suspect is at least 30 years old.
  2. Idris visited n sites on a case. After 9 of them were closed, 14 were left open. The model is n − 9 = 14. How many sites did he visit?
  3. Noelle wants to spend less than $45 on 5 flashlights that each cost f dollars. Which inequality shows her goal?
    • 5f ≤ 45
    • f + 5 < 45
    • 5f < 45
    • 5f > 45
  4. Dmitri solves 6w = 3.6 for the weight w of one clue, in pounds, and gets w = 21.6. Why should he doubt his answer?
    • Because a weight cannot be a decimal.
    • Six clues that each weigh 21.6 pounds would weigh far more than 3.6 pounds.
    • Because he should have added 6 to 3.6.
    • Because 21.6 is a multiple of 3.6.
  5. Amani has $30 for bus tickets that cost $4 each. The inequality 4t ≤ 30 shows how many tickets t she can buy. What is the greatest whole number of tickets she can buy?
  6. Write two short mystery problems of your own. One needs an equation, and one needs an inequality. Model each, solve each, and say whether your answer makes sense.
