  1. Two quantities are related. Which statement is ALWAYS true?

    • The independent variable is the input used to describe the relationship
    • The dependent variable is always measured in dollars
    • The independent variable is always listed first in a table
  2. Give an example where the SAME quantity can be independent in one problem and dependent in another.
    • Time is always independent

    • Time is always dependent
    • A quantity can never switch roles
  3. The pizza shop spends $1.15 on cheese per pizza. Which weekly total is correct if it makes 200 pizzas?
    • $115
    • $201.15
    • $230
    • $1,150
  4. Which relationship is NOT a case of one quantity depending on the other?
    • Hours studied and quiz score
    • Minutes jogged and Calories burned
    • Pizzas made and cheese used
    • A student's height and their house number
  5. Write the relationship as a sentence: a printer prints 12 pages per minute.
    • Minutes running depends on pages printed
