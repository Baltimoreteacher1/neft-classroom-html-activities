1. Warm up your thinking

Quick questions that wake up what you already know for this lesson.

Preguntas rápidas para activar lo que ya sabes de esta lección.

  1. Which equation represents: 'Three times a number equals 21'?
    • n + 3 = 21
    • n − 3 = 21
    • 3n = 21
    • n / 3 = 21
  2. Which equation represents: 'Seven less than a number is 18'?
    • 7 − n = 18
    • n − 7 = 18
    • n + 7 = 18
    • n / 7 = 18
  3. Which equation represents: 'A number plus 12 equals 30'?
    • n − 12 = 30
    • 12n = 30
    • n + 12 = 30
    • n / 12 = 30
