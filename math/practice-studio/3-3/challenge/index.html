Follow the numbers to the truth.Sigue los números hasta la verdad.

A midnight break-in has scrambled the evidence tables, and some rows are fake. Spot which rows keep the ratio and fix the ones that do not before sunrise.

Un robo a medianoche revolvió las tablas de evidencia, y algunas filas son falsas. Detecta qué filas mantienen la razón y corrige las que no, antes del amanecer.

1. Climb the skill ladder

Each rung is harder than the last, and the numbers change every time.

Cada peldaño es más difícil que el anterior y los números cambian cada vez.

  1. 6 fresh problems with new numbers each time (interactive only).

2. Multi-step missions

Real situations that need more than one step: plan, solve, then check that your answer makes sense.

Situaciones reales que necesitan más de un paso: planea, resuelve y revisa que tu respuesta tenga sentido.

  1. Find Devon's Mistake
  2. A recipe uses 4 cups of flour for every 3 cups of sugar. A student filled in a ratio table: 4:3, 8:6, 12:9, 14:12. Find and fix the error in the last row. Explain what went wrong.
  3. Fill in the table
  4. The lab's invisible-ink formula uses 3 drops of reagent with 4 mL of water in one batch. Fill in the missing numbers so every row keeps the same ratio.
  5. A footprint photo is enlarged. The ratio table shows real length to photo length. What real length, in centimeters, matches a 35 cm photo?
  6. Detective Lee built this ratio table for the code ratio 2:3, but one row is wrong. Which row is wrong, and what should it be?
    • Row 4 should be 8:12.
    • Row 2 should be 4:5.
    • Row 3 should be 6:8.
    • Row 5 should be 10:13.
  7. A lab mixes 5 mL of dye with 8 mL of solvent in the smallest batch. A big case needs 35 mL of dye. How many milliliters of solvent keep the same ratio?

3. Build it, move it, test it

Use the tools to build the idea. Then check it.

Usa las herramientas para construir la idea. Luego compruébala.

  1. The crime lab's table is for the ratio 3:5. Sort each row by whether it keeps the ratio.
  2. 2 fresh problems with new numbers each time (interactive only).

4. Detective work

Somebody made a mistake. Find the step, then decide who is right.

Alguien cometió un error. Encuentra el paso y decide quién tiene razón.

  1. A technician scaled an ink formula. One step goes wrong. Tap the first step that is wrong.
  2. A detective scaled an evidence ratio. One step goes wrong. Tap the first step that is wrong.
  3. A lab tech shrank a formula. One step goes wrong. Tap the first step that is wrong.
  4. A ratio table for 2:3 has rows 2:3, 4:6, and 6:9. Ana says the next row is 8:12 because she adds 2 and 3. Dev says it is 8:11 because he adds 2 to both. Eli says it is 8:12 because 2:3 times 4 is 8:12. Who finds the next row correctly?
    • Ana and Eli
    • Dev only
    • Eli only
    • All three

5. Boss level

Tell us how sure you are, then solve. Finish with a problem of your own.

Dinos qué tan seguro estás y luego resuelve. Termina con un problema tuyo.

  1. A case ratio is 7 clues to 3 suspects. A bigger file has 35 clues. How many suspects keep the same ratio?
  2. A table shows 4:9 and 20:45. What scale factor takes the first row to the second row?
  3. A lab table has the row 18:24. Which ratio could also be a row in the same table?
    • 6:9
    • 9:16
    • 3:4
    • 13:19
  4. A case file needs 3 evidence stickers for every 2 bags. There are 18 bags, and 10 stickers are already on them. How many more stickers are needed?
  5. Which reason proves that 12:16 and 15:20 are equivalent ratios?
    • 15 − 12 = 3 and 20 − 16 = 4.
    • Both simplify to 3:4.
    • Both rows have a first number that is a multiple of 3.
    • The second number is bigger in both.
  6. Invent a mystery-lab formula with two ingredients. Build a ratio table with at least four rows, explain how you found each new row, and say why adding the same number to both columns does not work.
