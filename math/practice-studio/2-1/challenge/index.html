1. Climb the skill ladder

Each rung is harder than the last, and the numbers change every time.

Cada peldaño es más difícil que el anterior y los números cambian cada vez.

  1. 6 fresh problems with new numbers each time (interactive only).

2. Multi-step missions

Real situations that need more than one step: plan, solve, then check that your answer makes sense.

Situaciones reales que necesitan más de un paso: planea, resuelve y revisa que tu respuesta tenga sentido.

  1. Find the Reasoning Error
  2. Write one statistical question and one non-statistical question about your school's cafeteria. Explain why each question is or is not statistical, and describe what the data would look like for the statistical question.
  3. A survey asks 30 students how many books they read last month, collecting 30 answers. What makes this a statistical question?
    • It is about books
    • Everyone reads the same number
    • The answers vary from student to student
    • It has exactly one correct answer
  4. The Reef Rescue crew has 6 dive teams. For each question, type Yes if it is statistical, then type how many data values the crew would collect.
  5. Reef Rescue wants to learn about plastic on Heron Beach. Analyst A asks, “How many pieces of plastic were collected on Heron Beach in total last year?” Analyst B asks, “How many pieces were collected on Heron Beach in each of the 52 weeks of last year?” Which statement is correct?
    • Only A’s question is statistical, and it collects 1 data value.
    • Only B’s question is statistical, and it collects 52 data values.
    • Both questions are statistical, and each collects 52 data values.
    • Neither question is statistical, because both are about one beach.
  6. Reef Rescue tallied the divers at four reefs, shown in the table. Each diver reports on 3 dives. The statistical question is “How many fish did each diver see on each dive?” How many data values will the team collect?
  7. Mateo says, “Every anemone has the same number of clownfish, so our question ‘How many clownfish live in each anemone?’ has one fixed answer.” The dot plot shows the team’s counts for 10 anemones. What should the team conclude?
    • Mateo is wrong: the counts differ from anemone to anemone, so the question is statistical.
    • Mateo is right: all the anemones have the same count.
    • Mateo is right: a plot with dots means the question has one answer.
    • Mateo is wrong, because 10 anemones are too few to make a question statistical.

3. Build it, move it, test it

Use the tools to build the idea. Then check it.

Usa las herramientas para construir la idea. Luego compruébala.

  1. Sort each set of data by how much variability it shows. Numbers that are all the same have none. Numbers close together have low variability. Numbers far apart have high variability.
  2. Sort each question: could it produce data that vary, or does it have one fixed answer?
  3. Match each question that has one fixed answer with a statistical question about the same topic.

4. Detective work

Somebody made a mistake. Find the step, then decide who is right.

Alguien cometió un error. Encuentra el paso y decide quién tiene razón.

  1. Kenji decides whether “How many dives did Reef Rescue make last year in total?” is a statistical question.
  2. Sana reviews “How many tons of fish did the trawler Sea Wren land in each month of 2025?”
  3. Tariq decides whether “How many days are in each week of April?” is a statistical question.
  4. Mei says the data 120, 121, 120, 122 have more variability than the data 3, 40, 11, 27 because the numbers are bigger. Jamal says the second set has more variability because its numbers are farther apart. Who is right?
    • Mei, because bigger numbers mean more variability
    • Both sets have the same variability
    • Neither, because variability only applies to questions
    • Jamal, because variability is about how spread out the numbers are

5. Boss level

Tell us how sure you are, then solve. Finish with a problem of your own.

Dinos qué tan seguro estás y luego resuelve. Termina con un problema tuyo.

  1. Which statement about statistical questions is true?
    • It must always ask about many different people.
    • It expects answers that can differ from case to case.
    • It is any question whose answer is a number.
    • It is any question about science or sports.
  2. A team records 14, 9, 17, 11, 12 minutes to answer a statistical question about tours. Which of these is the data?
    • The question “How long does each tour last?”
    • The tour guide’s clipboard
    • The word “minutes”
    • The list 14, 9, 17, 11, 12 minutes
  3. The dots show how many fish 10 divers saw. Which sentence describes the data?
    • Every diver saw the same number of fish.
    • Only one diver answered the question.
    • The answers vary, and most divers saw 4 to 6 fish.
    • The data show a fixed answer of 10 fish.
  4. Ms. Okoye’s class collects two kinds of data. For “How many pets does each of the 24 students have?” they collect one value from every student. For “How many students are in the class?” they collect one value, 24, by counting. How many data values do they collect in all?
  5. Which rewrite turns “How many crew members are on Boat 3?” into a statistical question?
    • How many crew members are on each boat in the fleet?
    • How many crew members are on Boat 3 today?
    • How many crew members are in the whole fleet in total?
    • What is the name of the captain of Boat 3?
  6. Create your own problem. Write one statistical question about the reef or the ocean and one question that is not statistical. For the statistical question, say what data you would collect and why the answers would vary. Explain why the other question has only one answer.
