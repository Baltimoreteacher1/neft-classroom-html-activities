Word bankBanco de palabras
statistical questionpregunta estadística
A question that expects different answers, so you collect data to answer it.Una pregunta que espera respuestas diferentes, por lo que se reúnen datos para responderla.
non-statistical questionpregunta no estadística
A question with one fixed answer. Nothing varies, so there is nothing to collect.Una pregunta con una sola respuesta fija. Nada varía, así que no hay nada que reunir.
datadatos
Facts or numbers you collect, such as the answers to a survey.Hechos o números que reúnes, como las respuestas de una encuesta.
variabilityvariabilidad
How much the values in a set of data differ from one another.Cuánto difieren entre sí los valores de un conjunto de datos.
surveyencuesta
A way to collect data by asking people the same question.Una manera de reunir datos preguntándoles a las personas la misma pregunta.

2. Practice with support

Start here. Use the hints whenever you need them; every wrong answer tells you why.

Empieza aquí. Usa las pistas cuando las necesites; cada respuesta incorrecta te dice por qué.

  1. Which of the following is a statistical question?
    • How many points did each player score this season?
    • How many points are scored for a free throw?
    • What sport does this team play?
    • How many halves are in a soccer game?
  2. Which question is NOT a statistical question?
    • How many home runs did each player hit this year?
    • How many miles does each runner train per week?
    • How many innings are in a baseball game?
    • How tall is each player on the basketball team?
  3. Why is 'How many hours of sleep did each student get last night?' a statistical question?
    • Because different students got different amounts of sleep
    • Because it asks about sleep
    • Because hours are numbers
    • Because the answer is always 8 hours
  4. Match each question to its type.
  5. Sort these questions into Statistical or Not Statistical.
