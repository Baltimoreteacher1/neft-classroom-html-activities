1. Climb the skill ladder

Each rung is harder than the last, and the numbers change every time.

Cada peldaño es más difícil que el anterior y los números cambian cada vez.

  1. 6 fresh problems with new numbers each time (interactive only).

2. Multi-step missions

Real situations that need more than one step: plan, solve, then check that your answer makes sense.

Situaciones reales que necesitan más de un paso: planea, resuelve y revisa que tu respuesta tenga sentido.

  1. Find the Exponent Error
  2. A new song from the studio is shared online, and the number of shares doubles every hour. Starting with 1 share, write a power expression for the number of shares after 6 hours. Explain why exponential growth is so much faster than adding the same number each hour.
  3. Fill in the table
  4. On Summit Trail, every fork splits the path into 2 new paths. A hiker passes 5 forks, so each different choice of paths makes a different route. A ranger puts one marker on every route, and each marker costs $3. How much do the markers cost?
    • $30
    • $75
    • $15
    • $96
  5. On Day 0, one hiker knows about a trail closure. Each day, the number of hikers who know doubles. Fill in how many hikers know on each day.
  6. Ridge Route has 3⁵ steps. Valley Route has 5³ steps. Which route has more steps, and by how many?
    • Valley Route, by 118 steps
    • Ridge Route, by 118 steps
    • Ridge Route, by 2 steps
    • They have the same number of steps
  7. A trail cairn is built in 4 square layers. The layers have 2², 3², 4² and 5² stones. How many stones are in the whole cairn?

3. Build it, move it, test it

Use the tools to build the idea. Then check it.

Usa las herramientas para construir la idea. Luego compruébala.

  1. Work out each power, then sort it by its value.
  2. Match each power to its value.
  3. The value of 3 raised to a power is 81. Tap the exponent.
  4. Invent a story that grows by a power, such as a rumor that spreads or a path that keeps splitting. Write it as a power, expand it, and evaluate it. Then write one mistake a classmate might make.
  5. 2 fresh problems with new numbers each time (interactive only).

4. Detective work

Somebody made a mistake. Find the step, then decide who is right.

Alguien cometió un error. Encuentra el paso y decide quién tiene razón.

  1. Ilan evaluates 8². Tap the step where his work first goes wrong.
  2. Lucía evaluates 2⁶. Tap the step where her work first goes wrong.
  3. Hana evaluates 5⁴. Tap the step where her work first goes wrong.
  4. Ana says 3⁴ must be double 3², because the exponent doubles from 2 to 4. Ben says that is not true. Who is right?
    • Ana, because doubling the exponent doubles the value
    • Ben, because 3⁴ = 12
    • Ben, because 3⁴ = 81 is nine times 3² = 9
    • Neither, because 3⁴ and 3² have the same value
  5. What is the best next move?
    • Work out 3³ the same way: 3 × 3 × 3.
    • Add the bases and exponents: 4 + 3 and 2 + 3.
    • Add 16 + 3, then use the exponent 3 on the sum.
    • Stop here, because 4² + 3³ is already finished.
  6. 1 fresh problem with new numbers each time (interactive only).

5. Boss level

Tell us how sure you are, then solve. Finish with a problem of your own.

Dinos qué tan seguro estás y luego resuelve. Termina con un problema tuyo.

  1. Which power is the same as 5 × 5 × 5 × 5 × 5 × 5?
    • 6⁵
    • 5 × 6
    • 30¹
    • 5⁶
  2. A chain of trail lamps starts with 1 lit lamp on Day 0. Each day, every lit lamp lights one more, so the number of lit lamps doubles each day. How many lamps are lit on Day 10?
  3. Which of these is NOT equal to 64?
    • 6²
    • 8²
    • 4³
    • 2⁶
  4. At a trail festival, 1 guide greets 4 hikers, and then each of those hikers greets 4 more hikers, for 3 rounds in all. The number greeted in round 3 is 4³. How many hikers are greeted in round 3?
  5. Which statement about 2⁵ and 5² is true?
    • They are equal, because they use the same digits
    • 5² is greater, because 5 is the greater base
    • 2⁵ is 10 and 5² is 10, so they are equal
    • 2⁵ is greater, because 32 is more than 25
  6. Create your own Summit Trail problem that uses a power. Tell a story where something multiplies by the same number again and again, write it as a power, and evaluate it. Explain what the base and the exponent mean in your story.
