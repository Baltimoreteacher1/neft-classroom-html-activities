1. Climb the skill ladder

Each rung is harder than the last, and the numbers change every time.

Cada peldaño es más difícil que el anterior y los números cambian cada vez.

  1. 6 fresh problems with new numbers each time (interactive only).

2. Multi-step missions

Real situations that need more than one step: plan, solve, then check that your answer makes sense.

Situaciones reales que necesitan más de un paso: planea, resuelve y revisa que tu respuesta tenga sentido.

  1. Find the Equation Error
  2. Write a real-world situation that can be modeled by the equation n / 5 = 9. Explain what n represents and verify your equation makes sense.
  3. Dara's playlist is 45 minutes long. It opens with an 18-minute intro, then t minutes of songs. She writes 18 + t = 45. Which value of t is the solution?
    • t = 63
    • t = 45
    • t = 27
    • t = 18
  4. Kofi checks mixing levels in the equation 3m = 42. For each test value m, fill in 3m. Then fill in how far 3m is from 42. A distance of 0 means the value is a solution.
  5. Ines needs a whole number t so that 2t = 26. She tries t = 10 and the left side is too small. She tries t = 15 and it is too big. Which whole number between 10 and 15 makes the equation true?
  6. Mateo says: 'After I gave away 9 stickers, I had 15 left.' He lets s be the number of stickers he started with. Which pair of statements is correct?
    • s − 9 = 15, and s = 6 is a solution
    • s + 9 = 15, and s = 6 is a solution
    • 9 − s = 15, and s = 24 is a solution
    • s − 9 = 15, and s = 24 is a solution

3. Build it, move it, test it

Use the tools to build the idea. Then check it.

Usa las herramientas para construir la idea. Luego compruébala.

  1. The value is x = 6. Sort each equation by whether x = 6 is a solution of it.
  2. Write an addition equation for a real situation, such as saving money or collecting items. Say what the variable means. Name one value that is a solution and one value that is not. Show the substitution for both and tell how you know.
  3. 4 fresh problems with new numbers each time (interactive only).

4. Detective work

Somebody made a mistake. Find the step, then decide who is right.

Alguien cometió un error. Encuentra el paso y decide quién tiene razón.

  1. Tariq writes an equation for 'a number decreased by 8 equals 5'.
  2. Lena tests whether w = 6 is a solution of w + 3 = 10.
  3. Jun tests whether c = 5 is a solution of 4c = 20.
  4. Amara and Dev test t = 9 in the equation t ÷ 3 = 3. Amara says 9 ÷ 3 = 3, so it is a solution. Dev says it is not a solution because 9 is not equal to 3. Who is right?
    • Dev, because the value must match the right side.
    • Both, because 9 and 3 are both in the problem.
    • Amara, because 9 ÷ 3 = 3 makes both sides equal.
    • Neither, because a solution must be less than 9.
  5. What is the best next move?
    • Parts add to the whole.
    • Write r + 35 = 17.
    • Write r = 17, since 17 is the number that is known.
    • Write r − 17 = 35.
  6. 1 fresh problem with new numbers each time (interactive only).

5. Boss level

Tell us how sure you are, then solve. Finish with a problem of your own.

Dinos qué tan seguro estás y luego resuelve. Termina con un problema tuyo.

  1. The studio had some microphones. After 6 were sold, 11 were left. Which equation matches the story, with m for the starting number?
    • m + 6 = 11
    • 6 − m = 11
    • m − 6 = 11
    • 6m = 11
  2. A value p makes the equation p ÷ 4 = 9 true. What is p?
  3. Which value is a solution of 7y = 56?
    • y = 49
    • y = 63
    • y = 392
    • y = 8
  4. Which equation has n = 12 as a solution?
    • n ÷ 4 = 3
    • n + 9 = 3
    • n − 5 = 17
    • 2n = 14
  5. How many of these equations have w = 14 as a solution? w + 5 = 19, w − 5 = 9, 5w = 70, w ÷ 2 = 28.
  6. Make up a short story about a band or a recording studio that can be written as an equation. Write the equation, pick a number for the variable, and show by substituting whether that number is a solution.
