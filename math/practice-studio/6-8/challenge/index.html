2. Multi-step missions

Real situations that need more than one step: plan, solve, then check that your answer makes sense.

Situaciones reales que necesitan más de un paso: planea, resuelve y revisa que tu respuesta tenga sentido.

  1. Find the Property Error
  2. Explain why the commutative property works for addition and multiplication but NOT for subtraction and division. Give a specific number example for each operation to prove your point.
  3. Fill in the table
  4. Two cooks add up the weight of a tray. Cook A writes 14 + n + 6 and Cook B writes n + 20, where n is the weight of the sauce. Which statement is correct?
    • They are not equivalent, because one has three terms and the other has two.
    • They are not equivalent, because the 6 moved to a different place.
    • They are equivalent only when n = 0.
    • They are equivalent: reorder the terms, then add 14 + 6 = 20.
  5. A catering quote is 9 + 4n + 11 + 2n dollars for n trays. Rewrite it with fewer terms, then find the quote for 5 trays.
  6. A bag has 12 kg of flour and the kitchen uses 5 kg. Trainee Imani writes 5 − 12 for the flour left because "the order shouldn't matter." What is true?
    • 12 − 5 = 7 kg is left, but 5 − 12 cannot be done: order matters.
    • The two give the same answer, because they use the same numbers.
    • Order matters for division, but never matters for subtraction.
    • She is right, because you can swap the numbers in any operation.
  7. A cook lists the cost of n burgers as n + n + n + n + 6. Which equivalent expression is the simplest?
    • 10n
    • 4n + 6
    • n⁴ + 6
    • 6n + 4

4. Detective work

Somebody made a mistake. Find the step, then decide who is right.

Alguien cometió un error. Encuentra el paso y decide quién tiene razón.

  1. Chef Dev says 24 ÷ n can be rewritten as n ÷ 24. Tap the step where his reasoning goes wrong.
  2. Nia looked at 3 × (n × 4) = 3 × (4 × n) and labeled it. Tap the step where her reasoning goes wrong.
  3. Mo wants a simpler way to write n + n + n + 4. Tap the step where his work goes wrong.
  4. Ana says 7 × 1 = 7 shows the identity property. Ben says 7 × 0 = 0 shows the identity property too, because zero is special. Who is right?
    • Only Ben: multiplying by 0 is the identity.
    • Both are right: any property that uses 0 or 1 is an identity property.
    • Only Ana: multiplying by 1 keeps the number the same.
    • Neither, because the identity property is only for adding.
  5. What is the best next move?
    • Replace n × 1 with 1, because anything times 1 is 1.
    • Remove ×1 and +0; neither changes the value.
    • Move the parentheses to make n × (1 + 0) + 7.
    • Replace 0 + 7 with 0, because adding 0 gives 0.

5. Boss level

Tell us how sure you are, then solve. Finish with a problem of your own.

Dinos qué tan seguro estás y luego resuelve. Termina con un problema tuyo.

  2. Use properties to regroup 5 × 37 × 20 so the mental math is easy. What is the product?
  3. Which expression is equivalent to 7 + 3n + 8 + n?
    • 4n + 15
    • 3n + 15
    • 19n
    • 15n + 4
  4. Which statement is FALSE?
    • n + 9 = 9 + n for every n
    • n ÷ 4 = 4 ÷ n for every n
    • n × 8 = 8 × n for every n
    • (n + 2) + 6 = n + (2 + 6) for every n
  5. Evaluate 1 × n + 0 + n × 1 when n = 12.
  6. Create your own expression with a variable and at least three terms. Rewrite it two different ways and name the property you used each time. Then give one example of a swap that would NOT work, using division.
