  2. A theme park has two rides. Ride A requires height h > 48 inches. Ride B requires height h ≥ 48 inches. A child is exactly 48 inches tall. Which ride can they go on? Explain using number line graphs for both inequalities.

4. Detective work

Somebody made a mistake. Find the step, then decide who is right.

  4. Bruno says that 4.9 is a solution of y < 5. Nia says only whole numbers can be solutions. Who is right?
