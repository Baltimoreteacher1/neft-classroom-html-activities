Stretch: Which Display Tells the Story Best?

I can choose the best data display for a question and read values from a histogram.

🧠 The Big Idea

A dot plot shows every value (good for small data sets). A histogram groups values into intervals (good for large data sets and showing shape). A box plot shows spread and the middle 50% (good for comparing groups).
