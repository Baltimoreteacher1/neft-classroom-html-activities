Stretch: Likely, Unlikely, Certain, Impossible

I can use the language of probability to describe how likely an event is.

🧠 The Challenge

likelyunlikelycertainimpossibleequally likely

Probability words describe chance. An event is certain if it must happen, impossible if it cannot, and equally likely if both outcomes have the same chance (like a fair coin).

👀 Worked Example

Rolling a number from 1–6 on a standard die is certain. Rolling a 7 is impossible. Flipping heads on a fair coin is equally likely.
