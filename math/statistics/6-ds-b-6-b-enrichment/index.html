Stretch: Attribute and Units of Measurement

I can describe what attribute a data set measures and the units used.

🧠 The Challenge

attributeunitsvariablemeasurement

Every data set measures an attribute (what is measured, like height or time) in some units (how it is measured, like centimeters or minutes). Name both to describe the data.

👀 Worked Example

"Heights of plants in centimeters": attribute = height, units = centimeters. "Times to run a mile in minutes": attribute = time, units = minutes.

1. "Times to run a mile in minutes" — the units are…

2. "Weights of dogs in kilograms" — the attribute is…

3. "Temperatures recorded in °C" — the units are…

💬 Explain Your Thinking

"The attribute being measured is ____, and the units are ____."
