Displaying Data: Dot Plots, Histograms & Box Plots

I can name common data displays and read a simple dot plot.

📘 Word Bank + Sentence Frames

dot plothistogrambox plotdata displayfrequency (how many)

  • Dot plot: one dot for each data value, stacked above a number.
  • Histogram: bars showing how many values fall in each interval (no gaps).
  • Box plot: a box showing the middle half of the data, with "whiskers".
  • Frame: "In the dot plot, the value ____ appears ____ times."

👀 See It: A Worked Example

Pets per student (each ● is one student):

0 │ ● ●
1 │ ● ● ● ●
2 │ ● ● ●
3 │ ●

The most common value is 1 pet (4 dots). One student has 3 pets.
