Words to knowPalabras clave

  • Number lineRecta numérica

    A straight line where numbers are placed in order; numbers get smaller to the left and larger to the right.Una recta donde los números se colocan en orden; los números son menores a la izquierda y mayores a la derecha.

    A horizontal line with marks at 0, 1, 2, 3, ... showing where values fall

  • Open circleCírculo abierto

    An empty circle showing a number is NOT included.Un círculo vacío que muestra que un número NO está incluido.

    x > 5: open circle at 5 means 5 itself is NOT a solution, but 5.1, 6, 7, ... are

  • Closed circleCírculo cerrado

    A filled-in circle showing a number IS included.Un círculo relleno que muestra que un número SÍ está incluido.

  • Solution setConjunto solución

    All the numbers that make the inequality true.Todos los números que hacen verdadera la desigualdad.

    For x > 3, the solution set includes 3.1, 4, 5, 10, 100 — any number greater than 3

Key ideaIdea clave

Graphing Inequalities on the Number Line.

  1. Draw the boundary circle at the given constant number.
  2. Open Circle (○) for < or > (boundary value is not included in solution set).
  3. Closed Circle (●) for ≤ or ≥ (boundary value is included). Shade right for >, left for <

Graficar desigualdades en la recta numérica. 1. Dibuja el círculo del límite en el número dado. 2. Círculo abierto (○) para < o > (el valor límite no está incluido en el conjunto solución). 3. Círculo cerrado (●) para ≤ o ≥ (el valor límite sí está incluido). Sombrea a la derecha para >, a la izquierda para <

Watch out for a common mistakeCuidado con un error común

A common mistake in Graph Inequalities is treating ≥ and ≤ the same as > and < and drawing the wrong circle. For example, students often graph x ≥ 6 with an OPEN circle (as if it were x > 6), which wrongly excludes 6 even though 6 itself makes x ≥ 6 true. A second common mistake is choosing the right circle but shading the wrong direction — for x < 9 students sometimes shade right instead of left. Always check the symbol twice: once for the circle (does it have an 'or equal to' line?) and once for the shading direction (does the symbol point toward larger or smaller numbers?).

Sentence frameMarco de oración

I use a ___ circle when the symbol is ___ because the boundary value ___ part of the solution.Uso un círculo ___ cuando el símbolo es ___ porque el valor del límite ___ parte de la solución.
