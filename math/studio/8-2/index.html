Words to knowPalabras clave

  • EquationEcuación

    A math sentence with an equal sign showing both sides are the same.Una oración matemática con un signo igual que muestra que ambos lados son iguales.

    x + 25 = 60 — both sides equal 60 when x = 35

  • Inverse operationOperación inversa

    Two math actions that undo each other, like × and ÷.Dos operaciones que se deshacen entre sí, como × y ÷.

    Addition undoes subtraction: if x − 3 = 10, add 3 to get x = 13

  • IsolateDespejar

    To get the letter by itself on one side.Dejar la letra sola en un lado.

    x + 5 = 12 → subtract 5 from both sides → x = 7 (x is isolated)

  • SolutionSolución

    A number that makes the equation or inequality true.Un número que hace verdadera la ecuación o desigualdad.

    x = 7 is the solution to x + 5 = 12 because 7 + 5 = 12 ✓

Key ideaIdea clave

Solving Addition & Subtraction Equations. Formula: x + a = b → x = b − a | x − a = b → x = b + a.

  1. Identify operation on variable.
  2. Use inverse operation: subtract to undo addition; add to undo subtraction.
  3. Property of Equality: do same operation to both sides.

Resolver ecuaciones de suma y resta. Fórmula: x + a = b → x = b − a | x − a = b → x = b + a. 1. Identifica la operación aplicada a la variable. 2. Usa la operación inversa: resta para deshacer una suma; suma para deshacer una resta. 3. Propiedad de igualdad: aplica la misma operación inversa a los dos lados de la ecuación

Watch out for a common mistakeCuidado con un error común

A common mistake is applying the same operation instead of the inverse — for example, solving x − 7 = 15 by subtracting 7 from both sides (getting the wrong x = 8) instead of adding 7 to both sides (the correct x = 22). Another common mistake is doing the inverse operation to only one side, like solving x + 6 = 14 by subtracting 6 from the left but forgetting the right side. Before you submit, name the operation shown in the equation, choose its inverse, apply it to BOTH sides, and check by substituting your answer back into the original equation.

Question: If Margaret's apartment building only allows dogs up to 30 pounds, which breed or breeds would you recommend she adopt?
