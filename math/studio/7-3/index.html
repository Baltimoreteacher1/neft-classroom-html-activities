Step 3 of 9: What is absolute value?Paso 3 de 9: ¿Qué es el valor absoluto?

A rational number is any number that can be written as a fraction: integers like -6, fractions like -3/4, and decimals like 2.5 are all rational numbers. The absolute value of a number is how far it is from zero on the number line. Distance is never negative.Un número racional es cualquier número que se puede escribir como fracción: los enteros como -6, las fracciones como -3/4 y los decimales como 2.5 son números racionales. El valor absoluto de un número es qué tan lejos está del cero en la recta numérica. La distancia nunca es negativa.

Key ideaIdea clave

Absolute Value. Formula: |a| = Distance of a from 0 (always ≥ 0).

  1. Absolute value represents distance on a number line, never direction.
  2. Distance is always positive or zero: |-7| = 7 and |7| =
  3. 7.
  4. Context: Magnitude of temperature, debt, elevation regardless of sign

Valor absoluto. Fórmula: |a| = distancia de a al 0 (siempre ≥ 0). 1. El valor absoluto representa distancia en una recta numérica, nunca dirección. 2. La distancia siempre es positiva o cero: |-7| = 7 y |7| = 7. 3. Contexto: magnitud de temperatura, deuda o elevación sin importar el signo

Watch out for a common mistakeCuidado con un error común

A common mistake in Integers and Absolute Value is judging size by the digits alone instead of position on the number line — students think -8 is 'more' than -3 because 8 > 3, when really -8 sits farther left (colder, deeper, or lower) and is actually the SMALLER integer. Absolute value measures distance from zero and is always positive or zero, but that distance does not decide which integer is greater — only left-to-right order on the number line does. Before you submit, ask: am I comparing distance from zero (absolute value) or position on the number line (greater/less than)?
