How do we turn words into an expression?¿Cómo convertimos palabras en una expresión?

An algebraic expression uses numbers, a variable (a letter for an unknown number), and operations. We read a word phrase and write it with math symbols.Una expresión algebraica usa números, una variable (una letra para un número desconocido) y operaciones. Leemos una frase y la escribimos con símbolos matemáticos.

Watch me

  1. Tickets cost $12 each, plus a flat $50 venue fee. Let t be the number of tickets.Los boletos cuestan $12 cada uno, más una cuota fija de $50 por el lugar. Sea t el número de boletos.
  2. "$12 each ticket" means 12 times t, which I write as 12t.«$12 por cada boleto» significa 12 por t, que escribo como 12t.
  3. The flat fee $50 is added once, so I add 50.La cuota fija de $50 se suma una sola vez, así que sumo 50.
  4. I put them together: total revenue = 12t + 50.Los junto: ingreso total = 12t + 50.

Let's write one together

  1. The field day committee orders one $4.25 item for each student, plus a one-time $23.50 shipping fee. The number of students is unknown.El comité del día de campo pide un artículo de $4.25 para cada estudiante, más una cuota única de envío de $23.50. No se sabe cuántos estudiantes hay.
  2. Let s stand for the number of students. “$4.25 for each student” means 4.25 times s, written 4.25s.Sea s el número de estudiantes. «$4.25 por cada estudiante» significa 4.25 por s, escrito 4.25s.
  3. The shipping fee does not depend on how many students there are, so it is a constant that is added once: 4.25s + 23.50.La cuota de envío no depende de cuántos estudiantes haya, así que es una constante que se suma una vez: 4.25s + 23.50.
  4. The expression 4.25s + 23.50 has two terms: 4.25s, whose coefficient is 4.25, and the constant 23.50.La expresión 4.25s + 23.50 tiene dos términos: 4.25s, cuyo coeficiente es 4.25, y la constante 23.50.

Your turn — now evaluate it

  1. The committee learns that 30 students signed up, so s = 30.El comité se entera de que se inscribieron 30 estudiantes, así que s = 30.
  2. Substitute: replace s with 30 to get 4.25 × 30 + 23.50.Sustituye: reemplaza s por 30 para obtener 4.25 × 30 + 23.50.
  3. Evaluate using the order of operations — which comes first, the multiplication or the addition?Evalúa usando el orden de las operaciones — ¿qué va primero, la multiplicación o la suma?
  4. Find the total cost, and say what your answer means for the committee.Halla el costo total y di qué significa tu respuesta para el comité.

Key ideaIdea clave

Writing & Evaluating Algebraic Expressions.

  1. Define the variable to represent the unknown quantity.
  2. Translate mathematical phrases into operations, coefficients, and constants.
  3. Evaluate by substituting given numerical values for the variable

Escribir y evaluar expresiones algebraicas. 1. Define la variable que representa la cantidad desconocida. 2. Traduce las frases matemáticas en operaciones, coeficientes y constantes. 3. Evalúa sustituyendo los valores numéricos dados en la variable

Watch outCuidado

A common mistake in Write Algebraic Expressions is treating 'each' or 'per' as if it means add instead of multiply, and attaching the variable to the wrong number. For 'a $25 setup fee plus $8 per hour, h,' students often write 25 + 8 + h (adding all three numbers) or 25h + 8 (multiplying the flat fee by h) instead of the correct 8h + 25. Since $8 applies per hour, it must multiply the variable (8h), and the flat $25 fee is a constant added only once — check that the per-unit rate, not the flat fee, is the number multiplied by the variable.

Words to usePalabras para usar
  • Write Algebraic ExpressionsEscribir expresiones algebraicas

    Translate words or a situation into numbers, variables, and operation symbols.Traducir palabras o una situación a números, variables y símbolos de operaciones.

    Five more than n becomes n + 5.

  • Variable

    A letter that stands for a number that is unknown or can change.Una letra que representa un número desconocido o que puede cambiar.

    In 5t + 20, t could be hours worked — if t = 3, the expression equals 35; if t = 8, it equals 60

  • Algebraic ExpressionExpresión algebraica

    A math phrase that has at least one letter.Una frase matemática que tiene al menos una letra.

    3n + 7 means 'triple a number, then add 7' — it has a variable (n), a coefficient (3), and a constant (7)

  • CoefficientCoeficiente

    The number in front of a letter, like the 3 in 3x.El número frente a una letra, como el 3 en 3x.

    In 8x, the coefficient 8 means '8 groups of x' — if x = 3, then 8x = 8 × 3 = 24

  • ConstantConstante

    A fixed number in an expression or equation that does not change.Un número fijo en una expresión o ecuación que no cambia.

    In 3n + 7, the 7 never changes no matter what n is — like a flat fee that stays the same

  • Like termsTérminos semejantes

    Terms with the same letter raised to the same power, like 2x and 5x.Términos con la misma letra elevada a la misma potencia, como 2x y 5x.

    4x + 2x = 6x (like terms, same variable); but 4x + 2y cannot be combined (different variables)

  • SubstituteSustituir

    To replace a variable with a given number before working out the value.Reemplazar una variable por un número dado antes de calcular el valor.

    For s = 30: 4.25s + 23.50 → 4.25 × 30 + 23.50

  • EvaluateEvaluar

    To find what an expression is worth once every variable has a number, following the order of operations.Hallar cuánto vale una expresión una vez que cada variable tiene un número, siguiendo el orden de las operaciones.

    4.25 × 30 + 23.50 = 151

  • TermTérmino

    A part of an expression joined to the other parts by + or −. A term can be a number (50), a variable (t), or a number times a variable (12t).Una parte de una expresión que se une a las otras partes con + o −. Un término puede ser un número (50), una variable (t) o un número por una variable (12t).

    12t + 50 has two terms: 12t and 50.

Sentence frameMarco de oración

The phrase '___ ' tells me to use ___ because the key word ___ means ___.La frase «___ » me dice que use ___ porque la palabra clave ___ significa ___.

Apply: Acceptable Quality Levels

Some industries set three different levels of defects: critical, major, and minor. The acceptable quality levels (AQLs) for an automotive supplier are shown: minor 5%, major 2%, critical 0%. If any of these levels is exceeded, the factory can pause production to examine the source of the defects. A lot of 1,500 sensors had 0 critical defects, 25 major defects, and 143 minor defects. Question: As the supervisor inspecting the lot, what would you do?
