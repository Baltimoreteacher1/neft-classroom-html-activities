2. What is a histogram?2. ¿Qué es un histograma?

A histogram is a bar graph that groups numbers into equal ranges called intervals. The height of each bar is the frequency: how many values fall in that interval. The bars touch because the intervals are continuous.Un histograma es una gráfica de barras que agrupa números en rangos iguales llamados intervalos. La altura de cada barra es la frecuencia: cuántos valores caen en ese intervalo. Las barras se tocan porque los intervalos son continuos.

  2. Interval 0–9: the values 3 and 7 fit, so the frequency is 2.Intervalo 0–9: caben los valores 3 y 7, así que la frecuencia es 2.
  3. Interval 10–19: the values 12, 15, and 18 fit, so the frequency is 3.Intervalo 10–19: caben los valores 12, 15 y 18, así que la frecuencia es 3.
  4. Interval 20–29: only the value 24 fits, so the frequency is 1.Intervalo 20–29: solo cabe el valor 24, así que la frecuencia es 1.
  5. Now I draw three bars with heights 2, 3, and 1, touching each other. The tallest bar (10–19) is where most values are.Ahora dibujo tres barras con alturas 2, 3 y 1, tocándose entre sí. La barra más alta (10–19) es donde está la mayoría de los valores.

Key ideaIdea clave

Histograms & Frequency Distributions.

  1. Set equal intervals along the horizontal axis with no gaps.
  2. Count the frequency (how many data values fall into each interval).
  3. Draw adjacent bars with heights equal to frequency

Histogramas y distribuciones de frecuencia. 1. Marca intervalos iguales en el eje horizontal, sin huecos. 2. Cuenta la frecuencia (cuántos valores caen en cada intervalo). 3. Dibuja barras contiguas con alturas iguales a la frecuencia

Watch out for a common mistakeCuidado con un error común

A common mistake in Display Data: Histograms is counting a boundary value in two intervals at once — for example, putting the value 10 in both the '0–9' bin and the '10–19' bin. Each data value belongs to exactly ONE interval. Before you submit, add up all your frequencies and check that the total matches the number of data values you started with.
