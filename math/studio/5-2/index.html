A triangle has three sides. The base is one side, and the height is the straight-up (perpendicular) distance from the base to the top corner.Un triángulo tiene tres lados. Key ideaIdea clave

Area of Triangles. Formula: Area = ½ × Base × Height (A = ½ b · h).

  1. Identify the base and the perpendicular height to that base.
  2. A triangle is exactly half of a rectangle with the same base and height.
  3. Multiply base by height, then divide by 2

Área de triángulos. Fórmula: área = ½ × base × altura (A = ½ b · h). 1. Identifica la base y la altura perpendicular a esa base. 2. Un triángulo es exactamente la mitad de un rectángulo con la misma base y altura. 3. Multiplica base por altura y luego divide entre 2

Watch out for a common mistakeCuidado con un error común

A common mistake in Area of Triangles is forgetting the ½ — students multiply base × height like a rectangle and stop there, or they use the triangle's slanted side instead of the perpendicular height that's already given. Always check: did I take half, and did I use the straight-up height, not the slanted side?
