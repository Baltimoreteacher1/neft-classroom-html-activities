Adding & Subtracting Decimals: Line Up the Points

I can add and subtract decimals by lining up the decimal points.

📘 Word Bank + Sentence Frames

decimal pointline upplace valuetenths / hundredths

The one rule: stack the numbers so the decimal points are in a line, then add or subtract normally.
  • Fill empty spots with 0 to keep columns even.
  • Frame: "I lined up the decimal points, so the answer is ____."

👀 See It: A Worked Example

Add 1.2 + 0.45. Line up the points (write 1.2 as 1.20):

1.20
+0.45
1.65

The decimal points stay in a straight line. 1.2 + 0.45 = 1.65.
