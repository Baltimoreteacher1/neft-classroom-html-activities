Absolute Value: How Far from Zero

I can understand absolute value as the distance a number is from zero.

📘 Word Bank + Sentence Frames

absolute value | x |distance from 0never negativemagnitude

  • | x | means the distance from x to 0 on the number line.
  • Distance is never negative, so absolute value is always 0 or positive.
  • Frame: "| ____ | = ____ because it is ____ steps from zero."

👀 See It

|−6| = 6 because −6 is 6 steps from zero. |6| = 6 too. Both −6 and 6 are the same distance from zero.
