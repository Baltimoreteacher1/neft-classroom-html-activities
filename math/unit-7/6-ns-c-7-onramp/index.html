Order and Distance from Zero

I can order rational numbers and find absolute value (distance from zero).

📘 Word Bank + Sentence Frames

order (< >)absolute value | x |distance from 0greater / less

  • Order: the number farther right is greater.
  • Absolute value: distance from 0, always 0 or positive.

👀 See It

−6 < −2 (−2 is farther right). But |−6| = 6 and |−2| = 2, so −6 is farther from zero.
