Plotting Points: Right/Left, then Up/Down

I can plot ordered pairs by moving right/left for x, then up/down for y.

📘 Word Bank + Sentence Frames

ordered pair (x, y)origin (0, 0)x = acrossy = up/down

  • Always start at the origin (0, 0).
  • Move x across (right if +, left if −), then y up/down.
  • Frame: "For (____, ____), I move ____ then ____."

👀 See It

To plot (−2, 3): start at the origin, move 2 left (x = −2), then 3 up (y = 3). That lands you in the top-left region.
