Key Words
Learn these 4 navigation terms before you dive in
🦈
Negative Integer
A whole number less than zero. Used to represent depths below sea level.
Sub depth = -100 meters
🌐
Coordinate Plane
A grid with horizontal x-axis and vertical y-axis used to plot positions.
Harbor location = (3, 4)
📏
Absolute Value
The distance a number is from zero. Distance is always positive!
|-100| = 100 meters from surface
🗺️
Distance on Grid
The vertical or horizontal gap between checkpoints found via coordinate math.
From -100m to -200m is 100m

Need a hint on quadrants?

Quadrant signs:
• Quadrant I: (+, +) both x and y are positive.
• Quadrant II: (-, +) x is negative, y is positive.
• Quadrant III: (-, -) both x and y are negative.
• Quadrant IV: (+, -) x is positive, y is negative.

Step 2 — Depth Distances
Calculate vertical distances between depths using absolute values
Your job: Pick two checkpoints to calculate the vertical distance between them. Use the absolute values of their y-coordinates.
Need a hint on vertical distance?

Rules for distance on a vertical scale:
• Opposite sides: Add their absolute values. E.g. helicopter at +5 and submarine at -3: |5| + |-3| = 5 + 3 = 8 units.
• Same side: Subtract their absolute values (larger minus smaller). E.g. sub at -8 and sub at -3: |-8| - |-3| = 8 - 3 = 5 units.

Need a hint on coordinate reflections?

Reflection Rules:
• Reflected over x-axis: (x, y) ➔ (x, -y). The x coordinate stays the same, the y sign flips.
• Reflected over y-axis: (x, y) ➔ (-x, y). The y coordinate stays the same, the x sign flips.
• Reflected over both axes: (x, y) ➔ (-x, -y). Both signs flip!
