Two Different Questions: "How Big?" vs. "Which Is Greater?"

I can tell the difference between absolute value (distance from 0) and order (which number is greater).

📘 Word Bank + Sentence Frames

absolute value | x | distance from 0 size of a debt order (> / <)

Two questions, two answers:
  • Order: "Which is greater?" → the number farther right on the number line.
  • Absolute value: "How far from 0 / how big?" → ignore the sign. |−30| = 30.
  • "−30 < −5 (order), but |−30| > |−5| because −30 is farther from 0."

👀 See It: A Worked Example

Which is greater? (order)

−30 vs. −5 → −5 > −30
(−5 is farther right, less debt is "better")

Which debt is bigger? (absolute value)

|−30| = 30, |−5| = 5 → $30 debt is bigger
(farther from 0)

Same two numbers — opposite answers, because the questions are different!
