Stretch: When Size Matters More Than Order

I can interpret absolute value as magnitude (size) in context and distinguish it from order.

🧠 The Challenge

absolute value | x |magnitude (size)distance from 0order vs. size

Absolute value measures magnitude — how big, ignoring sign. In context: a bigger debt, a deeper dive, a larger temperature drop all use |value|, even though more-negative numbers are lower in order.

👀 Worked Example

Account A: −$50, Account B: −$20. In order, −50 < −20 (A is worse). In magnitude, |−50| > |−20|, so A has the bigger debt ($50).
