# BCPSS ESOL Premium — data contract (v1)

Source of truth for lesson companions. Schemas: `schemas/lesson.schema.json`, `schemas/activity.schema.json`,
`schemas/term.schema.json` (validated with Ajv by `npm run validate:bcpss-lessons`).

## Files and ownership

| Path                                                                                         | Role                                                                                                                                                                                  |
| -------------------------------------------------------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `db/seeds/bcpss/v2/lessons/<unitId>.mjs`                                                     | `export default { version: 1, unit_id, source, lessons: [lesson, …] }` (generated by `tools/build-bcpss-lessons.mjs`; pilot units are hand-authored and flagged `source: "authored"`) |
| `db/seeds/bcpss/v2/lessons-index.mjs`                                                        | generated lazy loaders (same pattern as `index.mjs`)                                                                                                                                  |

## The lesson arc (always these six steps, in this order)

`warm_up` → `input` → `notice` → `interact` → `produce` → `check`. Every lesson also has a `newcomer_path`
(3–4 activities that need no English reading), an optional `extension` for L5–6, and an `exit_check` activity.

## Activity envelope

Same envelope as unit activities: `kind, domain, title, mission, grouping, minutes, tip, materials?, support{l1_2,l3_4,l5_6}, payload`
plus optional `klu`. Rules: mission is ONE student-facing sentence written from the lesson's own content; no timers; the tip is
one teacher sentence; no unit title pasted into any sentence; feedback is kind and specific (second person).

## Payloads for the existing 14 kinds

Unchanged from `db/seeds/bcpss/v2/schema.mjs` (`checkPayload`), except that lesson activities may use smaller counts
(3–6 items) than unit activities.

## Payloads for the new kinds

All items are plain strings; `icon` is a single emoji or an id from `bcpss-teachers/studio/core/icons/`. Every kind must render
from its payload alone in four ways: digital play, print twin, projector mode (large type, one item at a time) and answer key.

```jsonc
// flash_retrieval — spaced retrieval, self-check (no scoring pressure)
{ "cards": [ { "prompt": "What does 'ratio' mean?", "answer": "A comparison of two amounts.", "icon": "⚖️" } ] }          // 3-6 cards

// listen_and_show — hear a sentence, tap what it describes (audio first; text shown after the first listen)
{ "items": [ { "say": "The ratio of red beads to blue beads is 3 to 5.",
               "options": [ { "label": "ratio", "icon": "⚖️" }, { "label": "rate" }, { "label": "unit" } ],
               "answer": 0, "why": "A ratio compares two amounts, like red beads and blue beads." } ] }                    // 3-5 items, 3 options each

// sentence_xray — color-coded functional chunks, drag to rebuild
{ "text": "The central idea is that scientists explore the reef to protect it.",
  "chunks": [ { "text": "The central idea is that", "role": "The big idea starter", "tone": "concept" },
              { "text": "scientists explore the reef to protect it.", "role": "The central idea", "tone": "precision" } ],
  "ask": "Which chunk tells you the big idea?" }                                                                              // chunks join to text exactly; 3-6 chunks; tone in concept|connector|evidence|precision

// speak_and_record — record, replay, self-check (audio never leaves the device)
{ "prompt": "Tell your partner what a ratio is and give one example.",
  "frame": "A ratio compares ___ and ___. For example, ___.",
  "model": "A ratio compares two amounts. For example, 3 red beads for every 5 blue beads.",
  "checklist": [ "I used the word 'ratio'.", "I gave an example.", "I spoke so my partner could hear me." ] }                // checklist 3 items

// exit_check — 2-3 items then a can-do self-rating (with help / by myself / and I can teach it)
{ "can_do": "I can explain what a ratio is.",
  "items": [ { "q": "Which sentence uses 'ratio' correctly?", "options": [ "…", "…", "…" ], "answer": 1, "why": "…" } ] }     // 2-3 items

// point_and_say — newcomer, no reading: picture/icon + audio, student points then says it
{ "items": [ { "term": "ratio", "icon": "⚖️", "cue": "Two groups side by side, 3 red and 5 blue.", "say": "A ratio compares two groups.", "es": "razón" } ] } // 3-5 items

// tpr_cards — newcomer total physical response (verbs/actions only)
{ "items": [ { "command": "Point to the bigger group.", "icon": "👉" } ] }                                                      // 3-6 items

// home_language_bridge — newcomer: say it in English and your home language
{ "items": [ { "term": "ratio", "es": "razón", "note": "Same word as 'reason' in Spanish; in math it compares two amounts." } ] } // 2-4 items

// cognate_detective — sort word pairs: true cognate / false friend / no look-alike
{ "items": [ { "term": "ratio", "es": "razón", "status": "none", "why": "…" } ] }                                              // status in true|false_friend|none; 4-8 items

// morph_lab — build words from parts
{ "items": [ { "word": "unscientific", "parts": [ "un", "scient", "ific" ], "meaning": "not based on science" } ] }              // 3-5 items; parts join to word

// paragraph_builder — KLU organizer that becomes a paragraph
{ "klu": "Explain", "slots": [ { "label": "Claim", "frame": "…" } ], "connectors": [ "because", "so" ], "checklist": [ "…" ], "model": "…" }

// mission_escape — unit finale: 5-7 locks drawn from lesson content + a printable certificate
{ "locks": [ { "title": "Lock 1: Ratio Order", "q": "…", "options": [ "…", "…", "…" ], "answer": 0, "why": "…", "code": "A1" } ],
  "certificate": { "title": "Unit Language Explorer Certificate", "badge": "Language Explorer", "can_do": [ "I can …" ] } } // 5-7 locks
```

## Print twin

Each kind renders (a) a student page: directions with an icon, large type, B&W-safe, space to write; (b) an answer key block.
Lesson PDF order: teacher card (page 1) → student pages by level → newcomer page → exit check → answer key.
Footer on every page: “Not affiliated with or endorsed by Great Minds, McGraw Hill, Activate Learning, Studies Weekly, WIDA, or Baltimore City Public Schools.”

## Audio

Browser `speechSynthesis` at normal (0.95) and slow (0.7) speeds with word-by-word highlight from `boundary` events; text always
visible as the caption. A neural-TTS build step may later fill `media.audio` (`assets/audio/{hash}.mp3` + word timestamps); the player prefers
`audio.human_url` > cached neural file > speechSynthesis.

## Privacy

Recordings, ratings and stars stay on the device (IndexedDB / localStorage, key prefix `bcpss-lesson:`). Nothing is sent to a server.
