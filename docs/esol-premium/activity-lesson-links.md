# Activity-to-lesson links (Language Studio)

Every Language Studio activity is tied to the lesson companion(s) of its own unit, and every lesson lists the
activities that practise it. All 162 units (K-8; ELA, Math, Science, Social Studies) are covered: 2,011 activities,
1,584 lessons.

## What a link means

Generated by `tools/build-bcpss-activity-lessons.mjs` (rules in `tools/lib/bcpss-activity-lessons.mjs`), one file per
unit in `db/seeds/bcpss/v2/lesson-links/`. Never edit those files by hand; change the rules or the unit content and
regenerate (`npm run build:bcpss-activity-lessons`). A link carries the reason it exists:

| how     | meaning                                                                                      |
| ------- | -------------------------------------------------------------------------------------------- |
| `uses`  | the lesson's own arc already runs this exact activity (same kind and title)                  |
| `terms` | the activity's text uses vocabulary the lesson teaches (3 points per new word, 1 per review) |
| `topic` | nothing above matched; closest lesson by shared content words                                |

Each activity gets its best-fit lesson first, plus a second only when it scores within 75% of the best. A lesson no
activity picked is offered its best activity only when there is a real signal behind it.

## Grade 6 math and Reveal Math

Only Grade 6 math has a lesson-level publisher catalog in this repo (the 84 Reveal Math lessons). Those lessons are
matched by shared vocabulary: first the Reveal unit(s) that match the whole BCPSS unit, then lessons inside them,
weighting domain terms over academic words and rare terms over common ones. The result is shown to teachers as
"Reveal Math connection" with the shared words, as a suggestion rather than an official crosswalk.

**Not in the repo, so not claimed:** lesson numbers for Wit & Wisdom, SABES 5E, IQWST, Studies Weekly, BCPSS Social
Studies, or Reveal Math outside Grade 6. For those units the link target is the unit's lesson companions. If a
publisher scope and sequence is supplied, it plugs in beside `revealFor`.

## Checks

- `node tools/validate-bcpss-activity-lessons.mjs` (part of `npm run validate:bcpss`): every activity linked, every
  link names a real lesson of its unit with the current title, both indexes agree, Reveal ids exist, files fresh.
- `node tools/bcpss-studio-sweep.mjs`: on every screen the "Part of lesson" chips equal the linked lessons.
- `node tools/bcpss-studio-links-e2e.mjs`: chips open lessons, lessons list activities back, Reveal Math shows to
  teachers only, and the completion extras work.
