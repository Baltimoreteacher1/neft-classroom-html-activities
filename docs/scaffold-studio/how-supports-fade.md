# How supports fade, and why

There are four steps. Each takes away one kind of help.

| Step | The student sees | Gone at this step |
|---|---|---|
| Full | The whole sentence frame, word help, sentence builder | nothing |
| Partial | A shorter frame | most of the frame |
| Hint | One hint, for example "begin with First" | the frame |
| On my own | Nothing extra | all prompts |

**Who decides.** The student does, with the dial. The system only suggests, from the last few activities. Suggestions are explained in words ("two activities in a row done well at Full").

**Asking for help is never a mistake.** "I need more help" moves up one step, instantly, and is stored only as a yes/no flag. It is not an error, a point lost or a trigger for a message to anyone.

**What "growing out of" means.** If a student used a support before but has not needed it in the last three activities of that domain, it appears in "Supports I am growing out of". It is a celebration, not a test, and the support stays available.

**How it connects to the lab.** The four steps are a student-facing view of the lab's five rungs (model, frame, partial, cue, independent): model and frame are "Full", partial is "Partial", cue is "Hint", independent is "On my own".

**Limits.** A count of activities is not a measure of language. Use it as one piece of evidence next to your own observation.
