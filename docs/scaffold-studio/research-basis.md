# Research basis

This page states the ideas the supports rest on, and how sure we are of each. It cites no specific study by author or year, because none was checked against its source in this build. Anything that needs a real citation is marked **needs verification**, and a person must add the source before the page is shared outside the team.

| Design choice | Idea behind it | Confidence |
|---|---|---|
| Supports fade in four steps (full, partial, hint, none) | Scaffolding works when it is temporary and shrinks as the learner gains control (gradual release of responsibility; "I do, we do, you do"). | Widely taught; **needs verification** of the primary sources |
| The step only ever changes by a suggestion, never a penalty | Learners who ask for help are using a strategy, not failing. Treating help as a cost discourages it. | Reasoned from practice; **needs verification** |
| Tap-a-word shows a short gloss, an image (grades 3-5) and audio | Brief, just-in-time word help keeps readers in the text. Pictures help concrete nouns; they can distract on abstract words, so grades 6-8 default to no pictures. | **needs verification** |
| Home-language glosses | Using a student's full language repertoire supports comprehension for multilingual learners. | Widely held in ESOL practice; **needs verification** |
| Sentence chunks with role labels | Parsing a long sentence into who/did/where/when/how/why makes structure visible. The label is a word plus a border style, never colour alone. | **needs verification** |
| Say-it-first rehearsal, private, never scored | Rehearsing aloud lowers the cost of speaking. Not scoring accent avoids penalising accent, which is not a language error. | Reasoned; **needs verification** |
| Easy-read face (Atkinson Hyperlegible) | Designed for character distinctness. Evidence that it helps students with dyslexia specifically is limited and mixed; we offer it as a comfort choice, not a treatment. | Honest limit stated |
| Counts, not scores, in the profile | A count of "times on my own" is evidence a teacher can read without it becoming a grade or a level. | Product decision (Joel) |

## What this layer does not claim
- It does not estimate, predict or place a WIDA/ACCESS level. The level a teacher enters is a planning input only.
- It does not detect accent, fluency or "correctness" of speech.
- Writing feedback names what the tool can and cannot see; it does not replace teacher judgment.
