# Visual reference board

The seven screenshots supplied on 19 November 2026 are visual direction, not screenshots of this platform. Only the embedded product imagery is relevant. Desktop surroundings are excluded from project assets.

| Reference | Design lesson | Original implementation direction |
| --- | --- | --- |
| Teacher dashboard | Generous space, compact navigation, strong typography, resource thumbnails | Navy text, muted teal actions, coherent panels, observed evidence only |
| Student pathway | Illustrated progression, obvious next action, readable task grouping | Preserve current continue/practice routes; use purposeful scene imagery |
| Illustrated reader | Story illustration dominates; narration and type controls stay contextual | Extend existing reader with composed pages and accessible controls |
| Language game environment | Spatial scenes, recognizable objects, purposeful discovery | Extend existing worlds; never call a static background a playable game |
| Conversation | Contextual characters, clear turn taking, dialogue remains readable | Original vector scene and character system around existing conversation logic |
| Writing | Readable text, local annotations, contextual next steps | Focused paper workspace; preserve authorship and targeted feedback |
| Museum | Cohesive lighting, distinct artifacts and rooms | Original art only; retain evidence-based exploration mechanics |
| Family | Warm human context, minimal first step | Large accessible controls and clear practice types |

## Shared direction

Warm neutral surfaces; deep navy hierarchy; muted teal and sage; restrained warm accents. Existing legible fonts remain locally hosted. Borders separate controls; whitespace separates tasks. Motion communicates a real state and respects reduced motion. No copied graphics, fake metrics or fabricated progress.

## Review criteria

Compare hierarchy, scene richness, legibility and control placement against these references, rather than claiming pixel fidelity. Inspect desktop (1440), tablet (820) and mobile (390/375). Functional tests cover real controls and recovery, not just screenshots. Explicitly report surfaces not yet transformed.
