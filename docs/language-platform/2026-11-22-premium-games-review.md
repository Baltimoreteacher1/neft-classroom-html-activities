# Premium language games review — 22 November 2026

This is a structured design critique using the requested expert lenses. It is **not** a meeting or endorsement by external professionals. The live site was checked through its public response and the repository; the interactive browser host was unavailable during discovery. The shipped catalog at this revision has 22 games, including vocabulary, reading, sentence, speaking rehearsal, evidence, an escape room, and a four-land expedition.

## Decision criteria

A subscription-worthy game must create repeatable language use, actionable feedback, content breadth, accessible play, and a reason to return that is tied to learning. It must preserve local-only learner work and avoid claiming an ACCESS score. Distinctiveness comes from the *decision and feedback loop*, not a larger asset budget.

| Lens | Initial idea and concern | Improvement adopted |
| --- | --- | --- |
| Educational publisher | More quiz boards would duplicate the catalog. | Add a teachable discourse sequence: interpret a partner, reply, then create an original reply in a new context. Author original cases for two grade bands. |
| ESOL and WIDA | Selecting a phrase alone is too shallow, and support cannot be a fake proficiency level. | Include spoken model access, bilingual help, graduated support modes, evidence-aware explanations, and open transfer. Label the modes as support choices. |
| Learning designer | Speed and points can reward guessing. | Use the existing miss → hint → revise → reveal loop; no timer. Explain why each weak move fails. |
| Game designer | A flat question list has little agency. | Use a three-stop route with situational consequences and a new case order on replay. Each decision changes what feedback the player sees. |
| Graphic and 2D design | The current site already has dense artwork; another decorative scene could obscure the text. | Use a legible route map, speech bubble, clear choice targets, and strong state labels, with the existing illustration on the hub card. |
| 3D and professional game production | A 3D scene would add download, device, and navigation costs without helping discourse practice. | Keep gameplay in 2D, target touch and keyboard, and make progress resilient to reload. Reserve 3D for future spatial-language tasks with a measurable benefit. |
| Product and subscription | One novelty game alone does not establish recurring value. | Add the game to an existing sequence and teacher assignment flow so it participates in progress, local history, replay, and transfer. Do not add a paywall or subscription claim without billing and account infrastructure. |

## Build choice

**Conversation Crossroads** fills the discourse gap. Three original cases per band cover clarifying, building on evidence, and respectful challenge. The existing Game Studio provides save/resume, support choice, language history, and teacher sequence links. The new game supplies deterministic replay order, specific feedback, accessible 2D route states, and an original written transfer prompt.

## Next content investments

1. Expand the case library by subject and grade, with editorial review for factual claims and Spanish.
2. Add a teacher authoring flow for classroom scenarios and a privacy-safe export of completed transfer work.
3. Pilot with multilingual learners and teachers, measuring completion, revision, oral participation, and whether the transfer writing shows improvement. Do not infer impact from play counts alone.

Research basis: WIDA ELD Standards Framework (https://wida.wisc.edu/teach/standards/eld), IES English Learner Practice Guide (https://ies.ed.gov/ncee/WWC/PracticeGuide/19/Published), and EEF feedback synthesis (https://educationendowmentfoundation.org.uk/education-evidence/teaching-learning-toolkit/Feedback).
