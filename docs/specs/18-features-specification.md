# 3. IMPLEMENT ALL 18 RECOMMENDED UPGRADES

## FEATURE 1 — Adaptive Question Pathways

Replace fixed progression as the only learning route.

## FEATURE 2 — Misconception Detection and Repair

Develop lesson-specific misconception libraries.

For each relevant concept, include:

- Plausible incorrect strategies.
- Observable diagnostic indicators.
- Follow-up diagnostic questions.
- Interactive visual models.
- Conceptual explanation prompts.
- New independent verification tasks.

Example: A student calculates the area of a parallelogram using the slanted side rather than the perpendicular height.

The system should present a targeted comparison, allow manipulation of the figure, and require a new independent area calculation.

A single incorrect response must not automatically be treated as proof of a specific misconception.

## FEATURE 3 — Manipulatives Embedded Directly in Problems

Place meaningful interactive mathematics beside relevant questions.

Students must be able to construct and manipulate models without navigating to separate websites or tools.

Examples:

- Move fraction sections.
- Complete ratio tables.
- Adjust double number lines.
- Manipulate percent tapes.
- Balance equations.
- Drag geometric vertices.
- Rearrange shapes.
- Modify datasets and graphs.

Manipulatives must actually function and update mathematical state.

Do not add decorative diagrams that merely resemble interactive tools.

## FEATURE 4 — ST Math-Inspired Visual Consequences

Create original, mathematically driven animations.

Students make mathematical decisions and observe accurate consequences.

Examples:

- A balance moves based on equation values.
- Fraction sections reveal gaps or overlaps.
- A ratio mixture reflects actual quantities.
- A parallelogram's area changes with its perpendicular height.
- A coordinate point moves to its calculated location.
- A statistical display changes when data values are adjusted.

The mathematical relationship must control the visual outcome.

Allow prediction, testing, resetting, replaying, and revising.

Support reduced motion and accessible alternatives.

## FEATURE 5 — Build It → Connect It → Solve It

Implement this instructional progression when appropriate.

**Build It:** Construct a mathematical relationship using a model.

**Connect It:** Match the model to mathematical notation.

**Solve It:** Complete a new independent problem symbolically.

The engine should select which stages are needed.

Do not require every student to complete unnecessary modeling steps when they have already demonstrated understanding.

Maintain meaningful conceptual-to-symbolic connections.

## FEATURE 6 — Intelligent Hint and Feedback Ladder

Build a reusable adaptive intervention sequence.

1. Independent attempt.
2. Targeted mathematical prompt.
3. Strategy or conceptual hint.
4. Interactive model.
5. Guided revision.
6. New independent problem.

Offer the minimum useful amount of support.

Feedback should be specific to the actual mathematical error.

Avoid immediately revealing correct answers.

Track the type of support received and distinguish assisted success from independent success.

## FEATURE 7 — Mathematical Strategy Recognition

Identify mathematical approaches demonstrated through observable student actions.

Examples:

- Ratio scaling.
- Repeated addition.
- Finding a unit rate.
- Fraction equivalence.
- Compensation.
- Decomposition.
- Equation balancing.
- Using inverse operations.
- Translating between representations.
- Geometric decomposition.

Provide appropriate feedback:

"You used equivalent ratios to preserve the relationship."

"You solved using a unit rate."

"Try another representation."

Do not pretend to identify a strategy from a final answer when there is insufficient evidence.

## FEATURE 8 — Independent Reattempt After Intervention

Every substantial instructional intervention should culminate in a different problem that checks whether the student can apply the learning independently.

Workflow:

**Error → Diagnostic check → Targeted support → Revision → New independent task.**

Record supported success and independent success separately.

Use appropriately varied questions rather than giving the student the same example with the answer already visible.

This requirement must apply across both standard and challenge practice.

## FEATURE 9 — Predict–Test–Revise Mathematical Investigations

Embed short investigations where the concept supports them.

Students should:

- Make a prediction.
- Manipulate relevant quantities.
- Test the relationship.
- Observe the mathematical result.
- Compare prediction and outcome.
- Revise their reasoning.
- Explain the mathematical relationship.

Use these for:

- Ratio scaling.
- Percentages.
- Geometry.
- Expressions and equations.
- Statistics.
- Coordinates.
- Rational-number relationships.

These should be concise and embedded naturally inside existing practice.

## FEATURE 10 — One-Minute Entry Diagnostics

Provide optional brief prerequisite checks.

Typically use two or three strategically selected items when appropriate.

Example:

Before finding the whole from a part and percent, check whether a student understands percent as a relationship between part and whole.

Use results to recommend a useful starting point.

Allow students to skip diagnostics.

Never present these short checks as comprehensive mastery assessments.

When the student changes a mathematical model, all associated representations should update correctly.

Examples:

**Geometry:** Adjust dimensions and update the correct measurement or area relationship.

**Statistics:** Modify data and update the corresponding graph and summary measures.

Use shared mathematical state.

Students should:

- Construct statistical and nonstatistical questions.
- Generate or organize sample data.
- Explore variability.
- Observe changes to data displays.
- Explain why statistical questions anticipate variability.

## Lesson 3-3 — Equivalent Ratios Using Tables

Build synchronized:

- Ratio tables.
- Visual quantity models.
- Double number lines.
- Corresponding coordinate relationships where appropriate.

Students adjust quantities and observe whether equivalence is preserved.

Incorrectly scaling only one quantity should produce a meaningful visual mismatch.

Include strategy identification and new independent transfer.

## Lesson 4-4 — Finding and Comparing Percentages

Build interactive percent tapes and part-whole models.

Students should compare percentages of different wholes and explore why a smaller percentage can represent a larger quantity.

Example:

Compare 50% of 12 and 25% of 40 using synchronized visual models.

Include applications and independent symbolic reasoning.

Challenge should require constructing examples, defending comparisons, and investigating generalizations.

## Lesson 4-5 — Determine the Whole Given a Part and Percent

Build interactive reverse-percent tape diagrams.

Students should:

- Identify the known part.
- Represent its percentage.
- Construct the whole.
- Connect the model to division.
- Find unknown original values.
- Solve reverse-discount contexts.
- Correct common part-whole confusions.

Challenge should include reverse-engineered discounts and multiple valid situations producing the same final value.

**Important:** Audit the existing Lesson 4-5 naming/objective inconsistency between the curriculum directory and specific practice pages. Use the authoritative lesson source to resolve this before applying structural changes. Do not silently change mathematical objectives or introduce incorrect titles.

## Lesson 5-1 — Area of Parallelograms

Build interactive geometry.

Students should:

- Manipulate vertices and base-height relationships.
- Distinguish slanted side length from perpendicular height.
- Construct equivalent rectangles.
- Observe how area changes.
- Explain why base × height works.
- Compare different parallelograms with equal area.

Challenge should include reverse problems, multiple dimensions producing the same area, and justification of invariance under appropriate transformations.

## Lesson 8-2 — Addition and Subtraction Equations

Build an interactive algebra balance.

Students should:

- Model equations with quantities.
- Add or remove equal values from both sides.
- Observe equality being preserved or broken.
- Connect actions to symbolic equations.
- Use inverse operations.
- Solve independently.
- Repair incorrect equation transformations.

Challenge should include constructing equations, evaluating solution methods, and defending equivalence.
