# Ratio table practice update

Scope: the eight workshop tasks in each Unit 3 ratio, rate, graph, comparison, and conversion lesson (56 tasks).

Acceptance: students enter both columns of three-row ratio tables, use equivalent rows to answer, receive cell-specific feedback, and retain their table work across reloads and downloads. The first two tasks provide a known row; independent and reasoning tasks start with blank rows. Worked examples show completed tables and scaling steps. Printable tasks provide blank grids; separate keys show completed tables. Existing answers are preserved when an older completed task needs its new table work.

Verification: independently check equivalence of every generated table; cover save/restore and stale status; browser-check correct and incorrect table entries, keyboard focus, downloads, responsive layout and contrast; render every student booklet; run the repository gate and build. Publication requires separate approval under the working agreements.
