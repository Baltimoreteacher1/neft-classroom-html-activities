### 3.3 Word record

```json
{
  "id": "va.cautious.adj",
  "hw": "cautious",
  "pos": "adj",
  "tier": "tier2",
  "cats": ["morph-productive"],
  "level": 1,
  "pron": "KAW-shus",
  "def": "Careful to avoid danger or mistakes.",
  "senses": [
    {
      "pos": "n",
      "def": "second sense, ONLY when a genuinely different sense is taught",
      "example": "…"
    }
  ],
  "ex": "The cautious hiker tested each rock before stepping on it.",
  "ex2": "She was cautious about sharing her password.",
  "nonExample": "Running across a busy street without looking is not cautious.",
  "syn": ["careful", "wary"],
  "ant": ["reckless"],
  "family": [
    { "w": "caution", "pos": "n" },
    { "w": "cautiously", "pos": "adv" }
  ],
  "morph": {
    "segs": [
      { "t": "base", "s": "caution", "m": "care taken to avoid risk" },
      { "t": "suffix", "s": "-ous", "m": "full of; having" }
    ],
    "note": ""
  },
  "rel": "careful and careless",
  "apps": { "academic": "…", "spoken": "…", "writing": "…" },
  "cloze": { "s": "The ___ driver slowed down on the icy road.", "f": "cautious" },
  "cloze2": { "s": "After the accident, Mika became more ___ near water.", "f": "cautious" },
  "misuse": {
    "s": "The cautious runner dashed into traffic without looking.",
    "why": "A cautious person avoids danger; this person ignores it."
  },
  "visual": {
    "kind": "scene",
    "glyphs": ["🧗", "⚠️"],
    "alt": "A climber testing a handhold next to a warning sign."
  },
  "es": { "gloss": "cauteloso", "cognate": true },
  "frame": "I am cautious when I ___.",
  "src": {
    "method": "original-curation",
    "basis": ["academic-utility", "morphology", "comprehension"],
    "note": ""
  }
}
```

Field rules:

- `id` = `va.<slug of hw, a-z0-9 and hyphen>.<pos>`; globally unique; second teaching of the same hw/pos appends `.2`.
- `pron`: plain respelling (hyphen-separated syllables, STRESSED SYLLABLE IN CAPITALS). No IPA required; if you add `ipa`, it must be correct.
- `def`: student-friendly, uses simpler words than the headword, grade-appropriate (K–2 ≤ 9 words, 3–5 ≤ 14, 6–12 ≤ 22). Never uses the headword or its family.
- `ex`/`ex2`: natural original sentences in different contexts (different subjects, setting, sentence structure), sense = `def`.
- `nonExample`: include when it clarifies (omit key otherwise); never a bare negation of the definition.
- `syn`: ≤4 real near-synonyms (no rare words); `ant`: **omit the key** when no natural opposite exists. Never invent one.
- `family`: only real, standard English words. `morph.segs`: omit `morph` entirely for non-decomposable words; every `s` must be a real part of the word as spelled (spelling changes noted in `note`); `m` is the meaning contributed. NO invented etymologies, no folk etymology. Origin claims (`note`) only if certain; otherwise put the doubt in `editorial.needsReview`.
- `cloze.f` is the exact surface form that fills the blank; `cloze.s` contains `___` exactly once and reads grammatically with `f`; the sentence must NOT be answerable by grammar alone: a context clue is required. `cloze2` is a different sentence.
- `misuse.s` uses the target in a plainly WRONG way that a student who knows the word can detect; `why` explains.
- `visual.glyphs`: 1–3 emoji (the program's illustration system is emoji-scene cards composed by the UI). Use `"kind":"diagram"` with `"diagram":"spectrum|contrast|cycle|web|flow"` + glyphs `[]` for abstract words; `"kind":"none"` is allowed for function words. `alt` is a real description.
- `es.gloss`: Spanish translation of THIS sense; `cognate` boolean. Spanish glosses are unreviewed by a native speaker — mark doubtful ones in `editorial.needsReview`.
- `level`: 1–3 position inside the grade (1 early, 3 late).
- Grades K–2: shorter everything; `apps.academic` may be a classroom phrase; `nonExample` simple; morphology limited to plurals/-ed/-ing/-er/-est/un-/re-/compound words.

## 4. Learning model (Core agent implements; others consume through `contract.js`)

Evidence dimensions (`DIMS`): `rec` recognition, `mean` meaning, `ctx` contextual comprehension, `morph` morphological
understanding, `prod` productive use, `delay` delayed retrieval. Each word keeps `{ [dim]: { c: correct, n: attempts, last: ISO } }`.
Word states (`STATES`): `new → learning → developing → applying → secure`, plus `review-needed`. State derives from evidence,
never from one correct answer: `learning` after first exposure; `developing` needs correct `mean` OR `rec` ≥ 2 of the last 3;
`applying` additionally needs `ctx` correct and `prod` attempted; `secure` needs `delay` correct at ≥ 7-day interval AND ≥ 2
independent dimensions correct recently; a miss on a `secure/applying` word after its due date → `review-needed`. Support use is
recorded on each attempt (`sup: [keys]`) and a correct answer WITH heavy support counts at half weight toward advancing state (it
never counts against the student). Do not drop a student to lower-grade content because of a few errors.
Spaced review (`INTERVAL_DAYS = [1,3,7,14,30,60]`): correct on or after due → step+1; early correct → step stays; miss → step−2
(min 0), `lapses+1`, due tomorrow. Teacher can set `reviewPerDay` (default 8, range 3–20). No claim of guaranteed retention anywhere in copy.
Storage key `VA_KEY = "accessPracticeLab:v1:vocabAcademy"` (JSON `{v:1,…}`), written through `storage` from `src/util.js`, with a
truthful `saveState` event (`saved | saving | error-recoverable`). Import/export hooks join the existing `store.js` export code (Core agent).
