# Award readiness

This is not an award submission and not a certification. Differentiators below are descriptions of what the branch actually contains.

## Differentiators that are in the product today

- One lesson engine still renders the core lessons, and the shell now shows the lesson’s own learning target.
- Equivalent ratios on the Living Math Canvas can show five representations from one scale factor, with a deterministic invariant test.
- `3^2` has an explicit repair that rejects “multiply by the exponent” and then offers a new power.
- Family pages already say the work is optional and ungraded, and a guard test fails if policy language turns it into required homework or bonus credit.
- The curriculum home keeps the existing teacher tools and adds a first-screen grouping.

## Five working demo routes

These are existing routes, not mock pages.

1. Equivalent ratios: `/curriculum/math-canvas/?scene=equivalent-ratios&lesson=3-3`
2. Exponent repair: `/curriculum/almost-right-lab/#exponent-repair`
3. Teacher path: `/curriculum/` then `/lessons/3-3-group1/`
4. Family Spanish: `/lessons/6-4/homework.html?lang=es`
5. Project studio: `/curriculum/projects/studio/?project=discovery`

## Not yet evidenced

- A full browser play of those five routes.
- axe or contrast results.
- Regenerated family homework HTML.
- Individual rebuilds of bespoke games.
- `npm run qa:loop` on this branch.
- Any claim about student learning gains, awards, or external review.
