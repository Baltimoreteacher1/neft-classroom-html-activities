`math/fluency-lab/problem-numbers.js` (`item.expr` first, so story problems work, then `item.question`).
Guard: `tools/fluency-model-inputs.test.mjs` (80 skills, plain and story versions).

## Removed

Number-line jump / hop models for whole-number and decimal addition and subtraction (generator models, Build it
lessons, the "Open Number Line Hops" and "Jump Back" widgets, the drawer's hop buttons), the equal-jumps
pattern model, and the "groups on a number line" division model. Number lines stay for integers, absolute
value, rounding and inequalities.

## Not changed on purpose

Guided practice still opens one coach step per miss (coached, never counts as independent). The "Show the model"
panel opens by default (a pre-existing line sets it visible after it was collapsed). The model pictures inside
`item.model` hold the answer only inside checked boxes that the learner fills (`data-expect`), as before.

## Review follow-up (2026-10-22)

An independent review of the model changes found, and this change fixed:

- Help before the first answer (opening the Interactive Solver, opening the Math Tool Drawer, a missed or opened column-board box) now sets `hintBeforeFirst`, so the answer no longer counts as independent. The drawer's "Try my own numbers" is covered by the same flag because the drawer must be opened first. A checkup offers no solver or drawer.
- A power of ten ("3 × 10^2") no longer opens the multiplication board or auto-fills a wrong product (`plainProduct` in `problem-numbers.js`).
- A division framed as "b × ? = a" and then split into tens and ones shows only the framing step (`peekCap`); the generator keeps its own test (`leakCap`).
- The column-board copy into the answer box now also checks the operator; the carry and regroup boxes are 44px; a problem with no model no longer shows an empty panel and a "Hide the model" button.

Known and left for a later pass (none of these show a final answer on first view):

- Older solvers (long division, fractions, balance, LCM/GCF) still keep targets in hidden `data-*` attributes.
- "Show the model" for signed multiplication in a Build-it lesson draws the product as a position on its number line.
- The drawer clamps some fractions (negative, improper) and a tape ratio above 8 instead of skipping them.
- The equation solver's second step prints the first step's result before it is typed.
- A finished column board re-copies its result if a later box is edited; Tab order runs left to right while the work runs right to left.
- The multiplication board's labels and some drawer labels are English only.
