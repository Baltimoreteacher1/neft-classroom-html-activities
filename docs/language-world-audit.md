# Language World audit (2026-11-16)

Scope: turn thelanguagepage.com into an immersive, language-driven quest platform **without duplicating** what exists.
Everything below was verified against this repository, not inferred from URLs.

## 1. What serves thelanguagepage.com

| Fact | Evidence |
| --- | --- |
| The Language Page **is** the ACCESS Practice Lab in this repo: one Cloudflare Pages project, one codebase, two hostnames. `/` on that host redirects to `/access-practice-lab/`. | `docs/language-page-migration.md`, `functions/_lib/language-page.js` |
| The lab is vanilla JS ES modules (no framework): router in `access-practice-lab/src/main.js` (`VIEW_LOADERS` + `parseRoute`), one view file per route, content in `content/*.json`, state in `localStorage` under `accessPracticeLab:v1:*`. | `src/main.js`, `src/store.js` |
| Navigation, the "More" menu, `/explore` and the home registry each read one registry (`src/sitemap.js`, `src/home-registry.js`). A new destination is one entry. | `tools/access-sitemap.test.mjs` |
| Student data stays on the device. No accounts, no analytics. Progress moves between the two hosts only through the explicit `/move` page. | `docs/language-page-migration.md`, `PLATFORM.md` |
| The lab already ships (selection): Speaking/Writing Studios, Language Worlds (4 worlds, `content/worlds.json`), Language City (6 buildings, 12 missions), Science Investigation Lab, Exhibition, Scenarios, Newsroom, Word Lab, Argument Arena, Mentor Texts, Sentence Lab, Voice Lab, Journey, Path, Portfolio (`/portfolio`), Class, Teacher Launch Studio, intro tours, family pages. | `access-practice-lab/PLATFORM.md` |

## 2. Language Adventures and Language Studio: who owns them

| App | Where it is here | Source | Status |
| --- | --- | --- | --- |
| **Language Adventures** (`/language-adventures/`) | `language-adventures/`, a **Next.js static export** (`_next/static`). Nine worlds under `adventures/`: mystery-files, explorers-guild, science-city, history-portal, word-forge, diplomacy-chronicles, media-detectives, communication-lab, language-nexus. Also arcade, studios, mystery-club, family, passport, practice. | **Not on disk.** `docs/language-studio.md`: "its source is no longer on disk (only the export)". | Cannot be edited in place. It logs a React hydration warning (error 418) that only its source can fix. |
| **Language Studio** (`/language-studio/`) | `language-studio/`, a second Next.js export (18 cases, 6 arcade games, 12 studios). | Private repo `Baltimoreteacher1/neft-language-studio` (snapshot). Not part of this repo; republishing needs `tools/sync-static-apps.mjs`. | Out of scope for this build (separate repo, separate build). |
| **ACCESS Practice Lab** | This repo, `access-practice-lab/`. | This repo. | **The place to build.** |

**Decision.** The nine Language Adventures worlds are exports whose source is gone, so they cannot be upgraded in place and rebuilding them would duplicate them. Instead the Quest World is a new, data-driven layer **inside the lab** that:

- uses the same nine world names and links each world to its original `/language-adventures/adventures/<slug>/` page (the validator fails if a link stops resolving);
- adds missions through one mission engine, so the existing adventure pages stay exactly as they are;
- links to, and does not replace, Language City, the Science Lab, Language Worlds, Word Lab, Newsroom and the rest.

## 4. Duplication risks and how they were handled

| Risk | Handling |
| --- | --- |
| A second set of nine worlds | Worlds are names plus a link; missions are the only new content. |
| A second portfolio | `/portfolio` (existing, writing/speaking records) is untouched. The Quest portfolio holds **mission runs and creations only** and links out. A later merge is listed in progress notes. |
| A second progress format | One key, `accessPracticeLab:v1:quest` (versioned), under the prefix that `/move`, Start fresh and the offline pack already treat as lab data. |
| Parallel dialogue / scaffold systems | New, deliberately small, and independent of the Language City engine; they reuse its conventions (bilingual pairs, untimed, supports recorded as supports). Merging them is future work. |
| A second recorder | Reuses `recorder.js` / `recorderHTML` exactly (in-memory takes, never uploaded). |


## 6. Constraints honoured

No accounts, uploads, chat, public profiles, third-party analytics or AI calls were added. Writing checklists look for words and shape and say so; nothing claims to understand free text or to rate speech. No WIDA level or ACCESS score is computed or shown (the validator fails a mission that names one). Student initials and SPED labels are rejected by the validator.

## 7. Not evaluated

**Marble Builder** (`withmarble.com/marble-builder/`): this session's network cannot resolve withmarble.com, so its license, dependencies and install scripts could not be reviewed. Nothing from it was installed or run. The product does not depend on it. To evaluate it, allow that host and ask for the review.
