# EduWonderLab v3.0 release notes

## Release status

The candidate has built locally. Production deployment is pending the normal change-scoped QA and guarded ship flow.

## What changed

- Added a shared navy, teal, warm off-white, and amber visual system; Unit 6 family accents now use coral. The changed-surface palette gate includes source files, generated production files, Markdown, and changed raster assets, with negative controls for indigo and violet.
- Regenerated lesson notes and printable outputs from their generators. Regenerated 166 homework pages after the shared token update so their cache hashes match the current design tokens.
- Bundled the curriculum hub's 41 scripts into one 905 KB bundle, reducing that route's script requests by 40. Bundled hub styles from 15 sheets into 3, and unit-index styles from 13 sheets into 2.
- Updated curriculum, math, family, and ACCESS source artwork and controls; no generated page or image was hand-edited.
- Fixed the ACCESS Reading Room contrast issue by using dark teal for white-on-teal controls, and made the weekly-goal browser fixture deterministic.

## Verification

- `npm run build` completed successfully.
- `npm run validate:access-lab` passed: 501 activities, 17 tests, language-route scan, axe checks, and mobile reflow journeys.
- Changed-surface palette validation passed for 789 text/doc surfaces and 22 raster assets, with zero findings.
- Family design-token validation passed 429 contrast pairs across 3 themes; family art browser validation passed at 320, 768, and 1280 pixels in light and dark modes.
- Generated-page freshness passed for all gated worksheet, answer-key, lesson, and homework outputs.
- Chromium probes sampled modified curriculum and math routes at desktop and mobile widths. The sampled routes loaded with no page errors; two unrelated legacy math activities still have mobile horizontal overflow.

## Scope notes

- At Joel's direction, the release gate now prevents new palette violations on changed production surfaces; `npm run validate:no-purple -- --full` remains available to inventory untouched legacy surfaces. This release does not claim a whole-repository palette cleanup.
- No LCP or critical-path baseline was captured for Phase 0, so no before/after performance claim is made beyond the generated bundle/request counts above.
- The 25-item ACCESS editorial hand audit was skipped as requested. No item content was silently rewritten.
