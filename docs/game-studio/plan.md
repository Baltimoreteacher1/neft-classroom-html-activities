Scope: every cabinet and flagship in the curriculum Games catalog; Practice Arcade's ten unit worlds and lesson mode; Review Arcade; Placement Quest; Class Boss; Order Up; five Almost-Right equation missions; Monster Math Academy; both embedded games in the shared Learning Labs engine.

Acceptance criteria:

- Genuine playable keyboard and touch controls; readable at 390, 768 and 1366 pixel widths.
- Difficulty changes actual problem selection, with diagnostic measurement kept fixed.
- Correctness and session summaries reflect actual attempts; no fabricated mastery certificates.
- Feedback stays long enough to read; repeat submissions cannot award duplicate results.
- Preferences persist, dialogs manage focus, and pause stops supported engines.
- Existing routes, local saves, supported SCORM and progress messages remain compatible.
- No added tracking, student-data migrations, or new backend writes.
- Targeted game checks, repository validation and production build; live verification after guarded release.

Implementation: shared player controls plus engine-specific adapters, native DOM game fixes, updated discovery, and the canonical Monster Math Academy source build. No new runtime dependencies.
